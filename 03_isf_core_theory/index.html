03 · ISF 核心理論 Core Theory

從 impulse→Δφ 到 Eq.(21)、傅立葉/Parseval、線寬、擴散字典、App.B 閉式、capstone 主脊。

📄️ISF 的定義

從 current impulse 到 charge、到 state 擾動、投影到 phase direction，嚴謹定義無因次的 Γ(ω₀τ)，並推導 ideal LC 的 Γ(θ)=−sin θ。

📄️從 impulse 到 phase shift 的推導

從 Δq = ∫i dt 一路推到 Δφ = Γ(ω₀τ)·Δq/q_max，逐步、帶單位、附數值。

📄️從單一 impulse 到任意 noise 的卷積推導

把「一個 impulse 給一個相位 step」疊加成連續 noise 電流的相位響應 φ(t)=∫Γ(ω₀τ)/q_max·iₙ(τ)dτ，並說明這是 LTV 不是普通 LTI 卷積。

📄️ISF 的 Fourier series（傅立葉級數）

把 ISF 展成 Γ=c₀/2+Σcₙcos(nω₀τ+θₙ)，逐步推導；解釋 c₀ 控制 1/f 上轉、cₙ 把 nω₀ 附近 noise 搬到 carrier，附數值與 Python。

📄️非對稱三角 ISF 的閉式解（[P2] 附錄 B）

逐步推導 [P2] Appendix B Eq.(52)–(57)：rise/fall 不對稱的三角 ISF 之 Γrms、Γdc 與 1/f³ corner 閉式；A=1 精確退化為 Eq.(16)、corner ∝ (1−A)²/(1−A+A²) 且 ∝ 1/N；含數值例、慣例 2 倍旗標與 lab_33 模擬驗證。

📄️從波形直接算 ISF：[P1] 附錄的三種方法

逐字轉錄並逐步推導 [P1] 附錄「Calculation of the Impulse Sensitivity Function」的三種 ISF 計算法——打脈衝直接量測、state-space 投影 closed form Γ=f′/(f′²+f″²)、一階導數近似 Γ=f′/f′²max——並在 van der Pol 上做「三法對決」，誠實量化 closed form 何時可用、何時失準。

📄️白噪如何變成 1/f² phase noise

從 white current noise PSD 經 ISF 加權與相位積分，逐步推到 [P1] Eq.(19)→(20)→(21)，含 factor-of-2 教學註記與 canonical 數值例。

📄️Lorentzian 線寬：解開 1/f² 在 Δf→0 發散的矛盾

從相位 random walk（Var[Δφ]=2D|t|）經高斯特徵函數推出載波自相關 ½cos(ω₀τ)e^{-D|τ|}，再用 Wiener-Khinchin 得 Lorentzian S∝D/(D²+Δω²) 與 3-dB 線寬 D/π，並把 1/f² 在近載波的「假發散」修正為有限峰、總功率守恆，連 ISF 的 D=Γrms²/(4qmax²)·S_i 與 [E2] Demir 2000。

📄️擴散常數字典：κ、D、線寬、ADEV、1/f² 係數是同一個數字

以相位方差成長率 κ²=Γrms²·Si/(2qmax²)（[P2] Eq.11/12）為主角，逐步推導它換上五件衣服——ring jitter 常數 κ、相位擴散常數 D（兩種慣例）、Lorentzian 3-dB 線寬 κ²/(2π)、1/f² phase PSD 係數 2κ²、white-FM Allan deviation κ/(2πf₀√τ)——並把每個 factor-of-2 慣例（單邊/雙邊、Var=D|t| vs 2D|t|、SSB /2 vs /4）逐一對帳，用 lab_23 一次模擬五路驗證，canonical κ²=0.125 rad²/s。

📄️超越 Lorentzian：1/f³ 線形與非平穩性——儀器到底量什麼

白噪假設 Var[Δφ]=2D|t| 給 Lorentzian；flicker FM 使 Var[Δφ] 以 t²×log 成長（含低頻截止 f_l 的角色），特徵函數給出近高斯線核而非 Lorentzian。再嚴格說明自由振盪相位是 random walk、S_φ 嚴格不存在為平穩 PSD，儀器量的是平穩的 V(t) 頻譜（Demir 觀點），本站 S_φ 公式是「有限觀察時間、offset ≫ 線寬」的條件譜。lab_29 數值驗證全套。

📄️Flicker noise 上轉成 1/f³ phase noise

為何 device 1/f 雜訊被 ISF 的 DC 項 c₀ 上轉成 close-in 1/f³；推導 [P1] Eq.(22),(23),(24)，並說明 1/f³ corner ≠ device 1/f corner、波形對稱性為何關鍵。

📄️rms ISF 與 Parseval 關係

由 Parseval 推 Σcₙ²=(1/π)∫|Γ|²dx=2Γrms²；解釋 Γrms 如何決定 1/f² phase noise、DC factor 的慣例，以及 ring 的 Γrms∝N^(−3/2)（Γrms²∝N^(−3)）。

📄️Effective ISF 與 cyclostationary noise

從 cyclostationary device noise 推到 effective ISF Γ_eff(x)=Γ(x)·α(x)；說明 device 雜訊如何被週期「閘控」併入 ISF，並補充 PPV / adjoint / Floquet 的外部背景（不在 5 篇 PDF）。

📄️Capstone — 一顆 ideal LC 從 state equations 到 BER（全嚴格一條龍）

把全站串成一條主脊：LC state equations → Floquet 線性化 → Γ(θ)=−sin θ → Γrms=1/√2 → [P1] Eq.(21) 得 S_φ/L(Δω)（真·LC −145 dBc/Hz）→ Lorentzian 線寬 Δf₃dB → 積分得 σ_t → BER bathtub，每步嚴格、帶數值、做 dimension check。

📄️核心理論章習題（含完整解答）

ISF 核心理論章成套習題：由 ISF 算 Γrms、c0→1/f³ corner、白噪→L、impulse→phase、Fourier 係數、effective ISF。每題附逐步解、單位與 dimension check、數值答案、一行 Python 驗證。
