Lab 34 — 相關供電/基板雜訊的 N·f0 選擇律

先備：lab_03（ring toy 與累積 jitter）、lab_05（cnc_ncn​ 的數值萃取）、fourier_series_of_isf（cnc_ncn​ 是「接收頻道」）｜接下來：varactor_tuning_supply_pushing（供電雜訊的準靜態 KpushK_{push}Kpush​ 門）、device_noise_mapping（諧波＝頻道的整張地圖）

到目前為止的 phase noise 計算都有一個沒明說的前提：每個雜訊源只打進一個節點、且各節點的源彼此獨立（uncorrelated，不相關）。device 的 thermal / flicker 雜訊確實如此——[P2] p.792 明講：各節點源不相關時，NNN 個源的總 phase noise 就是單源結果（[P2] Eq.(6)）的 NNN 倍（差動 ring 為 2N2N2N 倍），功率直接相加，沒有任何頻率選擇。

但供電（supply）與基板（substrate）雜訊不是這樣。[P2] Sec. VI（p.797）指出它們與 device 內部雜訊有兩個關鍵差異：

  1. 其 PSD 通常非白，且常在特定頻率有強尖峰（例如開關穩壓器、數位區塊的開關諧波）；
  2. 同一條供電線/同一塊基板打到 ring 的每一個節點，擾動幾乎完全相同——各節點看到的是強相關（幾乎 identical）的雜訊。

這一頁把第 2 點變成一條可以量出來的選擇律（selection rule）：相關雜訊的有效 ISF 是 NNN 個相移 2π/N2\pi/N2π/N 的每級 ISF 之和，其傅立葉分量除了 n≡0 (mod N)n\equiv0\ (\mathrm{mod}\ N)n≡0 (mod N) 全部相量抵銷——所以相關雜訊只有 DC 附近與 k⋅N⋅f0k\cdot N\cdot f_0k⋅N⋅f0​ 附近的頻帶會轉成相位。

物理直覺（先講結論）：把 NNN 級 ring 想成 NNN 支指向不同方向的天線——每級的 ISF 形狀相同、只差一個 2π/N2\pi/N2π/N 的相位（[P2] Fig. 10 把它們畫成 ej2πn/5e^{j2\pi n/5}ej2πn/5 的五支相量）。同一個擾動打進全部 NNN 支時，第 mmm 個諧波頻道收到的是 NNN 支相量之和：只有當 mmm 是 NNN 的整數倍，五支相量才同相疊加（增益 NNN）；否則它們在複數平面繞一整圈，向量和恰為零。這不是近似，是有限幾何級數的恆等式——本 lab 會把它算到機器精度給你看。

模型層級聲明：本 lab 的每級 ISF 是 pedagogical toy model（雙葉三角、刻意上升/下降不對稱），非 transistor-level（要看「量出來」的 ring ISF 去 lab_32）。選擇律本身不依賴 ISF 形狀——推導對任何 2π2\pi2π 週期的 Γ\GammaΓ 都成立，這正是它強大的原因。相位模型是線性 LTV（[P1] Eq.(11)），沒有振幅動態；真實振盪器的振幅響應會留下殘餘 sideband（[P2] Fig. 11 實測有看到，見第 11 節）。

1. 教學目標​

  • 逐字轉錄並解釋 [P2] Eq.(37)–(38)（p.797）：相同雜訊源打進全部 NNN 節點時，總相位是 NNN 個相移 ISF 的疊加。
  • 用有限幾何級數一步不跳地證明：疊加後的 ISF 只剩 n≡0 (mod N)n\equiv0\ (\mathrm{mod}\ N)n≡0 (mod N) 的傅立葉分量，且倖存分量放大 NNN 倍。
  • N=5N=5N=5 toy ring 數值驗證（頻域）：summed ISF 的 ∣cn∣\lvert c_n\rvert∣cn​∣ 梳只剩 n=0,5,10,15n=0,5,10,15n=0,5,10,15，禁止分量掉到數值底噪（選擇比 165.8 dB）。
  • 時域驗證（仿 [P2] Fig. 11 的 10 µA 實驗）：共同正弦擾動掃 nf0+Δfn f_0+\Delta fnf0​+Δf，相位響應只在 n=0,5,10n=0,5,10n=0,5,10 出峰（選擇比 66 dB、同調增益 4.998≈N4.998\approx N4.998≈N、與 [P1] Eq.(15)/(16) 理論吻合到 10−510^{-5}10−5 相對誤差）。
  • 把結果翻成設計語言：N⋅f0N\cdot f_0N⋅f0​ 選擇律——供電尖峰要避開 k⋅N⋅f0k\cdot N\cdot f_0k⋅N⋅f0​；上升/下降對稱關 DC 門；級間失配會讓抵銷不完全。

2.4 DC 門與上升/下降不對稱 —— 為什麼低頻供電雜訊最危險​

供電雜訊的功率恰恰集中在低頻（穩壓器 ripple、負載瞬變、1/f1/f1/f）——正好對準 ΓΣ\Gamma_{\Sigma}ΓΣ​ 的 DC 頻道。這個頻道開多大由單級 ISF 的 c0c_0c0​ 決定，而 c0c_0c0​ 由上升/下降不對稱決定（[P2] App. B，p.803）：Eq.(53) 定義 A=frise′/ffall′A=f_{rise}'/f_{fall}'A=frise′​/ffall′​（上升/下降斜率比），Eq.(56) 給出

Γdc=2πη2N2⋅1−A1+A\Gamma_{dc}=\frac{2\pi}{\eta^2N^2}\cdot\frac{1-A}{1+A}Γdc​=η2N22π​⋅1+A1−A​

——完美對稱（A=1A=1A=1）時 DC 門關死；不對稱越大門越開，並經 Eq.(57) 抬高 1/f31/f^31/f3 corner。本 lab 的 toy ISF 刻意取不對稱雙葉（正葉峰 1.0、負葉峰 0.6），讓 c0≠0c_0\neq0c0​=0、DC 頻道打開，你才能在圖上同時看到「DC 門」與「Nf0N f_0Nf0​ 梳」兩件事。

設計語言（N⋅f0N\cdot f_0N⋅f0​ 選擇律）：對相關的供電/基板雜訊，ring 是一個梳狀接收機——只聽 DC 與 k⋅N⋅f0k\cdot N\cdot f_0k⋅N⋅f0​。所以：(i) 已知供電有開關尖峰 fswf_{sw}fsw​ 及其諧波時，選 NNN、f0f_0f0​ 讓 k⋅N⋅f0k\cdot N\cdot f_0k⋅N⋅f0​ 避開尖峰（或反過來選 fswf_{sw}fsw​）；(ii) NNN 越大，第一個高頻敏感帶 Nf0N f_0Nf0​ 越高，而封裝/去耦在高頻通常衰減更多；(iii) 上升/下降對稱（A→1A\to1A→1）把 DC 門關小——這與 device flicker 的 c0c_0c0​ 對策（symmetry）是同一顆鈕；(iv) 級間失配會讓相量抵銷不完全，禁止頻帶漏進殘餘（見第 11 節）。

def gamma_stage(theta):
    """每級 toy ring ISF：+1.0 三角葉在上升緣（θ=0）、−0.6 三角葉在下降緣（θ=π）。
    刻意不對稱（1.0 vs 0.6）→ c0 ≠ 0（[P2] App.B：A≠1 ⇒ Γdc≠0）。"""

    d_rise = np.minimum(th, 2 * np.pi - th)
    d_fall = np.abs(th - np.pi)
    return H_RISE * _tri(d_rise, W_LOBE) - H_FALL * _tri(d_fall, W_LOBE)

def gamma_summed(theta):
    """N 個相移 2π/N 的每級 ISF 之和（[P2] Eq.(37) 的中括號）。"""
    acc = np.zeros_like(np.asarray(theta, dtype=float))
    for n in range(N_STAGES):
        acc += gamma_stage(theta + 2 * np.pi * n / N_STAGES)
    return acc

def response(n_h, g_t):
    """共同注入 i(t)=I0·cos(2π(n_h·f0+Δf)t)，回傳 φ 在 Δf 的振幅 [rad]。"""
    i_inj = I0 * np.cos(2 * np.pi * (n_h * F0 + DF) * t)
    phi = np.cumsum(i_inj * g_t) * dt / QMAX      # [P1] Eq.(11) 的離散版
    return 2.0 * np.abs(np.mean(phi * proj))      # 投影到 Δf bin（整數個慢週期）

頻域部分用 compute_fourier_coefficients（lab_05 同一把尺）對單級與 summed ISF 各算 c0…c15c_0\dots c_{15}c0​…c15​；相量恆等式直接算 ∣Sm∣=∣∑nej2πmn/5∣\lvert S_m\rvert=\lvert\sum_n e^{j2\pi mn/5}\rvert∣Sm​∣=∣∑n​ej2πmn/5∣。

11. 限制與 approximation​

  • 純相位線性 LTV：本 lab 只有 [P1] Eq.(11) 的相位積分，沒有振幅動態。[P2] Fig. 11 實測在非 NNN 倍諧波處看到振幅響應造成的殘餘 sideband——那條路徑（AM，及經 AM-PM 轉回相位）在本模型裡不存在；我們的禁止頻帶殘餘（−66-66−66 dB）純屬數值底噪（取樣洩漏），不要拿去預測真實電路的禁止頻帶深度。
  • 完全相同的級（identical stages）：抵銷恰為零依賴每級 ISF 形狀相同、間隔精確 2π/N2\pi/N2π/N。實際失配（負載、驅動強度、佈局）讓相量和殘留 ∝\propto∝ 失配量——一階近似下，ε\varepsilonε 的相對失配讓禁止頻道漏進 ∼ε\sim\varepsilon∼ε 的振幅（20log⁡10ε20\log_{10}\varepsilon20log10​ε dB）。1% 失配 ⇒ 禁止頻帶只壓 40 dB，不是無限深。
  • 「完全相關、等強度、同號」的注入：真實供電/基板耦合到各節點的係數不完全相等（IR drop、佈局距離），介於「完全相關」與「不相關」之間；本頁兩個極端給出上下界。
  • toy ISF：雙葉三角是手放的（lab_03 同款思路、加上不對稱）；真實單端 ring 的 ISF 形狀見 lab_32。但選擇律不依賴形狀——2.2 的證明對任何 2π2\pi2π 週期 Γ\GammaΓ 成立，換 ISF 只改各頻道的 cnc_ncn​ 值、不改「哪些頻道存在」。
  • 供電雜訊這裡被模型化為節點電流注入：低頻供電雜訊還有一條準靜態 FM 路徑（KpushK_{push}Kpush​，經工作點改 f0f_0f0​）——那是 varactor_tuning_supply_pushing 的主題；兩條路徑並存，低 offset 時 KpushK_{push}Kpush​ 門通常主導，kNf0k N f_0kNf0​ 梳則是高頻供電尖峰的專屬入口。
  • cyclostationary 加權未含：嚴格說各級注入還要乘 NMF α(ω0t)\alpha(\omega_0t)α(ω0​t)（effective_isf）；相同級時 α\alphaα 也是同族相移函數，選擇律對 Γeff=Γα\Gamma_{eff}=\Gamma\alphaΓeff​=Γα 照樣成立（乘積仍 2π2\pi2π 週期）。
