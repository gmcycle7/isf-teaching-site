1. 把 κ² 當 D——線寬直接大 2 倍​

❌ 錯誤做法：算出相位方差成長率 κ2=Γrms22qmax2in2‾Δf\kappa^2=\dfrac{\Gamma_{rms}^2}{2q_{max}^2}\dfrac{\overline{i_n^2}}{\Delta f}κ2=2qmax2​Γrms2​​Δfin2​​​（[P2] Eq.(11)/(12), p.793）， 把這個數字直接叫做 diffusion constant DDD，再套 Demir 慣例的線寬公式 Δf3dB=D/π\Delta f_{3\mathrm{dB}}=D/\piΔf3dB​=D/π。（本站 v3 規範曾犯此錯，v5 以 Monte-Carlo 裁決修正。）

💥 為什麼錯：文獻裡 DDD 有兩種定義——rate 慣例 Var[Δϕ]=D∣t∣\mathrm{Var}[\Delta\phi]=D\vert t\vertVar[Δϕ]=D∣t∣ （此時 D=κ2D=\kappa^2D=κ2）與 Demir/雷射慣例 Var[Δϕ]=2D∣t∣\mathrm{Var}[\Delta\phi]=2D\vert t\vertVar[Δϕ]=2D∣t∣（此時 D=κ2/2D=\kappa^2/2D=κ2/2）。Δf3dB=D/π\Delta f_{3\mathrm{dB}}=D/\piΔf3dB​=D/π 是後者的公式；把前者的值塞進去， 線寬多算 2×2\times2×。

✅ 正確版：先問對方的 Var\mathrm{Var}Var 式子裡有沒有那個 2，再換裝。無歧義的寫法是 全部用 κ2\kappa^2κ2 表達：

4. 用 ΔV/斜率 直覺推 ISF 方向——LTI 直覺在 LTV 系統上翻車​

❌ 錯誤做法：套 comparator 的 Δt=ΔV/(dV/dt)\Delta t=\Delta V/(\mathrm{d}V/\mathrm{d}t)Δt=ΔV/(dV/dt) 直覺，宣稱「注入正電荷把電壓推高，所以相位 一律超前（或一律落後）」；或由此推出「斜率越小越敏感，所以正弦振盪器在波峰最怕 noise」。（本站 lti_vs_ltv 頁早期版本就把方向寫反過，已修正。）

💥 為什麼錯：振盪器是 LTV（linear time-variant，線性時變）系統，Δϕ\Delta\phiΔϕ 的正負 由電壓跳變在 limit cycle 上的切向投影決定，隨注入相位變號；而在波峰，ΔV\Delta VΔV 幾乎全是徑向（振幅）分量，被振幅恢復力吃掉——真實敏感度是 0，不是 1/1/1/斜率 暗示的 無限大。

✅ 正確版：理想 LC（V=Vmaxcos⁡θV=V_{max}\cos\thetaV=Vmax​cosθ）的 ISF 是 Γ(θ)=−sin⁡θ\Gamma(\theta)=-\sin\thetaΓ(θ)=−sinθ （[P1] Sec. 8. 把 L 在 Δf→0 的發散當物理——「近載波無限大」不存在​

9. 把 DJ_pp 直接塞進 TJ 公式——該用 DJ_δδ​

❌ 錯誤做法：量到（或算出）deterministic jitter 的實際 peak-to-peak 值 DJpp\mathrm{DJ}_{pp}DJpp​，直接代入業界外插公式 TJ(BER)=DJ+2Q−1(BER) σ\mathrm{TJ}(\mathrm{BER})=\mathrm{DJ}+2Q^{-1}(\mathrm{BER})\,\sigmaTJ(BER)=DJ+2Q−1(BER)σ。

10. RBW 開太寬量 close-in——把 −30 dB/dec 的陡裙邊抹平​

❌ 錯誤做法：用 spectrum analyzer 直接法量近載波 phase noise 時，為了掃得快， 在 offset 1 kHz 用 RBW（resolution bandwidth，解析頻寬）=1=1=1 kHz 級的濾波器讀 dBc/Hz；或用標稱 RBW（而非 ENBW）做 per-Hz 歸一。

💥 為什麼錯：dBc/Hz 讀數是「RBW 濾波器窗內的平均密度」。1/f31/f^31/f3 區密度在一個 窗內變化數十 dB，平均值被靠載波那側主導——讀數偏高、陡裙邊被抹平；RBW 大到窗沿 碰到載波時，載波功率直接漏進來，read 到的是濾波器形狀不是 DUT。

✅ 正確版：close-in 量測讓 RBW ≪Δf\ll\Delta f≪Δf（保守取 Δf/10\Delta f/10Δf/10 以下）。誠實的 數值手感（對 1/f31/f^31/f3 密度在窗內取平均、與 Δf=1\Delta f=1Δf=1 kHz 的真值比）：RBW =1=1=1 kHz 偏高 2.5 dB，RBW =100=100=100 Hz 只剩 0.02 dB（見文末 code；這還沒算載波洩漏，實況 只會更糟）。歸一到 per-Hz 用 ENBW（equivalent noise bandwidth，等效雜訊頻寬） 而非標稱 RBW，並記得 log 檢波的 +2.5+2.5+2.5 dB 修正（與上面窗平均那個 2.5 dB 是不同機制， 數值撞號純屬巧合）——此為標準頻譜儀量測常識（外部文獻， 非本站 5 篇 PDF；見 measurement 頁方法 A 所引 Keysight/Agilent AN-1303）。真正的 近載波轉平是 Lorentzian（錯誤 8），先排除 RBW 假象才能宣稱看到了它。

共同病根：三個 factor-of-2 家族 + 一個 LTI 慣性​

13 條地雷裡有 7 條（1、2、3、7、9 的 2Q−12Q^{-1}2Q−1、11、12）本質上是記帳慣例問題， 可歸成三家族（詳見 diffusion_dictionary）：

  1. 單邊 vs 雙邊 PSD：Si/2S_i/2Si​/2 的 δ\deltaδ 強度、2κ22\kappa^22κ2 的單邊譜、jitter 核的 8 vs 4。
  2. Var=D∣t∣\mathrm{Var}=D\vert t\vertVar=D∣t∣ vs 2D∣t∣2D\vert t\vert2D∣t∣：κ2=D甲=2D乙\kappa^2=D_{\text{甲}}=2D_{\text{乙}}κ2=D甲​=2D乙​。
  3. SSB /2/2/2 vs /4/4/4：−145-145−145 vs −148-148−148 的 3 dB。

另外 4 條（4、5、8、部分 10）是把 LTI／線性化直覺用到它失效的地方：斜率直覺撞上 振幅恢復、device corner 直覺撞上 c0c_0c0​ 上轉、1/f21/f^21/f2 直線撞上隨機漫步的大角度、 窄帶密度直覺撞上寬 RBW 平均。防禦方法只有一個：每個數字都問「這是哪個慣例？ 近似在這裡還成立嗎？」——然後用一行 Python 對帳。

一鍵對帳：本頁所有數字的驗證 code​

以下把 13 條地雷中可一行驗證的數字全部重算一次（跑法：在專案根目錄 PYTHONPATH=. python3 <此檔>；錯誤 9 的 DJ 數字由 simulations/lab_31_dual_dirac.py 產生，見 dj_dual_dirac）：

import numpy as np
from simulations.common.noise_utils import leeson_one_over_f2, integrate_rms_jitter

# --- 錯誤 1：κ² 誤當 D（線寬 2×）---
GRMS, QMAX, SI = 0.5, 1e-12, 1e-24
k2 = GRMS**2 * SI / (2 * QMAX**2)                 # [P2] Eq.(11)/(12)
print(round(k2, 3))                               # -> 0.125 （κ², rad²/s）
print(round(k2 / (2*np.pi) * 1e3, 1))             # -> 19.9 （正確 FWHM，mHz）
print(round(k2 / np.pi * 1e3, 1))                 # -> 39.8 （κ² 塞進 D/π 的 2× 錯值）

# --- 錯誤 2：SSB /4 vs 時域 /2（3 dB）---
dw = 2 * np.pi * 1e6
print(round(10*np.log10(GRMS**2/QMAX**2 * SI/(4*dw**2)), 1))  # -> -148.0 （[P1] Eq.(21) /4）
print(round(10*np.log10(GRMS**2/QMAX**2 * SI/(2*dw**2)), 1))  # -> -145.0 （時域 /2）

# --- 錯誤 3：單邊譜塞進 8 係數核（×√2）---
f0, T = 5e9, 2e-10
sigP = np.sqrt(k2 * T) / (2*np.pi*f0)
print(round(sigP*1e15, 4))                        # -> 0.1592 （正確 period jitter，fs）
print(round(sigP*np.sqrt(2)*1e15, 4))             # -> 0.2251 （×√2 錯值，fs）

# --- 錯誤 5：1/f³ corner ≠ device corner（Eq.24，device corner=1 MHz）---
print(round(1e6 * 0.4**2 / (2*GRMS**2) / 1e3, 1))   # -> 320.0 （c0=0.4，kHz）
print(round(1e6 * 0.04**2 / (2*GRMS**2) / 1e3, 1))  # -> 3.2 （c0=0.04，kHz）

# --- 錯誤 6：8/(3γ) vs 8/(3η)（γ=2/3、η=1）---
print(round(10*np.log10((8/(3*(2/3))) / (8/3)), 2))  # -> 1.76 （dB，錯記法多算的量）

# --- 錯誤 7：積分忘 ×2、或 f₁ 亂移 ---

重點回顧​

  • 換慣例前先對帳：單邊/雙邊、Var=D∣t∣\mathrm{Var}=D\vert t\vertVar=D∣t∣ vs 2D∣t∣2D\vert t\vert2D∣t∣、 SSB /2/2/2 vs /4/4/4——三個 factor-of-2 家族包辦了大半地雷。
  • ISF 的方向與大小來自 limit-cycle 切向投影，不是 ΔV/\Delta V/ΔV/斜率；波峰是振幅通道 的地盤（Γ=0\Gamma=0Γ=0）。
  • 兩個 corner 是兩回事：1/f31/f^31/f3 corner =ω1/f c02/(2Γrms2)=\omega_{1/f}\,c_0^2/(2\Gamma_{rms}^2)=ω1/f​c02​/(2Γrms2​)， 由對稱性可壓到遠低於 device corner（本例 c0=0.04c_0=0.04c0​=0.04 時低 300 倍：1 MHz → 3.2 kHz）。
  • ring FOM 前置係數是 8/(3η)8/(3\eta)8/(3η)；γ\gammaγ 只活在 Vchar=ΔV/γV_{char}=\Delta V/\gammaVchar​=ΔV/γ 裡。
  • jitter 積分：×2\times2×2、標頻帶（f1f_1f1​ 主導）、÷2πf02\pi f_02πf0​；理想 ×N/÷N 之下 秒數不變，變的只是 dB 匯率。
  • Δf→0\Delta f\to0Δf→0 的發散是線性化假象——真實譜是 Lorentzian，總功率守恆。
  • TJ 外插吃 DJδδ\mathrm{DJ}_{\delta\delta}DJδδ​（模型參數、故意低報），不吃 DJpp\mathrm{DJ}_{pp}DJpp​。
  • close-in 量測：RBW ≪Δf\ll\Delta f≪Δf、用 ENBW 歸一，先排除儀器假象再談物理。
  • flicker 主導時累積律 ≈N\approx N≈N（非 N\sqrt NN​），且對數依賴 flf_lfl​——報數字附條件。

  • 7. dBc/Hz 積分算 jitter：忘了 ×2，或積分範圍亂標
  • 8. 把 L 在 Δf→0 的發散當物理——「近載波無限大」不存在
  • 9. 把 DJ_pp 直接塞進 TJ 公式——該用 DJ_δδ
  • 10. RBW 開太寬量 close-in——把 −30 dB/dec 的陡裙邊抹平
  • 11. ÷2 之後以為 jitter（秒）也減半——相位 dB 與絕對時間的混淆
  • 12. 對 flicker 噪聲用白噪的 √N 累積律
  • 13. 純弦波次諧波注入以為會鎖——純正弦沒有第 N 諧波
