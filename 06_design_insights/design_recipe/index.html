規格驅動設計配方：從 spec 到 jitter 的 7 步

先備：fom_limit（FOM=173.8−10log⁡10Feff\mathrm{FOM}=173.8-10\log_{10}F_{eff}FOM=173.8−10log10​Feff​ 天花板家族）、tank_Q_and_energy_restoration（QQQ 的三種寫法、4kT/Rp4kT/R_p4kT/Rp​）、tank_swing（qmax=CVmaxq_{max}=CV_{max}qmax​=CVmax​、current/voltage-limited、4πIbiasRp\tfrac{4}{\pi}I_{bias}R_pπ4​Ibias​Rp​）、white_noise_to_phase_noise（[P1] Eq.(21) 與 /2 vs /4 慣例）｜ 接下來：pll_noise_budget、clock_chain_budget、lab_09_design_tradeoffs

本站其他設計頁都是「正向」的：給你 qmaxq_{max}qmax​、Γrms\Gamma_{rms}Γrms​、SiS_iSi​，算出 L(Δf)\mathcal{L}(\Delta f)L(Δf)； 或是「單旋鈕反推」：只動 qmaxq_{max}qmax​ 要放大幾倍（exercises 習題 1）、 只動 QQQ 該多高（fom_limit 例 2）。真正的設計工作卻是反過來的： 手上只有一張規格表（phase noise、功率、調諧範圍），要一路決定拓樸、tank 元件值、swing、 偏壓電流，最後回頭驗證規格達標、再換算成系統要的 jitter。這頁把這條路寫成一份可以重複套用的 配方（recipe）：7 個步驟、一組數字從頭算到尾、每一步都標明用了哪條公式、單位是否合、 什麼情況下會失效；最後給出「餘裕不夠時該轉哪個旋鈕、每轉一格買幾 dB、花多少功率」的迭代規則。

物理直覺（先講結論）：規格表裡的三個數字 L\mathcal{L}L、PPP、f0/Δff_0/\Delta ff0​/Δf 合成一個數字—— 所需 FOM。這個數字跟 fom_limit 的天花板家族一比，拓樸就決定了 （ring 的天花板 168.3 dB 是一道硬牆）。拓樸定了之後，LC 的 L\mathcal{L}L 只由四樣東西決定： QQQ（雜訊源 4kT/Rp4kT/R_p4kT/Rp​ 有多小）、qmax=CVmaxq_{max}=CV_{max}qmax​=CVmax​（訊號電荷有多大）、FFF（除了 tank 還有誰在吵）、 Γrms\Gamma_{rms}Γrms​（波形形狀）——這正是 [P1] Eq.(21) 的四個因子。配方的工作就是把這四個因子一個一個 釘死成元件值與偏壓，然後用 Eq.(21) 驗收。

def design(C, Q=Q, Vmax=Vmax, VDD=VDD, F=F):
    L = 1/(w0**2*C); Rp = Q*w0*L
    qmax = C*Vmax; Ib = (np.pi/4)*Vmax/Rp; P = VDD*Ib
    Si = F*4*kB*T/Rp
    Ldb = 10*np.log10(grms2/qmax**2 * Si/(4*dw**2))
    return Ldb, P, -Ldb + 20*np.log10(f0/df) - 10*np.log10(P/1e-3), Rp, Ib
