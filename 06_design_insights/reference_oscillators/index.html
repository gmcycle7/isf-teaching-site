參考源（crystal / MEMS）：時脈鏈的 low-offset 錨

先備：clock_chain_budget（規則 3：in-band =N2Sref∣Hlp∣2= N^2 S_{ref}\lvert H_{lp}\rvert^2=N2Sref​∣Hlp​∣2）、tank_Q_and_energy_restoration（QQQ 三寫法、4kT/Rp4kT/R_p4kT/Rp​、Q↔Γrms/qmaxQ\leftrightarrow\Gamma_{rms}/q_{max}Q↔Γrms​/qmax​ 橋——本頁的推導全部踩在它上面）、derivation_leeson（(ω02QΔω)2\big(\tfrac{\omega_0}{2Q\Delta\omega}\big)^2(2QΔωω0​​)2 整形項）｜ 接下來：pll_noise_budget、fom_limit

每一條真實的時脈鏈——SoC、SerDes、取樣系統、射頻收發機——的最上游都坐著一顆 參考源（reference oscillator，頻率參考振盪器）：石英晶體振盪器（crystal oscillator） 或 MEMS 振盪器。系統設計者為它花的錢常常超過整顆 PLL，問題是：為什麼？它到底買到了什麼、 買不到什麼？ 這頁用本站已建好的兩座橋回答： clock_chain_budget 的規則 3 說明為什麼鏈上沒有任何 東西能替 reference 的 close-in 雜訊擦屁股； tank_Q_and_energy_restoration 的 Q↔Γrms/qmaxQ\leftrightarrow\Gamma_{rms}/q_{max}Q↔Γrms​/qmax​ 橋說明為什麼 crystal 的 close-in 雜訊天生就低幾個數量級。

物理直覺（先講結論）：crystal 不是什麼新物理——它就是一顆 QQQ 高到誇張的 LC tank。 石英的機械共振等效成 LLL、CCC、RRR，QQQ 常見 10410^4104 到 10610^6106（產業慣例量級，外部）， 而 on-chip spiral inductor 的 tank 只有 Q≈5Q\approx5Q≈5–202020。同一套 Leeson／ISF 公式、 同一個 (f02QΔf)2\big(\tfrac{f_0}{2Q\Delta f}\big)^2(2QΔff0​​)2 整形項，把 QQQ 從 10 換成 5×1045\times10^45×104， close-in phase noise 就掉 ∝1/Q2\propto 1/Q^2∝1/Q2——幾十個 dB 不是靠聰明電路，是靠共振器裡 儲存的巨大能量對上極小的每週期損耗。時脈鏈的分工因此天生確定：低 offset 聽 reference 的、 高 offset 聽 VCO 的，PLL 只是把兩段縫起來的裁縫。

誠實聲明（請先讀）：本站下載的 5 篇 PDF（[P1]–[P5]）都沒有 crystal / MEMS 的內容。 本頁凡是接到 ISF 的地方都經由已核的 [P1] Eq.(21), p.185 與站內 tank_Q_and_energy_restoration 的橋； Leeson 整形項屬 [E1] Leeson 1966（外部文獻，非本站 5 篇 PDF，見 references）；crystal 等效電路（BVD model）與 XO/TCXO/OCXO/MEMS 的典型數字屬標準頻率控制工業知識（產業慣例，外部，非本站 5 篇 PDF），本頁只給 order-of-magnitude 範圍、不杜撰特定論文引用，選型請以廠商 datasheet 為準。

第 1 步：為什麼 reference 是整條鏈的 low-offset 錨​

clock_chain_budget 的規則 3（PLL）說：

Sout(f)=N2 Sref(f) ∣Hlp(f)∣2+Svco(f) ∣Hhp(f)∣2S_{out}(f)=N^2\,S_{ref}(f)\,\lvert H_{lp}(f)\rvert^2+S_{vco}(f)\,\lvert H_{hp}(f)\rvert^2Sout​(f)=N2Sref​(f)∣Hlp​(f)∣2+Svco​(f)∣Hhp​(f)∣2

in-band（f≪fnf\ll f_nf≪fn​，loop bandwidth 內）∣Hlp∣2→1\lvert H_{lp}\rvert^2\to1∣Hlp​∣2→1：輸出的 close-in 相位雜訊 就是 reference 的相位雜訊加 20log⁡10N20\log_{10}N20log10​N，一個 dB 都跑不掉。再看鏈上其他元件能做什麼 （同頁規則 1、2、4）：×N、÷N 只做縮放（整條曲線平移，乾淨的進去才乾淨的出來）； buffer 只會加自己的床（功率相加，只會更糟）。結論：

  • 鏈上沒有任何東西能改善 reference 的 close-in 雜訊。低 offset（loop BW 內）的品質， 在你「買下那顆 reference」的瞬間就定案了。
  • 該頁的 worked chain 是活生生的證據：最終 27.6 fs 積分 jitter 裡 65.9 % 的功率來自 被 ×N2\times N^2×N2 抬高的 reference in-band 床，而那顆漂亮的 −148-148−148 dBc/Hz VCO 只佔 0.42 %。
  • 反過來，far-out（loop BW 外）reference 完全無關——那裡 ∣Hhp∣2→1\lvert H_{hp}\rvert^2\to1∣Hhp​∣2→1， 聽 VCO 的。reference 是 low-offset 錨，不是全頻段救星（第 4 步的 worked block 會給這句話數字）。

例 1（把 reference 錨進 ×50 PLL——canonical 數字）：一顆 100 MHz 低雜訊 XO 在 1 kHz offset 有 L=−150\mathcal{L}=-150L=−150 dBc/Hz（低雜訊 XO 等級，產業慣例量級，外部）。 鎖進 ×50 PLL 到 5 GHz，in-band 的 L(1 kHz)\mathcal{L}(1\,\text{kHz})L(1kHz) 是多少？ 比 free-run 的 on-chip LC 好幾 dB？

逐步代入（帶單位）——in-band 用規則 3 的漸近式：

Lout(1 kHz)=−150+20log⁡1050=−150+33.98=−116.02 dBc/Hz.\mathcal{L}_{out}(1\,\text{kHz})=-150+20\log_{10}50=-150+33.98=-116.02\ \text{dBc/Hz}.Lout​(1kHz)=−150+20log10​50=−150+33.98=−116.02 dBc/Hz.

對照組：本站 canonical 例 B 的 5 GHz on-chip LC（L(1 MHz)=−148\mathcal{L}(1\,\text{MHz})=-148L(1MHz)=−148、 1/f21/f^21/f2 裙邊）free-run 外推到 1 kHz：−148+20log⁡10(106/103)=−148+60=−88-148+20\log_{10}(10^6/10^3)=-148+60=-88−148+20log10​(106/103)=−148+60=−88 dBc/Hz。 鎖 reference 在 1 kHz 贏 28.0 dB——這就是「買 reference」買到的東西。 兩條線交叉在 25.225.225.2 kHz（−148−20log⁡10(f/106)=−116.02-148-20\log_{10}(f/10^6)=-116.02−148−20log10​(f/106)=−116.02 解出 fff）， 正是 pll_noise_budget 「交叉點決定最佳 loop BW」 的第一手感。Dimension check：dB 加法 = 無因次比值相乘 ✓； 20log⁡10N20\log_{10}N20log10​N 之 NNN 無因次 ✓。一行 Python 驗證：

import numpy as np
L_in = -150.0 + 20*np.log10(50)        # 規則 3 in-band：ref + 20logN
print(round(L_in, 2))                  # -> -116.02
L_lc = -148.0 - 20*np.log10(1e3/1e6)   # canonical LC 1/f² 裙邊外推到 1 kHz
print(round(L_lc, 1))                  # -> -88.0
print(round(L_lc - L_in, 1))           # -> 28.0
f_cross = 1e6 * 10**(-(L_in + 148.0)/20)
print(round(f_cross/1e3, 1))           # -> 25.2

第 2 步：crystal 就是一顆極端 QQQ 的 LC tank​

石英晶體是機械共振器：壓電效應（piezoelectricity，機械應變↔電場互相轉換）把石英片的 機械振動模態映成電埠上的等效電路——標準的 BVD model（Butterworth–Van Dyke 等效電路， 外部教科書內容，非本站 5 篇 PDF）：

  • motional branch（動生支路）：LmL_mLm​–CmC_mCm​–RmR_mRm​ 串聯，代表機械的質量－勁度－阻尼。 量級（產業慣例）：Lm∼L_m\simLm​∼ mH–H、Cm∼C_m\simCm​∼ fF、Rm∼R_m\simRm​∼ 十到百 Ω\OmegaΩ。
  • C0C_0C0​（靜態電容）：電極與封裝的普通電容，pF 級，與 motional branch 並聯。

在 series resonance ωs=1/LmCm\omega_s=1/\sqrt{L_mC_m}ωs​=1/Lm​Cm​​ 附近，這就是一顆 LC tank，QQQ 用 tank_Q_and_energy_restoration 的同一套定義 （串聯形式 Q=ωsLm/RmQ=\omega_s L_m/R_mQ=ωs​Lm​/Rm​，或能量定義 Q=ω0Estored/PdissQ=\omega_0 E_{stored}/P_{diss}Q=ω0​Estored​/Pdiss​——兩頁同一個 QQQ）：

Qcrystal∼104 到 106vsQon-chip LC∼5–20.Q_{crystal}\sim10^4\ \text{到}\ 10^6\qquad\text{vs}\qquad Q_{on\text{-}chip\ LC}\sim5\text{–}20.Qcrystal​∼104 到 106vsQon-chip LC​∼5–20.

（crystal QQQ 範圍為產業慣例量級，外部；on-chip QQQ 天花板見 tank_Q 頁第 5 步。） Lm∼L_m\simLm​∼ mH 對上 on-chip 的 nH——差 6 個數量級的等效電感配上更小的等效損耗， 這就是「巨大儲能對上極小損耗」的電路化身。振盪波形接近正弦，所以 pedagogical toy 的 ISF 仍是 Γ≈−sin⁡\Gamma\approx-\sinΓ≈−sin、Γrms=1/2\Gamma_{rms}=1/\sqrt2Γrms​=1/2​（rms_isf）—— crystal 的優勢不是來自 ISF 形狀，而是全部從 QQQ（等價地：儲能 EEE 與 qmaxq_{max}qmax​）進帳。 下一步就把這句話變成公式。

第 3 步：用站內的 Q↔Γrms/qmaxQ\leftrightarrow\Gamma_{rms}/q_{max}Q↔Γrms​/qmax​ 橋推 1/Q21/Q^21/Q2 scaling​

  1. close-in L∝1/Q2\mathcal{L}\propto 1/Q^2L∝1/Q2（固定 PdissP_{diss}Pdiss​）：QQQ 乘 10⇒−2010\Rightarrow-2010⇒−20 dB。 crystal 的 QQQ 比 on-chip LC 高 10310^3103–10510^5105 倍，光這一項就是 −60-60−60 到 −100-100−100 dB 級。
  2. 真正的槓桿是 Estored⋅QE_{stored}\cdot QEstored​⋅Q 乘積（步驟 4 形式）——「儲多少能」×「漏得多慢」。 同一個 4kT4kT4kT 漲落對上越大的儲能水庫、越慢的洩漏，換到的相位就越小。這就是 Q↔Γrms/qmaxQ\leftrightarrow\Gamma_{rms}/q_{max}Q↔Γrms​/qmax​ 橋的能量讀法：crystal 的有效 Γrms/qmax\Gamma_{rms}/q_{max}Γrms​/qmax​（連同它看到的雜訊）比任何 on-chip LC 低好幾個數量級， 不是 ISF 形狀不同，而是分母 qmaxq_{max}qmax​（儲存電荷/能量）巨大、雜訊源（損耗）相對微小。

第 6 步：MEMS——f⋅Qf\cdot Qf⋅Q 乘積上限與「倍頻稅」​

MEMS（microelectromechanical systems，微機電）振盪器把石英換成矽的機械共振器 （真空封裝、Q∼104Q\sim10^4Q∼104–10510^5105 量級），再用 fractional-N PLL 把 MHz 級的共振頻率 合成到使用者要的輸出。兩件物理決定它的 phase noise 定位（皆產業慣例／材料物理量級，外部）：

(a) f⋅Qf\cdot Qf⋅Q 乘積上限。 對給定材料與損耗機制（聲子散射 Akhiezer damping、 thermoelastic damping、anchor loss 等），共振頻率與 QQQ 的乘積有量級上限—— 石英與矽在室溫都在 f⋅Q∼1013f\cdot Q\sim10^{13}f⋅Q∼1013 Hz 量級（產業慣例；精確值依切型/模態/溫度而異， 本站不給假精度）。這條上限把 QQQ 和 f0f_0f0​ 綁成蹺蹺板：f0f_0f0​ 拉高，QQQ 就 ∝1/f0\propto1/f_0∝1/f0​ 掉下來。

(b) 「倍頻稅」下的最佳分工。 若 f⋅Qf\cdot Qf⋅Q 固定，Leeson corner 變成

與 SerDes 的關聯​

  • TX PLL 的 in-band（loop BW 內）就是 reference +20log⁡10N+20\log_{10}N+20log10​N——reference 的 close-in 決定 TX 時脈在 CDR tracking 頻寬邊緣的殘餘 jitter；完全在 CDR 頻寬內的部分會被 接收端追掉（serdes_clocking_connection）， 所以 SerDes 對 reference 的 L(10 Hz)\mathcal{L}(10\,\text{Hz})L(10Hz) 相對寬容、對 10 kHz–數 MHz 的「交接帶」敏感——恰好是例 1 交叉點（25.2 kHz）附近的戰場。
  • 無 CDR 追蹤的系統（ADC/DAC 取樣、雷達）沒這個豁免：aperture jitter 從低 offset 一路積上來， reference 的 close-in 直接進 SNR（adc_aperture_jitter）。
  • 慢軸也咬人：reference 的 ppm 偏移吃掉 CDR 的 pull-in/tracking range 與 SSC（spread-spectrum clocking）預算——這是第 7 步「兩條軸」在 SerDes 的具體化身。

重點回顧​

  • reference 是 low-offset 錨：in-band Lout=Lref+20log⁡10N\mathcal{L}_{out}=\mathcal{L}_{ref}+20\log_{10}NLout​=Lref​+20log10​N （clock_chain_budget 規則 3），鏈上任何元件都 救不了它的 close-in；worked chain 裡 65.9 % 的 jitter 功率來自 ref×N2\times N^2×N2 床。
  • crystal＝極端 QQQ 的 LC（BVD：Lm∼L_m\simLm​∼ mH、Cm∼C_m\simCm​∼ fF、Q∼104Q\sim10^4Q∼104–10610^6106， 產業慣例量級）；ISF 形狀照舊（Γ≈−sin⁡\Gamma\approx-\sinΓ≈−sin、Γrms=1/2\Gamma_{rms}=1/\sqrt2Γrms​=1/2​）， 優勢全從 QQQ（儲能對損耗）進帳。
  • 站內橋推出的 scaling：[P1] Eq.(21) ＋ 4kT/Rp4kT/R_p4kT/Rp​ ＋ QQQ 定義 ⇒ Llin=kT ω04EstoredQ Δω2=kTPdiss(ω02QΔω)2\mathcal{L}_{lin}=\dfrac{kT\,\omega_0}{4E_{stored}Q\,\Delta\omega^2}=\dfrac{kT}{P_{diss}}\big(\tfrac{\omega_0}{2Q\Delta\omega}\big)^2Llin​=4Estored​QΔω2kTω0​​=Pdiss​kT​(2QΔωω0​​)2； close-in L\mathcal{L}L 與 Lorentzian 線寬皆 ∝1/Q2\propto1/Q^2∝1/Q2；真正槓桿是 E⋅QE\cdot QE⋅Q 乘積 （crystal 例：7.96 nJ vs 0.507 pJ，E⋅QE\cdot QE⋅Q 差 79.0 dB、同 offset L\mathcal{L}L 差 95.9 dB）。
  • worked block：Q=5×104Q=5\times10^4Q=5×104@100 MHz vs Q=10Q=10Q=10@5 GHz——corner 1 kHz vs 250 MHz； 同 offset Leeson 項差 104.95 dB（1 kHz）、67.96 dB（100 kHz）；折算同載波（−33.98-33.98−33.98） 後仍贏 71.0／34.0 dB，但優勢隨 offset 縮水——far-out 要交還給 VCO。
  • 典型量級（產業慣例，外部）：XO floor −150…−165-150\ldots-165−150…−165、OCXO close-in 之王、 TCXO/OCXO 的階梯主要在慢軸（ppm）；floor 由 amp/buffer（kT/PkT/PkT/P 級）而非 QQQ 決定。
  • MEMS：f⋅Q∼1013f\cdot Q\sim10^{13}f⋅Q∼1013 Hz 量級蹺蹺板 ⇒ 輸出端 close-in ∝f02fout2\propto f_0^2f_{out}^2∝f02​fout2​ （共振器頻率降 10 倍淨賺 20 dB）⇒ MHz 共振器＋fractional-N PLL 的架構；in-band 是 PLL 床，買的是穩定度、抗震與可程式化。
  • 兩條 spec 軸：dBc/Hz（快軸，QQQ/PPP/amp 決定，鏈上修不了）與 ppm（慢軸， 補償/恆溫/馴服可修）；橋是 ADEV（allan_variance）。
