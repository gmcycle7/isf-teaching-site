自相關 → Wiener-Khinchin 嚴格推導

先備：white_noise_to_phase_noise（啟發式版 Eq.(19)→(20)→(21)、canonical 例 B）｜ 接下來：lorentzian_linewidth（把 ϕ˙\dot\phiϕ˙​ 白噪積成相位 random walk，Wiener-Khinchin 出 Lorentzian）

white_noise_to_phase_noise 那條「把白噪當成無數獨立小單音、算每根的 sideband 再求和」的路線是 [P1] 的原始路線， 物理直覺很強、但代數上是啟發式（heuristic）的：它在「白噪 === 單音疊加」「factor-8 記帳」 那幾步用了手算的功率簿記。這一頁把同一個結果用訊號與系統的嚴格機器重做一遍—— 直接寫下 LTV 輸出相位的時間平均自相關（time-averaged autocorrelation），用 ISF 的傅立葉 係數展開，讓 ∑cn2=2Γrms2\sum c_n^2=2\Gamma_{rms}^2∑cn2​=2Γrms2​ 自己從自相關裡掉出來，再用 Wiener-Khinchin 定理 取頻譜。讀者若熟悉「LTI 系統 Sy=∣H∣2SxS_y=|H|^2S_xSy​=∣H∣2Sx​」，這頁會把它升級成「LTV / cyclostationary」版本。

為什麼要做這頁：振盪器是週期時變（periodically time-varying）系統，它的輸出不是嚴格 平穩（stationary）而是 cyclostationary（週期穩態，統計量以週期 TTT 重複）。對 cyclostationary 過程，正確的譜分析要先對絕對時間 ttt 做一個週期平均，把它「平穩化」，再做 Wiener-Khinchin。 這一頁就是老實走完這條路；走完你會看到 Γrms\Gamma_{rms}Γrms​ 不是被「湊」出來的，而是自相關的週期平均 的必然產物。

第 A 步：寫下相位的雙時間自相關（two-time autocorrelation）​

ϕ˙(t)=g(t) in(t)=Γ(ω0t)qmax in(t).\dot\phi(t)=g(t)\,i_n(t)=\frac{\Gamma(\omega_0 t)}{q_{max}}\,i_n(t).ϕ˙​(t)=g(t)in​(t)=qmax​Γ(ω0​t)​in​(t).

第 B 步：對絕對時間做週期平均 → 把 cyclostationary 平穩化​

  • 用到的物理/數學：把絕對時間平均掉，等於把振盪器在一個週期內「各個相位的敏感度」平均起來—— 這正是 cyclostationary 系統「等效平穩化」的標準手法。

第 C 步：用 ISF 傅立葉係數展開 → ∑cn2=2Γrms2\sum c_n^2=2\Gamma_{rms}^2∑cn2​=2Γrms2​ 自然掉出來​

兩顆 2 的帳：第 A 步的 12\tfrac1221​（單邊 SiS_iSi​ → 雙邊位準 Si/2S_i/2Si​/2）與這裡的 222（雙邊 SϕDSS_\phi^{DS}SϕDS​ → 單邊 SϕS_\phiSϕ​）一進一出、剛好相消——「單邊輸入 PSD → 單邊輸出 PSD」的轉換增益裡不留任何 2； 只有在中途的自相關與雙邊譜上才看得到那顆 12\tfrac1221​。若把 SiS_iSi​ 誤當雙邊（寫成 R=SiδR=S_i\deltaR=Si​δ）又忘了 最後的摺疊，兩個錯會互相抵消而得到同一個答案，但中間每一條式子都差 2；若只犯其中一個， SϕS_\phiSϕ​ 差 2 倍（333 dB）。

於是單邊結果跟 white_noise_to_phase_noise「時域乾淨版」（factor-of-2 註記裡的） Sϕ=Γrms2Si/(qmax2(2πf)2)S_\phi=\Gamma_{rms}^2S_i/(q_{max}^2(2\pi f)^2)Sϕ​=Γrms2​Si​/(qmax2​(2πf)2) 逐字相同（Δω=2πf\Delta\omega=2\pi fΔω=2πf）。

  • 1/f21/f^21/f2 的嚴格出處：這條 1/Δω21/\Delta\omega^21/Δω2 完全來自「ϕ˙→ϕ\dot\phi\to\phiϕ˙​→ϕ 的那次積分」 （1/(jΔω)1/(j\Delta\omega)1/(jΔω) 濾波器），與 white_noise_to_phase_noise 開頭的物理直覺一字不差——只是現在是用 Wiener-Khinchin 嚴格證出來的，不是手算 sideband 湊出來的。
  • 白噪頻譜的角色：ϕ˙\dot\phiϕ˙​ 白、ϕ\phiϕ 才 1/f21/f^21/f2——這也解釋了為什麼相位是 random walk （白色頻率擾動的積分 === Wiener process），正是下一頁 Lorentzian 的起點。

數值驗證：直接量出那顆 12\tfrac1221​​

下面這段不畫圖，只做四件事：產生一筆單邊 PSD =Si=S_i=Si​ 的帶限白噪（取樣率 fsf_sfs​，頻寬 fs/2f_s/2fs​/2）， (1) 用 Welch 確認它的單邊 PSD 真的是 SiS_iSi​；(2) 數值算自相關、對 τ\tauτ 求面積 ∫R(τ)dτ≈∑kR[k] Δt\int R(\tau)d\tau\approx\sum_kR[k]\,\Delta t∫R(τ)dτ≈∑k​R[k]Δt——δ\deltaδ 的係數就是這個面積，應為 Si/2S_i/2Si​/2； (3) 乘上 ISF 權重 g(t)g(t)g(t) 得 ϕ˙\dot\phiϕ˙​，它的自相關面積就是雙邊 Sϕ˙DSS_{\dot\phi}^{DS}Sϕ˙​DS​； (4) 同一筆 ϕ˙\dot\phiϕ˙​ 的 Welch 單邊 PSD 應為雙邊的 2 倍。最後附 canonical 例 B 與第 C 步恆等式的數值。

import numpy as np
from simulations.common.isf_utils import gamma_lc_ideal
from simulations.common.noise_utils import white_noise, estimate_psd

F0 = 5e9
W0 = 2 * np.pi * F0
QMAX, SI, GRMS = 1e-12, 1e-24, 0.5        # canonical 參數
FS = 64 * F0                              # 取樣率：每週期 64 點（noise 頻寬 fs/2 = 160 GHz）
DT = 1 / FS
N = 2**20                                 # = 16384 個整數週期
rng = np.random.default_rng(12)

i_n = white_noise(N, SI, FS, rng)         # 單邊 PSD = S_i 的帶限白噪

# (1) Welch 單邊 PSD：確認輸入真的是「單邊 S_i」
f, pxx = estimate_psd(i_n, FS, nperseg=4096)
print(f"{np.mean(pxx[1:-1])/SI:.2f}")     # -> 1.00 (單邊 PSD / S_i)

# (2) 自相關面積 ∫R(τ)dτ ≈ Σ_k R[k]·dt：δ 的係數應為 S_i/2
K = 20
def acorr_area(x):
    r = [np.mean(x[:N - k] * x[k:]) for k in range(K + 1)]
    return (r[0] + 2 * sum(r[1:])) * DT

print(f"{acorr_area(i_n)/SI:.2f}")        # -> 0.50 (自相關面積 / S_i：就是那顆 1/2)

# (3) ISF 加權後的 φ̇ = g(t) i_n(t)：自相關面積 = 雙邊 S_φ̇ 位準
t = np.arange(N) * DT
g = np.sqrt(2.0) * GRMS * gamma_lc_ideal(W0 * t) / QMAX
phidot = g * i_n
s_ds = acorr_area(phidot)
print(f"{s_ds:.3f}")                      # -> 0.126 rad^2/s (雙邊 S_φ̇，理論 κ² = 0.125)
print(f"{s_ds/(GRMS**2*SI/QMAX**2):.2f}") # -> 0.50 (雙邊位準 / [Γrms² S_i/q_max²])

# (4) 同一筆 φ̇ 的 Welch 單邊 PSD（低頻平坦段）
f, pxx = estimate_psd(phidot, FS, nperseg=4096)
s_ss = np.mean(pxx[(f > 0) & (f < 0.4 * F0)])
print(f"{s_ss:.3f}")                      # -> 0.254 rad^2/s (單邊 S_φ̇，理論 0.25)
print(f"{s_ss/s_ds:.2f}")                 # -> 2.02 (單邊 / 雙邊，理論 2)

# (5) canonical 例 B：單邊 S_φ(1 MHz) 與兩個 L 家族
dw = 2 * np.pi * 1e6
s_phi = GRMS**2 * SI / (QMAX**2 * dw**2)
print(f"{s_phi:.3e}")                     # -> 6.333e-15 rad^2/Hz (單邊 S_φ @ 1 MHz)
print(f"{10*np.log10(s_phi/2):.1f}")      # -> -145.0 dBc/Hz (L = S_φ/2，「/2」家族)
print(f"{10*np.log10(s_phi/4):.1f}")      # -> -148.0 dBc/Hz ([P1] Eq.(21) 的「/4」家族)

# (6) 第 C 步的 DC 半權重恆等式：Γ = c0/2 + c1 cos x
x = np.linspace(0, 2 * np.pi, 100000, endpoint=False)
c0, c1 = 0.6, 1.0
gam = c0 / 2 + c1 * np.cos(x)
print(f"{np.mean(gam**2):.3f}")           # -> 0.590 (直接數值均方 Γrms²)
print(f"{0.5*(c0**2/2 + c1**2):.3f}")     # -> 0.590 ((1/2)[c0²/2 + c1²]：DC 半權重，吻合)
print(f"{0.5*(c0**2 + c1**2):.3f}")       # -> 0.680 ((1/2)[c0² + c1²]：DC 誤用整權，多出 c0²/4 = 0.09)
  • 怎麼讀：(1) 印 1.00、(2) 印 0.50——同一筆資料，單邊 PSD 是 SiS_iSi​、自相關的 δ\deltaδ 係數是 Si/2S_i/2Si​/2， 這就是第 A 步的 12\tfrac1221​。(3) 的 0.126 對上 κ2=0.125 rad2/s\kappa^2=0.125\ \text{rad}^2/\text{s}κ2=0.125 rad2/s（雙邊）； (4) 的 0.254 對上 0.250.250.25（單邊），比值 2.02 對上 2。(5) 的 −145.0-145.0−145.0 / −148.0-148.0−148.0 dBc/Hz 就是本站 canonical 的 「/2/2/2」與「/4/4/4」兩個家族——本頁的更動沒有改任何最終數字。
  • 誠實的限制：這是有限長度（2202^{20}220 點）的統計估計，(3)(4) 有約 1–2% 的取樣誤差（0.126、0.254、2.02 而非 0.125、0.250、2.00）；離散時間的「δ\deltaδ」是寬度 Δt\Delta tΔt 的一格，所以白噪只白到 fs/2=160f_s/2=160fs​/2=160 GHz（帶限）， 連續時間的理想白噪是 fs→∞f_s\to\inftyfs​→∞ 的極限。ϕ˙\dot\phiϕ˙​ 是 cyclostationary，Welch 對絕對時間的平均 扮演的正是第 B 步的週期平均；這裡只取 f<0.4f0f\lt0.4f_0f<0.4f0​ 的平坦段。這段檢查驗證的是記帳（單邊／雙邊的 2）， 不是電晶體層級的振盪器。

重點回顧​

  • 啟發式版（[P1] 原路線）靠「白噪 = 無數獨立單音」手算 sideband 功率再求和；嚴格版改走 「LTV 自相關 → cyclostationary 週期平均 → Wiener-Khinchin」三板斧，同一個結果機械化推出。
  • 振盪器輸出是 cyclostationary（統計量隨絕對時間 ttt 以週期 TTT 重複），不是嚴格平穩； 必須先對 ttt 做週期平均「平穩化」，才能套用 Wiener-Khinchin。
  • ∑cn2=2Γrms2\sum c_n^2=2\Gamma_{rms}^2∑cn2​=2Γrms2​ 不是外加代入的 Parseval 關係，而是週期平均積分 12π∫02πΓ2(x)dx\tfrac1{2\pi}\int_0^{2\pi}\Gamma^2(x)dx2π1​∫02π​Γ2(x)dx 的自然結果。
  • 單邊／雙邊的帳：SiS_iSi​ 是單邊 PSD，白噪自相關是 Si2δ(τ)\tfrac{S_i}{2}\delta(\tau)2Si​​δ(τ)；Wiener-Khinchin 給的是 雙邊 SϕDS=Γrms2Si/(2qmax2Δω2)S_\phi^{DS}=\Gamma_{rms}^2S_i/(2q_{max}^2\Delta\omega^2)SϕDS​=Γrms2​Si​/(2qmax2​Δω2)，單邊 Sϕ=2SϕDSS_\phi=2S_\phi^{DS}Sϕ​=2SϕDS​。
  • 單邊結果與啟發式版逐字相同：Sϕ(Δω)=Γrms2qmax2⋅SiΔω2S_\phi(\Delta\omega)=\dfrac{\Gamma_{rms}^2}{q_{max}^2}\cdot\dfrac{S_i}{\Delta\omega^2}Sϕ​(Δω)=qmax2​Γrms2​​⋅Δω2Si​​， 1/Δω21/\Delta\omega^21/Δω2 完全來自 ϕ˙→ϕ\dot\phi\to\phiϕ˙​→ϕ 的那次積分。
  • 本頁是 lorentzian_linewidth 的入口：那裡把同一套自相關機器 用在相位本身（而非 ϕ˙\dot\phiϕ˙​），解開 1/f21/f^21/f2 在載波處的假發散。
