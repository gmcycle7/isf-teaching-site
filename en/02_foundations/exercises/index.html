This page is the exercise set for Chapter 02 (Foundations). Problem types cover derivation problems (derive the expressions by hand), numerical problems (plug in numbers, carry the units, do the dimension check), and reverse-design problems (given a target spec, back-solve the required parameters).

How to use this page: work each problem yourself first, then expand the "Solution" to compare. Every solution follows the same format: step-by-step substitution (with units) → result → dimension check → one-line Python verification. All Python verifications call this site's real library simulations/common/ (no invented APIs), so you can paste them straight into a REPL.

Core formulas involved (all from the spec and this chapter's pages, using the same notation):

  • phase→time: Δt=Δϕ2πf0\Delta t=\dfrac{\Delta\phi}{2\pi f_0}Δt=2πf0​Δϕ​ (spec Eq. 17)
  • phase variance: σϕ2=∫f1f2Sϕ(f) df\sigma_\phi^2=\displaystyle\int_{f_1}^{f_2}S_\phi(f)\,dfσϕ2​=∫f1​f2​​Sϕ​(f)df (spec Eq. 18)
  • rms jitter: σt=12πf0∫f1f2Sϕ(f) df\sigma_t=\dfrac{1}{2\pi f_0}\sqrt{\displaystyle\int_{f_1}^{f_2}S_\phi(f)\,df}σt​=2πf0​1​∫f1​f2​​Sϕ​(f)df​ (spec Eq. 19)
  • SSB↔phase PSD (small-angle): L(Δf)≈12Sϕ(Δf)\mathcal{L}(\Delta f)\approx\tfrac12 S_\phi(\Delta f)L(Δf)≈21​Sϕ​(Δf) (spec Eq. 16)
  • Parseval: ∑n=0∞cn2=1π∫02π∣Γ(x)∣2dx=2 Γrms2\displaystyle\sum_{n=0}^{\infty}c_n^2=\frac{1}{\pi}\int_0^{2\pi}\lvert\Gamma(x)\rvert^2dx=2\,\Gamma_{rms}^2n=0∑∞​cn2​=π1​∫02π​∣Γ(x)∣2dx=2Γrms2​ ([P1] Eq.(20), p.185)
  • Lorentzian linewidth (FWHM): Δf3dB=Dπ\Delta f_{3\mathrm{dB}}=\dfrac{D}{\pi}Δf3dB​=πD​, phase diffusion Var⁡[Δϕ(t)]=2D∣t∣\operatorname{Var}[\Delta\phi(t)]=2D\lvert t\rvertVar[Δϕ(t)]=2D∣t∣ (spec §11.2; linked to [E2] Demir 2000, not among the 5 source PDFs)

Exercise 4 solution (phase variance from PSD integration)

σϕ2=∫f1f2Kf2 df=K[−1f]f1f2=K(1f1−1f2).\sigma_\phi^2=\int_{f_1}^{f_2}\frac{K}{f^2}\,df=K\left[-\frac1f\right]_{f_1}^{f_2}=K\left(\frac{1}{f_1}-\frac{1}{f_2}\right).σϕ2​=∫f1​f2​​f2K​df=K[−f1​]f1​f2​​=K(f1​1​−f2​1​).

σϕ2=10−4(1103−1106)=10−4×(10−3−10−6)=10−4×9.99×10−4=9.99×10−8 rad2.\sigma_\phi^2=10^{-4}\left(\frac{1}{10^3}-\frac{1}{10^6}\right)=10^{-4}\times(10^{-3}-10^{-6})=10^{-4}\times9.99\times10^{-4}=9.99\times10^{-8}\ \text{rad}^2.σϕ2​=10−4(1031​−1061​)=10−4×(10−3−10−6)=10−4×9.99×10−4=9.99×10−8 rad2.σϕ=9.99×10−8≈3.16×10−4 rad=0.316 mrad.\sigma_\phi=\sqrt{9.99\times10^{-8}}\approx3.16\times10^{-4}\ \text{rad}=0.316\ \text{mrad}.σϕ​=9.99×10−8​≈3.16×10−4 rad=0.316 mrad.

Result: σϕ2≈9.99×10−8 rad2\sigma_\phi^2\approx9.99\times10^{-8}\ \text{rad}^2σϕ2​≈9.99×10−8 rad2, σϕ≈0.316\sigma_\phi\approx0.316σϕ​≈0.316 mrad.

Exercise 5 solution (LTI vs LTV: same impulse, different phase)

Step-by-step substitution (with units). Using the operational ISF (spec Eq. 5) Δϕ=Γ(θ) Δq/qmax\Delta\phi=\Gamma(\theta)\,\Delta q/q_{max}Δϕ=Γ(θ)Δq/qmax​. Δq/qmax=10−15/10−12=10−3\Delta q/q_{max}=10^{-15}/10^{-12}=10^{-3}Δq/qmax​=10−15/10−12=10−3.

(a) Zero-crossing θ=π/2\theta=\pi/2θ=π/2 (Γ=−sin⁡(π/2)=−1\Gamma=-\sin(\pi/2)=-1Γ=−sin(π/2)=−1, maximum sensitivity):

Δϕa=(−1)×10−3=−1×10−3 rad=−1 mrad.\Delta\phi_a=(-1)\times10^{-3}=-1\times10^{-3}\ \text{rad}=-1\ \text{mrad}.Δϕa​=(−1)×10−3=−1×10−3 rad=−1 mrad.

(b) Peak θ=0\theta=0θ=0 (Γ=−sin⁡0=0\Gamma=-\sin 0=0Γ=−sin0=0, zero sensitivity):

Δϕb=0×10−3=0 rad.\Delta\phi_b=0\times10^{-3}=0\ \text{rad}.Δϕb​=0×10−3=0 rad.

Result: injection at the zero-crossing produces a phase step of ∣Δϕ∣=1\lvert\Delta\phi\rvert=1∣Δϕ∣=1 mrad; injection at the peak produces 0 phase step (there the charge only changes the amplitude, which is subsequently pulled back by amplitude restoring).

Why this is LTV, not LTI: the impulse response of an LTI (linear time-invariant) system depends only on the elapsed time t−τt-\taut−τ, not on the injection instant τ\tauτ. Here, however, the same Δq\Delta qΔq at θ=π/2\theta=\pi/2θ=π/2 versus θ=0\theta=0θ=0 produces completely different Δϕ\Delta\phiΔϕ — the response explicitly depends on the absolute injection phase Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ), which is precisely the defining signature of an LTV (linear time-varying) system (see lti_vs_ltv).

Dimension check: Γ\GammaΓ dimensionless × Δq/qmax\times\ \Delta q/q_{max}× Δq/qmax​ (C/C, dimensionless) === rad ✓.

Exercise 7 solution (reading Allan-deviation slopes)

Note: The Allan variance is external literature (Allan 1966), not among the 5 source PDFs; the slope table is taken verbatim from spec §11.2.

Slope reference (spec §11.2). On a log–log σy(τ)\sigma_y(\tau)σy​(τ) plot:

Measured slope σy(τ)∝τ?\sigma_y(\tau)\propto\tau^{?}σy​(τ)∝τ?Noise typePhysics
τ−1/2\tau^{-1/2}τ−1/2white FM (white frequency modulation)frequency is white noise → phase is a random walk; the longer you average, the more stable
τ0\tau^{0}τ0 (plateau/floor)flicker FM (1/f frequency)σy\sigma_yσy​ is independent of the gate time τ\tauτ → ADEV forms a flat floor
τ+1/2\tau^{+1/2}τ+1/2random-walk FM (random walk of frequency)the frequency itself drifts → the longer you average, the worse it gets; slope turns upward

Why flicker FM forms a plateau: substitute Sy(f)∝1/fS_y(f)\propto1/fSy​(f)∝1/f (flicker FM) into the spec §11.2 expression σy2(τ)=2∫0∞Sy(f)sin⁡4(πfτ)(πfτ)2 df\sigma_y^2(\tau)=2\displaystyle\int_0^\infty S_y(f)\dfrac{\sin^4(\pi f\tau)}{(\pi f\tau)^2}\,dfσy2​(τ)=2∫0∞​Sy​(f)(πfτ)2sin4(πfτ)​df and change variables to u=πfτu=\pi f\tauu=πfτ: τ\tauτ cancels completely out of the integrand — the integral becomes a pure numerical constant independent of τ\tauτ, so σy2(τ)=\sigma_y^2(\tau)=σy2​(τ)= constant ⇒σy(τ)∝τ0\Rightarrow\sigma_y(\tau)\propto\tau^0⇒σy​(τ)∝τ0, a horizontal line (floor) on the log–log plot. This floor is the signature long-term-stability feature of quartz/atomic clocks, marking the limit that no amount of extra averaging time can push down.

Result: τ−1/2→\tau^{-1/2}\toτ−1/2→ white FM, τ0→\tau^{0}\toτ0→ flicker FM (floor), τ+1/2→\tau^{+1/2}\toτ+1/2→ random-walk FM.

Dimension check: σy(τ)\sigma_y(\tau)σy​(τ) is the dimensionless fractional-frequency stability (y=Δf/f0y=\Delta f/f_0y=Δf/f0​); its power-law relationship with τ\tauτ only compares slopes and carries no dimension ✓.

Key takeaways​

  • phase↔time: Δt=Δϕ/(2πf0)\Delta t=\Delta\phi/(2\pi f_0)Δt=Δϕ/(2πf0​); rms version σt=σϕ/(2πf0)\sigma_t=\sigma_\phi/(2\pi f_0)σt​=σϕ​/(2πf0​) (Exercises 1, 2).
  • Parseval: ∑cn2=2Γrms2\sum c_n^2=2\Gamma_{rms}^2∑cn2​=2Γrms2​; for −sin⁡-\sin−sin, Γrms=1/2\Gamma_{rms}=1/\sqrt2Γrms​=1/2​ and ∑cn2=1\sum c_n^2=1∑cn2​=1 (Exercise 3).
  • PSD integration: in the 1/f21/f^21/f2 region σϕ2\sigma_\phi^2σϕ2​ is dominated by the low-frequency end; σϕ2=K(1/f1−1/f2)\sigma_\phi^2=K(1/f_1-1/f_2)σϕ2​=K(1/f1​−1/f2​) (Exercises 4, 8).
  • The essence of LTV: the response depends on the absolute injection phase; the same impulse at different phases gives different Δϕ\Delta\phiΔϕ (Exercise 5).
  • Lorentzian: D=πΔf3dBD=\pi\Delta f_{3\mathrm{dB}}D=πΔf3dB​, coherence time ∼1/(2D)\sim1/(2D)∼1/(2D) (Exercise 6, external literature).
  • Allan slopes: τ−1/2/τ0/τ+1/2→\tau^{-1/2}/\tau^0/\tau^{+1/2}\toτ−1/2/τ0/τ+1/2→ white/flicker/random-walk FM; flicker FM forms a floor (Exercise 7, external literature).
