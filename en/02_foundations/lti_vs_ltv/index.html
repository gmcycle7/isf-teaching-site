LTI vs LTV — an Oscillator's Noise Sensitivity Is Periodically Time-Varying

β: This English translation is in beta — the Traditional-Chinese original is the authoritative version.

Prerequisites: oscillator_phase · phase_vs_amplitude_noise | Next: From impulse to phase shift — the derivation

Signals-and-systems courses teach us to describe linear systems with an impulse response h(t)h(t)h(t) and convolution. But that is the LTI (Linear Time-Invariant) story. The single most important insight of Hajimiri–Lee in [P1] is:

An oscillator's phase response to noise is not LTI — it is LTV (Linear Time-Variant).

This page spells out how LTI and LTV differ, why an oscillator is necessarily LTV, and why this difference is exactly the reason the ISF (Impulse Sensitivity Function) exists.

Physical intuition (conclusion first): an LTI system "does not care what time it is" — the same impulse applied today or tomorrow produces exactly the same response shape, merely shifted in time. An oscillator is not like that: because its state keeps rotating around the limit cycle, the same noise current injected at the peak versus at a zero crossing produces completely different phase shifts. The system's sensitivity to the input itself varies periodically with time (with the injection phase) — this is "periodically time-varying sensitivity", and packaging it into a 2π2\pi2π-periodic, dimensionless function gives the ISF Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ).

1. Review: the LTI h(t−τ)h(t-\tau)h(t−τ)​

A linear time-invariant system has two properties: linearity (superposition holds) and time invariance (delay the input by Δ\DeltaΔ and the output is simply delayed by Δ\DeltaΔ, shape unchanged). The consequence of time invariance is that the impulse response depends only on the time difference t−τt-\taut−τ:

y(t)=∫−∞∞h(t−τ) x(τ) dτ(LTI convolution).y(t)=\int_{-\infty}^{\infty}h(t-\tau)\,x(\tau)\,d\tau\qquad\text{(LTI convolution)}.y(t)=∫−∞∞​h(t−τ)x(τ)dτ(LTI convolution).
  • Why only t−τt-\taut−τ: inject a unit impulse at τ1\tau_1τ1​ and you get h(t−τ1)h(t-\tau_1)h(t−τ1​); inject at τ2\tau_2τ2​ and you get h(t−τ2)h(t-\tau_2)h(t−τ2​) — the same shape, merely shifted. The system does not care about "the absolute time τ\tauτ", only about "how long ago".
  • Unit check: the dimension of the convolution kernel hhh is set by output/input; the point here is "shape invariance", not the numerical value.
  • This is the undergraduate story: RLC filters, small-signal amplifier equivalents — as long as the operating point is fixed, they are LTI.

2. The oscillator: the impulse response becomes h(t,τ)h(t,\tau)h(t,τ) — one extra independent variable​

An oscillator has no fixed operating point — its state keeps moving along the limit cycle (see oscillator_phase). So "how sensitive the system is to a perturbation right now" changes with the state (that is, with the injection phase ω0τ\omega_0\tauω0​τ). The impulse response therefore depends on two times at once:

  hϕ(t,τ)≠hϕ(t−τ)  (LTV: depends on the absolute injection time τ, not only t−τ).\boxed{\;h_\phi(t,\tau)\neq h_\phi(t-\tau)\;}\qquad\text{(LTV: depends on the absolute injection time }\tau\text{, not only }t-\tau\text{)}.hϕ​(t,τ)=hϕ​(t−τ)​(LTV: depends on the absolute injection time τ, not only t−τ).

The excess-phase impulse response [P1] writes down is exactly of this form ([P1] Eq.(10), p.182):

hϕ(t,τ)=Γ(ω0τ)qmax u(t−τ).h_\phi(t,\tau)=\frac{\Gamma(\omega_0\tau)}{q_{max}}\,u(t-\tau).hϕ​(t,τ)=qmax​Γ(ω0​τ)​u(t−τ).

Unpacking it, the two independent variables of the LTV response map neatly onto the two factors, each with a clear meaning:

  • Step height Γ(ω0τ)qmax\dfrac{\Gamma(\omega_0\tau)}{q_{max}}qmax​Γ(ω0​τ)​: depends only on the injection phase ω0τ\omega_0\tauω0​τ. This is the "time-varying" part — the same-size impulse jumps by a different height at a different injection phase.

  • Time shape u(t−τ)u(t-\tau)u(t−τ): a unit step, depending only on t−τt-\taut−τ. It encodes "once a phase shift occurs it is retained permanently" (phase has no restoring force; see phase_vs_amplitude_noise).

  • Unit check / dimension: Γ\GammaΓ is dimensionless, qmaxq_{max}qmax​ has units of C, uuu is dimensionless, so hϕh_\phihϕ​ has units of C−1\mathrm{C^{-1}}C−1; convolving with a current (A), ∫hϕ i dτ\int h_\phi\,i\,d\tau∫hϕ​idτ gives C−1⋅A⋅s=C−1⋅C=\mathrm{C^{-1}\cdot A\cdot s}=\mathrm{C^{-1}\cdot C}=C−1⋅A⋅s=C−1⋅C= dimensionless = rad ✓.

  • Why Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ) and not Γ(τ)\Gamma(\tau)Γ(τ): the sensitivity varies periodically with the "waveform phase", with period 2π2\pi2π (every lap around the limit cycle returns to the same sensitivity). So the argument of Γ\GammaΓ is the phase ω0τ\omega_0\tauω0​τ, and Γ\GammaΓ is a 2π2\pi2π-periodic function — this is "periodically time-varying sensitivity".

3. Why the same impulse produces different phase shifts at different positions​

Plug the step height of Step 2 into the operational ISF definition (the impulse limit of [P1] Eq.(11)):

Δϕ(τ)=Γ(ω0τ)qmax Δq.\Delta\phi(\tau)=\frac{\Gamma(\omega_0\tau)}{q_{max}}\,\Delta q.Δϕ(τ)=qmax​Γ(ω0​τ)​Δq.

Fix Δq\Delta qΔq and sweep the injection phase θ=ω0τ\theta=\omega_0\tauθ=ω0​τ: Δϕ\Delta\phiΔϕ rises and falls following the shape of Γ(θ)\Gamma(\theta)Γ(θ). For an ideal LC, Γ(θ)=−sin⁡θ\Gamma(\theta)=-\sin\thetaΓ(θ)=−sinθ:

  • Physical reason (continuing Step 4 of oscillator_phase): the size of the phase shift is set by the component of the voltage jump projected onto the tangential direction of the limit cycle. At a zero crossing the state velocity (tangent) lies exactly along the voltage axis, so a fixed ΔV\Delta VΔV turns almost entirely into tangential displacement → maximum Δϕ\Delta\phiΔϕ; at the peak the tangent is perpendicular to the voltage axis, so ΔV\Delta VΔV is almost entirely radial (pure amplitude) → Δϕ≈0\Delta\phi\approx 0Δϕ≈0. The tangential component is ∝sin⁡θ\propto\sin\theta∝sinθ, hence Γ(θ)=−sin⁡θ\Gamma(\theta)=-\sin\thetaΓ(θ)=−sinθ for a sinusoid.
  • This is the fingerprint of LTV: if the oscillator were LTI, Δϕ\Delta\phiΔϕ would be independent of τ\tauτ (only t−τt-\taut−τ would matter) — but in reality Δϕ(τ)\Delta\phi(\tau)Δϕ(τ) rises and falls periodically. The sensitivity itself varies with time = time-variant.

The lower half is the oscillator's LTV phase response hϕ(t,τ)h_\phi(t,\tau)hϕ​(t,τ): at different injection phases τ\tauτ, the step height Γ(ω0τ)=−sin⁡(2πτ)\Gamma(\omega_0\tau)=-\sin(2\pi\tau)Γ(ω0​τ)=−sin(2πτ) changes accordingly (it even flips sign).

How to read this figure:

  • Upper half (LTI): the three curves, overlaid, have exactly the same shape — only the starting points are shifted: "the system ignores absolute time".
  • Lower half (LTV): all three are steps (u(t−τ)u(t-\tau)u(t−τ), retained permanently), but the step heights differ: at τ=0\tau=0τ=0, Γ=−sin⁡0=0\Gamma=-\sin 0=0Γ=−sin0=0 (injected at the peak: 0 step height, no phase shift); at τ=0.25\tau=0.25τ=0.25, Γ=−sin⁡(π/2)=−1\Gamma=-\sin(\pi/2)=-1Γ=−sin(π/2)=−1 (injected at the zero crossing: maximum step height, negative); at τ=0.5\tau=0.5τ=0.5, Γ=−sin⁡(π)=0\Gamma=-\sin(\pi)=0Γ=−sin(π)=0 (injected at the trough: 0 step height).
  • Message: the LTV "shape" is fixed (always a step, because phase has no restoring force), but the "strength" is periodically time-varying — and that is exactly the ISF.

5. Why LTV is unavoidable — where the LTI model goes wrong​

Historically, treating oscillator noise as LTI (e.g., simply multiplying the noise by the tank transfer function) misses two things that only LTV/ISF can capture:

  1. Frequency translation: because the sensitivity Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ) is itself periodic (containing harmonics of ω0\omega_0ω0​), it mixes noise near 0, ω0, 2ω0,…0,\,\omega_0,\,2\omega_0,\dots0,ω0​,2ω0​,… down next to the carrier. LTI does not mix, and therefore cannot explain why device noise both at DC and at nω0n\omega_0nω0​ shows up in close-in phase noise. This is described by the Fourier coefficients cnc_ncn​ of the ISF ([P1] Eq.(12)–(13), p.183).
  2. 1/f1/f1/f upconversion into 1/f31/f^31/f3: the device's low-frequency 1/f1/f1/f noise reaches the vicinity of the carrier through the ISF's DC coefficient c0c_0c0​ ([P1] Eq.(23)); a purely LTI view cannot explain it. Waveform symmetry → small c0c_0c0​ → suppressed 1/f31/f^31/f3 corner ([P1] Eq.(24)).

In other words, LTV is not a gratuitous complication — the oscillator is physically time-varying; forcing an LTI model misses mixing and 1/f1/f1/f upconversion, two real phenomena, already at the qualitative level.

Key takeaways​

  • LTI: h(t−τ)h(t-\tau)h(t−τ) — only the time difference matters; changing the injection time merely shifts the response, shape unchanged.
  • LTV: hϕ(t,τ)=Γ(ω0τ)qmaxu(t−τ)h_\phi(t,\tau)=\dfrac{\Gamma(\omega_0\tau)}{q_{max}}u(t-\tau)hϕ​(t,τ)=qmax​Γ(ω0​τ)​u(t−τ) — the step height varies periodically with the injection phase ω0τ\omega_0\tauω0​τ; the time shape (a step) is fixed.
  • An oscillator is necessarily LTV: the state moves along the limit cycle → sensitivity varies with phase → same impulse, different position → different Δϕ\Delta\phiΔϕ.
  • The ISF Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ) is, in essence, "periodically time-varying sensitivity"; for the ideal LC it is −sin⁡θ-\sin\theta−sinθ.
  • Only LTV explains frequency translation (cnc_ncn​ mixing) and 1/f→1/f31/f\to1/f^31/f→1/f3 upconversion (c0c_0c0​); LTI misses both.
  • Example A: 1 fC injected at a zero crossing → 31.8 fs; at the peak → 0 fs (a direct consequence of periodically time-varying sensitivity).
  • Sources: [P1] Eq.(10), Eq.(11), Sec. III; numbers and figures from lab_04.
