Lorentzian Linewidth: Resolving the 1/f² Divergence Paradox at Δf→0

β: This English translation is in beta — the Traditional-Chinese original is the authoritative version.

Prerequisites: white_noise_to_phase_noise (the signature 1/f21/f^21/f2 result [P1] Eq.(21)), rms_isf (Γrms2/qmax2\Gamma_{rms}^2/q_{max}^2Γrms2​/qmax2​ sets the phase diffusion), stochastic_noise_basics (autocorrelation ↔ Wiener–Khinchin).

The previous page white_noise_to_phase_noise derived the signature result of oscillator phase noise, [P1] Eq.(21): the phase-noise skirt caused by white noise is

L{Δω}=10log⁡10 ⁣(Γrms2qmax2⋅in2‾/Δf4 Δω2).\mathcal{L}\{\Delta\omega\}=10\log_{10}\!\left(\frac{\Gamma_{rms}^2}{q_{max}^2}\cdot\frac{\overline{i_n^2}/\Delta f}{4\,\Delta\omega^2}\right).L{Δω}=10log10​(qmax2​Γrms2​​⋅4Δω2in2​​/Δf​).

The equation is beautiful, but it hides a disturbing mathematical pathology: the denominator contains Δω2\Delta\omega^2Δω2, so as the offset Δω→0\Delta\omega\to0Δω→0 (infinitely close to the carrier), the bracket →∞\to\infty→∞ and L→+∞\mathcal{L}\to+\inftyL→+∞. Read literally, the noise power density at the exact center of the carrier is infinite — which is obviously wrong: a real oscillator has finite total power (namely its output power) and cannot pack infinite power density into any single frequency.

This page resolves that paradox head-on. Conclusion first: 1/Δω21/\Delta\omega^21/Δω2 is the far-offset asymptote of the "phase linearization" approximation, not the truth near the carrier. Honestly account for the random-walk nature of the phase, and the carrier spectrum flattens near the carrier into a Lorentzian, with a finite peak, conserved total power, and a naturally defined finite 3-dB linewidth Δf3dB=D/π\Delta f_{3\mathrm{dB}}=D/\piΔf3dB​=D/π.

Physical intuition (conclusion first): white noise keeps kicking the phase, so ϕ(t)\phi(t)ϕ(t) does not settle at any value; like a drunkard's walk it random-walks without bound (a Wiener process). The phase variance grows linearly: Var[Δϕ]=2D∣t∣\mathrm{Var}[\Delta\phi]=2D|t|Var[Δϕ]=2D∣t∣. The carrier cos⁡(ω0t+ϕ)\cos(\omega_0t+\phi)cos(ω0​t+ϕ) therefore gradually loses memory: the longer the separation, the larger and less correlated the phase difference, so the autocorrelation Rx(τ)R_x(\tau)Rx​(τ) decays exponentially. The Fourier transform of an exponentially decaying autocorrelation is a Lorentzian — a bell-shaped line of finite height and finite width. 1/f21/f^21/f2 is merely the tail of this Lorentzian "far from center." Near the center it must flatten, because "complete phase amnesia" can at most spread the power flat — it can never make it diverge.

This page follows the complete step-by-step Lorentzian derivation of spec 11.2 throughout. The mechanism used here — "phase diffusion → exponential autocorrelation → Lorentzian" — is external literature, corresponding mainly to [E2] A. Demir, A. Mehrotra, and J. Roychowdhury, "Phase Noise in Oscillators: A Unifying Theory and Numerical Methods for Characterization," IEEE Trans. Circuits Syst. I, vol. 47, no. 5, pp. 655–674, May 2000 (DOI: 10.1109/81.847872), not among the 5 source PDFs downloaded on this site (volume/issue/pages/DOI verified; see [E2] in references). [P1] itself obtains 1/f21/f^21/f2 by linearization but never addresses the Δω→0\Delta\omega\to0Δω→0 divergence; the phase-diffusion model of Demir et al. is exactly the standard tool that fills that gap.

Step 0: The root of the problem — the phase is a random walk, not a fixed value​

Return to the phase integral of [P1] Eq.(11) (see convolution_derivation):

ϕ(t)=1qmax∫−∞tΓ(ω0τ) in(τ) dτ.\phi(t)=\frac{1}{q_{max}}\int_{-\infty}^{t}\Gamma(\omega_0\tau)\,i_n(\tau)\,d\tau .ϕ(t)=qmax​1​∫−∞t​Γ(ω0​τ)in​(τ)dτ.

The integral of white noise ini_nin​ is a Wiener process — a Brownian-motion-style random walk. Its key property: no restoring force (the phase is the Floquet λ1=0\lambda_1=0λ1​=0 neutral direction, see derivation_floquet_ppv), so the phase never returns to some equilibrium value; it diffuses without bound.

  • Mathematical signature: the variance of integrated white noise grows linearly with time (this is the defining property of a Wiener process). Write the proportionality constant as 2D2D2D:
Var⁡[Δϕ(t)]=⟨(ϕ(t+t0)−ϕ(t0))2⟩=2D ∣t∣.\operatorname{Var}[\Delta\phi(t)]=\big\langle(\phi(t+t_0)-\phi(t_0))^2\big\rangle=2D\,|t|.Var[Δϕ(t)]=⟨(ϕ(t+t0​)−ϕ(t0​))2⟩=2D∣t∣.

Here DDD is called the phase diffusion constant, in units of rad2/s\text{rad}^2/\text{s}rad2/s (spec 11.2). ∣t∣|t|∣t∣ carries an absolute value because the variance is the same looking forward or backward (stationary increments).

  • Unit check: [Var⁡Δϕ]=rad2[\operatorname{Var}\Delta\phi]=\text{rad}^2[VarΔϕ]=rad2; right-hand side [2D]⋅[t]=(rad2/s)⋅s=rad2[2D]\cdot[t]=(\text{rad}^2/\text{s})\cdot\text{s}=\text{rad}^2[2D]⋅[t]=(rad2/s)⋅s=rad2 ✓.

  • Why linear and not something else: white noise is uncorrelated across time; integrating NNN independent increments makes the variances add linearly, like "summing NNN dice rolls" (N∝tN\propto tN∝t) — this is the origin of the t\sqrt{t}t​ walk and the ttt variance, and it is exactly the same thing as σΔt∝Δt\sigma_{\Delta t}\propto\sqrt{\Delta t}σΔt​∝Δt​ in numerical_feeling (accumulated jitter is the time-domain version of the phase walk).

This step already exposes the seed of the paradox: the 1/f21/f^21/f2 derivation treats ϕ\phiϕ as "small, linearizable, bounded"; but the real ϕ\phiϕ is an unbounded walk. When you ask "what happens infinitely close to the carrier (Δω→0\Delta\omega\to0Δω→0, i.e., observing infinitely long, t→∞t\to\inftyt→∞)", ϕ\phiϕ has long since wandered to ≫1\gg 1≫1 rad and the linearization has broken down. So the divergence is not physics — it is an approximation used where it fails.

Step 1: Carrier autocorrelation — turning the phase walk into exponential decay via the Gaussian characteristic function​

Write the carrier as (the pure-phase version of [P1] Eq.(1); amplitude AAA held constant, phase only):

x(t)=Acos⁡(ω0t+ϕ(t)).x(t)=A\cos\big(\omega_0 t+\phi(t)\big).x(t)=Acos(ω0​t+ϕ(t)).

We want its autocorrelation function (the average product of the signal with itself delayed by τ\tauτ):

Rx(τ)=⟨x(t) x(t+τ)⟩.R_x(\tau)=\big\langle x(t)\,x(t+\tau)\big\rangle .Rx​(τ)=⟨x(t)x(t+τ)⟩.

Step (i): expand the two cosines with the product-to-sum identity. Let Δϕ≡ϕ(t+τ)−ϕ(t)\Delta\phi\equiv\phi(t+\tau)-\phi(t)Δϕ≡ϕ(t+τ)−ϕ(t):

x(t)x(t+τ)=A2cos⁡(ω0t+ϕ(t))cos⁡(ω0(t+τ)+ϕ(t+τ)).x(t)x(t+\tau)=A^2\cos(\omega_0t+\phi(t))\cos(\omega_0(t+\tau)+\phi(t+\tau)).x(t)x(t+τ)=A2cos(ω0​t+ϕ(t))cos(ω0​(t+τ)+ϕ(t+τ)).

Using cos⁡αcos⁡β=12[cos⁡(α−β)+cos⁡(α+β)]\cos\alpha\cos\beta=\tfrac12[\cos(\alpha-\beta)+\cos(\alpha+\beta)]cosαcosβ=21​[cos(α−β)+cos(α+β)]:

x(t)x(t+τ)=A22[cos⁡(ω0τ+Δϕ)+cos⁡(2ω0t+ω0τ+ϕ(t)+ϕ(t+τ))].x(t)x(t+\tau)=\frac{A^2}{2}\Big[\cos\big(\omega_0\tau+\Delta\phi\big)+\cos\big(2\omega_0t+\omega_0\tau+\phi(t)+\phi(t+\tau)\big)\Big].x(t)x(t+τ)=2A2​[cos(ω0​τ+Δϕ)+cos(2ω0​t+ω0​τ+ϕ(t)+ϕ(t+τ))].
  • The slow term cos⁡(ω0τ+Δϕ)\cos(\omega_0\tau+\Delta\phi)cos(ω0​τ+Δϕ) is independent of absolute time ttt (it contains only τ\tauτ and the phase difference) and survives the averaging.
  • The fast term contains 2ω0t2\omega_0t2ω0​t; time-averaging over ttt (or averaging over the random phase) kills it — it oscillates near 2ω02\omega_02ω0​ and is invisible to any long-term carrier average. Drop it.

Hence

Rx(τ)=A22⟨cos⁡(ω0τ+Δϕ)⟩.R_x(\tau)=\frac{A^2}{2}\big\langle\cos(\omega_0\tau+\Delta\phi)\big\rangle.Rx​(τ)=2A2​⟨cos(ω0​τ+Δϕ)⟩.

Step (ii): move the average inside using the Gaussian characteristic function. Expand cos⁡(ω0τ+Δϕ)=cos⁡ω0τcos⁡Δϕ−sin⁡ω0τsin⁡Δϕ\cos(\omega_0\tau+\Delta\phi)= \cos\omega_0\tau\cos\Delta\phi-\sin\omega_0\tau\sin\Delta\phicos(ω0​τ+Δϕ)=cosω0​τcosΔϕ−sinω0​τsinΔϕ. Δϕ\Delta\phiΔϕ is zero-mean Gaussian (integrated white noise → Gaussian; and the distribution is symmetric, so ⟨sin⁡Δϕ⟩=0\langle\sin\Delta\phi\rangle=0⟨sinΔϕ⟩=0):

Rx(τ)=A22[cos⁡ω0τ ⟨cos⁡Δϕ⟩−sin⁡ω0τ ⟨sin⁡Δϕ⟩⏟=0]=A22cos⁡ω0τ ⟨cos⁡Δϕ⟩.R_x(\tau)=\frac{A^2}{2}\Big[\cos\omega_0\tau\,\langle\cos\Delta\phi\rangle-\sin\omega_0\tau\,\underbrace{\langle\sin\Delta\phi\rangle}_{=0}\Big]=\frac{A^2}{2}\cos\omega_0\tau\,\langle\cos\Delta\phi\rangle.Rx​(τ)=2A2​[cosω0​τ⟨cosΔϕ⟩−sinω0​τ=0⟨sinΔϕ⟩​​]=2A2​cosω0​τ⟨cosΔϕ⟩.

The remaining ⟨cos⁡Δϕ⟩\langle\cos\Delta\phi\rangle⟨cosΔϕ⟩ uses the Gaussian characteristic function — for a zero-mean Gaussian variable Δϕ∼N(0,σ2)\Delta\phi\sim\mathcal{N}(0,\sigma^2)Δϕ∼N(0,σ2),

⟨ejΔϕ⟩=e−σ2/2⟹⟨cos⁡Δϕ⟩=Re⁡⟨ejΔϕ⟩=e−σ2/2.\big\langle e^{j\Delta\phi}\big\rangle=e^{-\sigma^2/2}\quad\Longrightarrow\quad\langle\cos\Delta\phi\rangle=\operatorname{Re}\big\langle e^{j\Delta\phi}\big\rangle=e^{-\sigma^2/2}.⟨ejΔϕ⟩=e−σ2/2⟹⟨cosΔϕ⟩=Re⟨ejΔϕ⟩=e−σ2/2.

This is the mathematical pivot of this page: for a Gaussian, "the average of a complex exponential" equals "e−12variancee^{-\tfrac12\text{variance}}e−21​variance". Substitute Step 0's σ2=Var⁡[Δϕ(τ)]=2D∣τ∣\sigma^2=\operatorname{Var}[\Delta\phi(\tau)]=2D|\tau|σ2=Var[Δϕ(τ)]=2D∣τ∣:

⟨cos⁡Δϕ⟩=e−12⋅2D∣τ∣=e−D∣τ∣.\langle\cos\Delta\phi\rangle=e^{-\tfrac12\cdot 2D|\tau|}=e^{-D|\tau|}.⟨cosΔϕ⟩=e−21​⋅2D∣τ∣=e−D∣τ∣.

Step (iii): combine to get the carrier autocorrelation (spec 11.2). Absorb A2A^2A2 into the normalization (adopting the unit-power convention A2/2→12A^2/2\to\tfrac12A2/2→21​, consistent with lab_18):

 Rx(τ)=12cos⁡(ω0τ) e−D∣τ∣ \boxed{\ R_x(\tau)=\frac{1}{2}\cos(\omega_0\tau)\,e^{-D|\tau|}\ } Rx​(τ)=21​cos(ω0​τ)e−D∣τ∣ ​
  • Physical meaning: cos⁡(ω0τ)\cos(\omega_0\tau)cos(ω0​τ) is the carrier's own oscillation; e−D∣τ∣e^{-D|\tau|}e−D∣τ∣ is the memory-loss envelope — the longer the separation, the more phase difference accumulates and the smaller ⟨cos⁡Δϕ⟩\langle\cos\Delta\phi\rangle⟨cosΔϕ⟩ gets: the autocorrelation decays exponentially. Larger DDD (fiercer noise) means faster memory loss.
  • Unit check: [D∣τ∣]=(rad2/s)⋅s=rad2[D|\tau|]=(\text{rad}^2/\text{s})\cdot\text{s}=\text{rad}^2[D∣τ∣]=(rad2/s)⋅s=rad2? — note that D∣τ∣D|\tau|D∣τ∣ appears in an exponent and must be dimensionless. The convention here treats the "rad2\text{rad}^2rad2" of DDD as dimensionless (phase is dimensionless radians to begin with), so DDD is effectively [1/s][1/\text{s}][1/s] and D∣τ∣D|\tau|D∣τ∣ is dimensionless ✓. RxR_xRx​ is dimensionless (power-normalized) ✓.
  • Connection to [P1]: [P1] never wrote this e−D∣τ∣e^{-D|\tau|}e−D∣τ∣; it stops at "phase small, linear." Once you admit the phase is an unbounded walk, this exponential decay is the only self-consistent outcome (the core of [E2] Demir 2000).

Step 2: Wiener-Khinchin — exponentially decaying autocorrelation ⇒ Lorentzian spectrum​

Wiener-Khinchin theorem: the power spectral density Sx(ω)S_x(\omega)Sx​(ω) of a stationary random process is the Fourier transform of its autocorrelation Rx(τ)R_x(\tau)Rx​(τ):

Sx(ω)=∫−∞∞Rx(τ) e−jωτ dτ.S_x(\omega)=\int_{-\infty}^{\infty}R_x(\tau)\,e^{-j\omega\tau}\,d\tau .Sx​(ω)=∫−∞∞​Rx​(τ)e−jωτdτ.

Substitute Step 1's Rx(τ)=12cos⁡(ω0τ)e−D∣τ∣R_x(\tau)=\tfrac12\cos(\omega_0\tau)e^{-D|\tau|}Rx​(τ)=21​cos(ω0​τ)e−D∣τ∣. Splitting cos⁡(ω0τ)=12(ejω0τ+e−jω0τ)\cos(\omega_0\tau)= \tfrac12(e^{j\omega_0\tau}+e^{-j\omega_0\tau})cos(ω0​τ)=21​(ejω0​τ+e−jω0​τ) gives two identical two-sided-exponential transforms, shifted to ±ω0\pm\omega_0±ω0​. We only need the branch around +ω0+\omega_0+ω0​ (near the positive-frequency carrier).

The standard transform used (Fourier transform of the two-sided exponential — the canonical Lorentzian pair):

∫−∞∞e−D∣τ∣ e−jΩτ dτ=2DD2+Ω2.\int_{-\infty}^{\infty}e^{-D|\tau|}\,e^{-j\Omega\tau}\,d\tau=\frac{2D}{D^2+\Omega^2}.∫−∞∞​e−D∣τ∣e−jΩτdτ=D2+Ω22D​.

Work it out by hand (split into the τ>0\tau>0τ>0 and τ<0\tau<0τ<0 halves):

∫−∞∞e−D∣τ∣e−jΩτdτ=∫0∞e−(D+jΩ)τdτ+∫0∞e−(D−jΩ)τdτ=1D+jΩ+1D−jΩ=(D−jΩ)+(D+jΩ)D2+Ω2=2DD2+Ω2.\begin{aligned} \int_{-\infty}^{\infty}e^{-D|\tau|}e^{-j\Omega\tau}d\tau &=\int_{0}^{\infty}e^{-(D+j\Omega)\tau}d\tau+\int_{0}^{\infty}e^{-(D-j\Omega)\tau}d\tau\\ &=\frac{1}{D+j\Omega}+\frac{1}{D-j\Omega}=\frac{(D-j\Omega)+(D+j\Omega)}{D^2+\Omega^2}=\frac{2D}{D^2+\Omega^2}. \end{aligned}∫−∞∞​e−D∣τ∣e−jΩτdτ​=∫0∞​e−(D+jΩ)τdτ+∫0∞​e−(D−jΩ)τdτ=D+jΩ1​+D−jΩ1​=D2+Ω2(D−jΩ)+(D+jΩ)​=D2+Ω22D​.​

Let the offset angular frequency near the carrier be Ω=ω−ω0≡Δω\Omega=\omega-\omega_0\equiv\Delta\omegaΩ=ω−ω0​≡Δω (absorbing the ejω0τe^{j\omega_0\tau}ejω0​τ branch of the cos⁡\coscos, which amounts to shifting the frequency origin to the carrier), and carry the RxR_xRx​ prefactor 12⋅12=14\tfrac12\cdot\tfrac12=\tfrac1421​⋅21​=41​:

 Sx(Δω)∝DD2+Δω2 (Lorentzian, spec 11.2).\boxed{\ S_x(\Delta\omega)\propto\frac{D}{D^2+\Delta\omega^2}\ }\qquad(\textbf{Lorentzian, spec 11.2}). Sx​(Δω)∝D2+Δω2D​ ​(Lorentzian, spec 11.2).
  • This is the Lorentzian: a bell-shaped line centered on the carrier, with a finite peak, symmetric left and right.
  • See how the divergence is gone: as Δω→0\Delta\omega\to0Δω→0, Sx→D/D2=1/DS_x\to D/D^2=1/DSx​→D/D2=1/D — finite! The peak is 1/D1/D1/D, not infinity. The divergence is cured.
  • Unit/shape check: the two denominator terms D2+Δω2D^2+\Delta\omega^2D2+Δω2 share the same dimension (both [s−2][\text{s}^{-2}][s−2]), so the shape of the ratio is correct; the overall constant is fixed by total-power normalization (see Step 4).

Why the far offset returns to 1/f21/f^21/f2 (consistent with [P1])​

When Δω≫D\Delta\omega\gg DΔω≫D (far enough from the carrier), the denominator D2+Δω2≈Δω2D^2+\Delta\omega^2\approx\Delta\omega^2D2+Δω2≈Δω2:

Sx(Δω)→Δω≫DDΔω2∝1Δω2.S_x(\Delta\omega)\xrightarrow[\Delta\omega\gg D]{}\frac{D}{\Delta\omega^2}\propto\frac{1}{\Delta\omega^2}.Sx​(Δω)Δω≫D​Δω2D​∝Δω21​.

The far-offset asymptote is exactly 1/f21/f^21/f2 — in full agreement with [P1] Eq.(21). So the Lorentzian does not overturn [P1]; it embeds [P1]'s 1/f21/f^21/f2 into a complete lineshape that flattens near the carrier: 1/f21/f^21/f2 far out, flat close in, with the corner at Δω≈D\Delta\omega\approx DΔω≈D. Step 3: 3-dB linewidth (FWHM) = D/π​

The Lorentzian's full width at half maximum (FWHM) is what engineers call the "3-dB linewidth" or simply the "linewidth." Find it: the peak at Δω=0\Delta\omega=0Δω=0 is D/D2=1/DD/D^2=1/DD/D2=1/D; at half maximum Sx=12⋅1DS_x=\tfrac12\cdot\tfrac1DSx​=21​⋅D1​:

DD2+Δω2=12D⟹D2+Δω2=2D2⟹Δω=±D.\frac{D}{D^2+\Delta\omega^2}=\frac{1}{2D}\quad\Longrightarrow\quad D^2+\Delta\omega^2=2D^2\quad\Longrightarrow\quad\Delta\omega=\pm D.D2+Δω2D​=2D1​⟹D2+Δω2=2D2⟹Δω=±D.

So the half-maximum points sit at Δω=±D\Delta\omega=\pm DΔω=±D (rad/s).

  • HWHM (half width): ΔωHWHM=D\Delta\omega_{\text{HWHM}}=DΔωHWHM​=D rad/s ⇒\Rightarrow⇒ ΔfHWHM=D2π\Delta f_{\text{HWHM}}=\dfrac{D}{2\pi}ΔfHWHM​=2πD​ Hz.
  • FWHM (3-dB full width): twice the HWHM, ΔωFWHM=2D\Delta\omega_{\text{FWHM}}=2DΔωFWHM​=2D rad/s ⇒\Rightarrow⇒
 Δf3dB=2D2π=Dπ Hz (spec 11.2).\boxed{\ \Delta f_{3\mathrm{dB}}=\frac{2D}{2\pi}=\frac{D}{\pi}\ \text{Hz}\ }\qquad(\textbf{spec 11.2}). Δf3dB​=2π2D​=πD​ Hz ​(spec 11.2).
  • Physical meaning: larger DDD (fiercer noise, faster phase amnesia) means a wider linewidth and a "fatter" carrier. An ideal noiseless oscillator has D→0D\to0D→0 → linewidth →0\to0→0 → it degenerates into a delta line (pure carrier).
  • Unit check: [D/π]=(1/s)/(dimensionless)=Hz[D/\pi]=(1/\text{s})/(\text{dimensionless})=\text{Hz}[D/π]=(1/s)/(dimensionless)=Hz ✓.
  • Where "3 dB" comes from: half height === half power =10log⁡10(1/2)=−3.01=10\log_{10}(1/2)=-3.01=10log10​(1/2)=−3.01 dB, hence "3-dB linewidth."

Step 4: Total power conservation — the Lorentzian flattens the infinity into a finite integral​

The most fatal consequence of the near-carrier 1/f21/f^21/f2 divergence: integrating 1/Δω21/\Delta\omega^21/Δω2 from 000 diverges (∫0d(Δω)/Δω2=∞\int_0 d(\Delta\omega)/\Delta\omega^2=\infty∫0​d(Δω)/Δω2=∞), which would say the phase-noise power is infinite. The Lorentzian cures this, because the Lorentzian's integral converges. Using the standard integral ∫−∞∞dΩD2+Ω2=πD\int_{-\infty}^{\infty}\dfrac{d\Omega}{D^2+\Omega^2}=\dfrac{\pi}{D}∫−∞∞​D2+Ω2dΩ​=Dπ​:

∫−∞∞DD2+Δω2 d(Δω)=D⋅πD=π(finite).\int_{-\infty}^{\infty}\frac{D}{D^2+\Delta\omega^2}\,d(\Delta\omega)=D\cdot\frac{\pi}{D}=\pi\quad(\text{finite}).∫−∞∞​D2+Δω2D​d(Δω)=D⋅Dπ​=π(finite).
  • Physical meaning: summing the power over all offsets gives a finite constant — exactly equal to the carrier's total power (after proper normalization). The phase walk merely smears the power originally concentrated in a delta line into a Lorentzian of finite width; no total power is lost (energy conservation). This is "total power conservation" (the key teaching point of spec 11.2).
  • Compare with the delta line: as D→0D\to0D→0 the Lorentzian →π δ(Δω)\to\pi\,\delta(\Delta\omega)→πδ(Δω) (infinitely tall and thin), degenerating back into the ideal carrier; for D>0D > 0D>0 it is flattened into a finite peak. The power never diverged — it was only redistributed.

The paradox resolved in one sentence: the 1/f21/f^21/f2 divergence is a "false divergence" — it comes from forcing the unbounded phase walk into a bounded linear approximation. The real spectrum must flatten into a Lorentzian near the carrier (peak =1/D=1/D=1/D, width =D/π=D/\pi=D/π, total power === carrier power, conserved). [P1] Eq.(21)'s 1/f21/f^21/f2 holds only for Δω≫D\Delta\omega\gg DΔω≫D; it is the Lorentzian's far tail.

Step 5: Connecting to the ISF — expressing D in terms of Γrms and qmax​

Now connect the abstract DDD back to [P1]'s ISF quantities. Matching "the two expressions for the near-carrier 1/f21/f^21/f2 skirt" pins down DDD.

From the Lorentzian side: far out, Sx→D/Δω2S_x\to D/\Delta\omega^2Sx​→D/Δω2. Write it as a phase PSD — the double-sided phase PSD of a Wiener phase (Var=2D∣t∣\mathrm{Var}=2D|t|Var=2D∣t∣) is 2D/Δω22D/\Delta\omega^22D/Δω2; this site keeps its books in single-sided PSD throughout (consistent with jitter_kernels), so

Model: a single spec point, L at 10 kHz (time-domain "/2" convention), is mapped to the near-carrier lineshape two ways. White FM(lorentzian_linewidth.md): unilateral S_phi = 4D / Delta-omega^2 fixes the phase diffusion constant D, giving an exact Lorentzian with FWHM = D/pi. Flicker FM(beyond_lorentzian.md Part A): b_-3 = S_phi times f_ref^3 fixes the 1/f^3 level; with a low-frequency cutoff f_l = 1/32 Hz (an observation-time artifact, not a device parameter — the page shows the dependence on f_l is only logarithmic), the frozen-log Gaussian-envelope approximation gives FWHM ≈ 2·sqrt(2 ln 2)·sqrt(b_-3 · L*) — an approximation the page itself quotes as roughly 2% off the exact numeric Fourier transform, not an exact result. Both curves are then convolved (direct 512-point discrete convolution, no FFT) with a Gaussian resolution-bandwidth kernel of FWHM = RBW to produce the "measured" trace. Toy/illustrative: real spectrum analyzers, cross-correlation instruments, and residual white-FM skirts (see beyond_lorentzian.md) all modify this picture further.

Core Python (full script: simulations/lab_18_lorentzian.py):

import numpy as np
from scipy.signal import welch

RNG = np.random.default_rng(18)
fs, n, f0, D = 4096.0, 2**20, 400.0, 2.0          # D = phase diffusion [rad^2/s]
t = np.arange(n) / fs

# Wiener phase: increments ~ N(0, 2 D dt) -> Var[phi(t)] = 2 D t
dphi = RNG.standard_normal(n) * np.sqrt(2 * D / fs)
phi = np.cumsum(dphi)
x = np.cos(2 * np.pi * f0 * t + phi)

f, P = welch(x, fs=fs, nperseg=2**16, scaling="density")   # spectrum: the carrier is a Lorentzian
off = f - f0
lor = D / (D**2 + (2 * np.pi * off)**2)                     # Lorentzian theory
fwhm = D / np.pi                                            # 3-dB linewidth = D/pi Hz

Key takeaways​

  • The 1/f21/f^21/f2 divergence at Δω→0\Delta\omega\to0Δω→0 is a false divergence: it comes from forcing an unbounded phase random walk into a linear approximation.
  • The phase is a Wiener process: Var⁡[Δϕ]=2D∣t∣\operatorname{Var}[\Delta\phi]=2D|t|Var[Δϕ]=2D∣t∣ (DDD = phase diffusion, rad2/s\text{rad}^2/\text{s}rad2/s).
