Lab 06 — White Noise → 1/f² Phase Noise

This lab runs the entire causal chain — white noise → ISF weighting → integration → phase — in the cleanest possible numerical form, so you can see with your own eyes how a flat (white, frequency-independent) current-noise power spectrum gets colored by the oscillator — a "phase integrator" — into 1/f21/f^21/f2 (−20-20−20 dB per decade) phase noise.

Physical intuition (conclusion first): the oscillator's phase has no restoring force (a force that pulls a perturbation back), so every phase step kicked in by noise accumulates permanently — this is an integrator (a system that time-integrates its input; infinite memory). The integrator's transfer-function magnitude is 1/(2πf)1/(2\pi f)1/(2πf), which is 1/(2πf)21/(2\pi f)^21/(2πf)2 for a PSD. The input is flat (white noise), so the output is multiplied by 1/f21/f^21/f2. White in, 1/f21/f^21/f2 out — not because the noise source is 1/f21/f^21/f2, but because phase is obtained by integration.

1. Learning objectives​

  • Verify by simulation the signature result of [P1]: white current noise becomes 1/f21/f^21/f2 phase noise in an oscillator.
  • Understand where the −20-20−20 dB/decade slope comes from (the integrator, not the noise source).
  • Quantitatively verify the theoretical prediction Sϕ(f)=Γrms2Si/(qmax2(2πf)2)S_\phi(f)=\Gamma_{rms}^2 S_i/(q_{max}^2(2\pi f)^2)Sϕ​(f)=Γrms2​Si​/(qmax2​(2πf)2).
  • Understand the famous factor-of-2 controversy: the clean time-domain derivation differs from [P1] Eq.(21) by a factor of 2, but the scaling and slope are entirely unaffected.

2. Mathematical model​

The phase response is the LTV (linear time-variant) convolution expression [P1] Eq.(11), p.182:

ϕ(t)=1qmax∫−∞tΓ(ω0τ) in(τ) dτ\phi(t)=\frac{1}{q_{max}}\int_{-\infty}^{t}\Gamma(\omega_0\tau)\,i_n(\tau)\,d\tauϕ(t)=qmax​1​∫−∞t​Γ(ω0​τ)in​(τ)dτ

Split it into three blocks: first phase-weight the noise with the ISF, then integrate. The input is white current noise with constant one-sided PSD (power spectral density) SiS_iSi​ (A2/A^2/A2/Hz).

Integrating the white input, the clean time-domain result for the output phase PSD is

Sϕ(f)=Γrms2 Siqmax2 (2πf)2.S_\phi(f)=\frac{\Gamma_{rms}^2\,S_i}{q_{max}^2\,(2\pi f)^2}.Sϕ​(f)=qmax2​(2πf)2Γrms2​Si​​.
  • Where it comes from: after the ISF weights the white noise, the average power is scaled by Γrms2\Gamma_{rms}^2Γrms2​ (the ISF's rms squared, see [P1] Eq.(20)), with qmax2q_{max}^2qmax2​ in the denominator (normalization); the integrator is then 1/(j2πf)1/(j2\pi f)1/(j2πf) in the frequency domain, i.e. 1/(2πf)21/(2\pi f)^21/(2πf)2 for the PSD.
  • Dimension check: Γrms2\Gamma_{rms}^2Γrms2​ is dimensionless, SiS_iSi​ is A2/A^2/A2/Hz, qmax2q_{max}^2qmax2​ is C2C^2C2, (2πf)2(2\pi f)^2(2πf)2 is (rad/s)2=s−2(\text{rad/s})^2=\text{s}^{-2}(rad/s)2=s−2. Overall =A2/HzC2⋅s−2=A2 s2C2⋅1Hz=\dfrac{A^2/\text{Hz}}{C^2\cdot\text{s}^{-2}}=\dfrac{A^2\,\text{s}^2}{C^2}\cdot\dfrac{1}{\text{Hz}}=C2⋅s−2A2/Hz​=C2A2s2​⋅Hz1​. Since C=A⋅sC=A\cdot sC=A⋅s, A2s2/C2=1A^2 s^2/C^2=1A2s2/C2=1 (dimensionless = rad²), so [Sϕ]=rad2/Hz[S_\phi]=\text{rad}^2/\text{Hz}[Sϕ​]=rad2/Hz ✓.

This has the same scaling as the signature expression [P1] Eq.(21), p.185:

L{Δω}=10log⁡10 ⁣(Γrms2qmax2⋅in2‾/Δf4 Δω2)\mathcal{L}\{\Delta\omega\}=10\log_{10}\!\left(\frac{\Gamma_{rms}^2}{q_{max}^2}\cdot\frac{\overline{i_n^2}/\Delta f}{4\,\Delta\omega^2}\right)L{Δω}=10log10​(qmax2​Γrms2​​⋅4Δω2in2​​/Δf​)

factor-of-2 teaching note (must read): the clean time-domain derivation "white noise × ISF → integrate" gives Sϕ=Γrms2Si/(qmax2(2πf)2)S_\phi=\Gamma_{rms}^2 S_i/(q_{max}^2(2\pi f)^2)Sϕ​=Γrms2​Si​/(qmax2​(2πf)2), corresponding to SSB L=Γrms2Si/(2qmax2Δω2)\mathcal{L}=\Gamma_{rms}^2 S_i/(2q_{max}^2\Delta\omega^2)L=Γrms2​Si​/(2qmax2​Δω2) (denominator 222); whereas [P1] Eq.(21) is written with denominator 4Δω24\Delta\omega^24Δω2. This factor of 2 comes from the SSB (single-sideband) bookkeeping convention — a famous minor controversy in the literature. It does not affect the Γrms2/qmax2\Gamma_{rms}^2/q_{max}^2Γrms2​/qmax2​ scaling, nor the −20-20−20 dB/decade slope — those are the physics. The simulation in this lab uses the clean time-domain version (denominator (2πf)2(2\pi f)^2(2πf)2), so the simulated curve sits on the time-domain theory line. See white_noise_to_phase_noise.

4. Core Python code​

Verbatim from main() in simulations/lab_06_white_noise_phase_noise.py: three steps (generate white noise → ISF weighting → cumsum integration), then Welch-estimate the phase PSD and overlay the theory line.

f0 = 1.0
fs = 256.0                 # 256 samples per period
n = 2 ** 20                # ~4096 periods -> good low-freq resolution
t = np.arange(n) / fs

q_max = 1.0
S_i = 1.0e-4               # one-sided white current PSD [A^2/Hz] (normalized)

# ISF and its rms
theta_grid = np.linspace(0, 2 * np.pi, 4000, endpoint=True)
Grms = gamma_rms(theta_grid, gamma_lc_ideal(theta_grid))  # = 1/sqrt(2)

# 1) white current noise
i_n = white_noise(n, psd=S_i, fs=fs, rng=RNG)
# 2) ISF weighting
g = gamma_lc_ideal(2 * np.pi * f0 * t) * i_n / q_max
# 3) integrate (cumulative) -> excess phase
dt = 1.0 / fs
phi = np.cumsum(g) * dt
phi = phi - np.mean(phi)   # remove the random-walk DC offset for PSD est.

# 4) estimate phase PSD
f, Sphi = estimate_psd(phi, fs, nperseg=2 ** 16)

# theory line
Sphi_theory = Grms ** 2 * S_i / (q_max ** 2 * (2 * np.pi * f) ** 2)
  • Step 3, np.cumsum(g) * dt, discretizes the ∫dτ\int d\tau∫dτ in the convolution expression — the cumulative sum is the integrator, i.e. the source of the phase's "infinite memory".
  • The ISF is the ideal-LC gamma_lc_ideal (Γ(θ)=−sin⁡θ\Gamma(\theta)=-\sin\thetaΓ(θ)=−sinθ), whose Γrms=1/2≈0.707\Gamma_{rms}=1/\sqrt2\approx0.707Γrms​=1/2​≈0.707 (because ⟨sin⁡2⟩=1/2\langle\sin^2\rangle=1/2⟨sin2⟩=1/2).

9. How to read the figure​

  • Blue line (simulated SϕS_\phiSϕ​): the PSD actually estimated from the simulated phase sequence. On log–log it is a straight line of slope −2-2−2 (dropping 202020 dB per decade), with the random fluctuations of a Welch estimate.
  • Black dashed line (theory): the analytic line Γrms2Si/(qmax2(2πf)2)\Gamma_{rms}^2 S_i/(q_{max}^2(2\pi f)^2)Γrms2​Si​/(qmax2​(2πf)2). The blue line hugs the black one — this is "white noise → 1/f21/f^21/f2" confirmed numerically.
  • Red dotted line (−20-20−20 dB/dec guide): a pure slope reference confirming the slope is exactly −2-2−2.
  • Key point: the input is flat (SiS_iSi​ independent of fff), yet the output is 1/f21/f^21/f2. The extra 1/f21/f^21/f2 comes entirely from the integrator in step 3. Swapping in a different ISF shape only changes Γrms\Gamma_{rms}Γrms​ (shifting the whole line up or down); the slope is always −2-2−2. The height of the whole line is set by Γrms2/qmax2\Gamma_{rms}^2/q_{max}^2Γrms2​/qmax2​, so enlarging qmaxq_{max}qmax​ (tank swing) is the main knob for lowering 1/f21/f^21/f2 phase noise (design usage in tank_swing).

11. Limitations and approximations​

  • This is a pedagogical toy model, not transistor-level: the ISF is the analytic −sin⁡θ-\sin\theta−sinθ (ideal LC), not extracted from a real circuit. qmax=1q_{max}=1qmax​=1, f0=1f_0=1f0​=1 are normalized units, so there is no absolute dBc/Hz (for absolute values see lab_08 and numerical_feeling example B).
  • Single white-noise source, stationary assumption: real circuits have multiple sources and are cyclostationary (noise intensity varies periodically with the operating point); the correction is Γeff=Γ⋅α\Gamma_{eff}=\Gamma\cdot\alphaΓeff​=Γ⋅α (see effective_isf).
  • Small-angle approximation: phase is treated as linearly superposable and small; for large phase excursions L≈12Sϕ\mathcal{L}\approx\frac12 S_\phiL≈21​Sϕ​ breaks down.
  • factor-of-2: the simulation agrees with the time-domain theory line (denominator (2πf)2(2\pi f)^2(2πf)2) and differs from the 4Δω24\Delta\omega^24Δω2 of [P1] Eq.(21) by the SSB-bookkeeping factor of 2 — slope and scaling unaffected.
  • Numerical limits: the low-frequency end is limited by the total simulated time (≈4096\approx4096≈4096 periods) and nperseg; the leftmost few points have larger statistical scatter, and the plot shows only the trustworthy region f>0.02f>0.02f>0.02.

Key takeaways​

  • White noise (flat) → ISF weighting (scale by Γrms2/qmax2\Gamma_{rms}^2/q_{max}^2Γrms2​/qmax2​) → integrator (multiply by 1/(2πf)21/(2\pi f)^21/(2πf)2) → 1/f21/f^21/f2 phase noise.
  • The −20-20−20 dB/decade slope comes from the integrator, independent of the noise source's spectral shape.
  • The simulated PSD hugs the theory line Γrms2Si/(qmax2(2πf)2)\Gamma_{rms}^2 S_i/(q_{max}^2(2\pi f)^2)Γrms2​Si​/(qmax2​(2πf)2).
  • The factor-of-2 is an SSB bookkeeping-convention difference; it changes neither the scaling nor the slope.
