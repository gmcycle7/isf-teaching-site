Lab 07 — 1/f Noise Upconversion and ISF Symmetry

This lab answers the most profitable question in oscillator design: why do some oscillators have terrible close-in phase noise (a steep 1/f31/f^31/f3) while others are clean? The answer lies not in the noise source but in the waveform's symmetry — specifically, in the ISF's DC Fourier coefficient c0c_0c0​.

Physical intuition (conclusion first): the device's 1/f1/f1/f (flicker) noise is concentrated at very low frequencies (near DC). Whether it can "upconvert" (get moved next to the carrier and become phase noise) depends on whether the ISF has a DC component. The ISF's DC value is c0/2c_0/2c0​/2. If the waveform is perfectly symmetric (rise and fall mirror-symmetric), c0=0c_0=0c0​=0: near-DC 1/f1/f1/f noise, multiplied by an ISF that "averages to zero", cancels and does not upconvert; if the waveform is asymmetric, c0≠0c_0\neq0c0​=0: the near-DC noise survives, and the integrator then colors it into a steep, tall 1/f31/f^31/f3. Symmetry is a free lunch: making the waveform symmetric cuts 1/f31/f^31/f3 phase noise for free.

1. Learning objectives​

  • Understand how device 1/f1/f1/f noise "upconverts" into close-in phase noise.
  • Compare, by simulation, the close-in behavior of a symmetric ISF (c0=0c_0=0c0​=0) and an asymmetric ISF (c0≠0c_0\neq0c0​=0).
  • Confirm with your own eyes: c0=0c_0=0c0​=0 → close-in 1/f31/f^31/f3 suppressed; c0≠0c_0\neq0c0​=0 → a steep 1/f31/f^31/f3 appears.
  • Connect this phenomenon to [P1] Eq.(23) (the 1/f31/f^31/f3 expression) and Eq.(24) (the 1/f31/f^31/f3 corner).

2. Mathematical model​

The one-sided PSD of device flicker current noise has a 1/f1/f1/f shape ([P1] Eq.(22), p.185):

in,1/f2‾=in2‾⋅ω1/fΔω\overline{i_{n,1/f}^2}=\overline{i_n^2}\cdot\frac{\omega_{1/f}}{\Delta\omega}in,1/f2​​=in2​​⋅Δωω1/f​​
  • Meaning: ω1/f\omega_{1/f}ω1/f​ is the device's 1/f1/f1/f corner (corner frequency); below it the noise goes as 1/f1/f1/f, above it the noise approaches white.
  • Units: in2‾\overline{i_n^2}in2​​ is A2/A^2/A2/Hz; ω1/f/Δω\omega_{1/f}/\Delta\omegaω1/f​/Δω is dimensionless, so the whole expression is still A2/A^2/A2/Hz ✓.

Feeding this 1/f1/f1/f noise into the ISF's DC channel and integrating gives the close-in phase noise ([P1] Eq.(23), p.185):

L{Δω}=10log⁡10 ⁣(c02qmax2⋅in2‾/Δf8 Δω2⋅ω1/fΔω)\mathcal{L}\{\Delta\omega\}=10\log_{10}\!\left(\frac{c_0^2}{q_{max}^2}\cdot\frac{\overline{i_n^2}/\Delta f}{8\,\Delta\omega^2}\cdot\frac{\omega_{1/f}}{\Delta\omega}\right)L{Δω}=10log10​(qmax2​c02​​⋅8Δω2in2​​/Δf​⋅Δωω1/f​​)
  • Where the slope comes from: 1Δω2\frac{1}{\Delta\omega^2}Δω21​ (integrator, −20-20−20 dB/dec) ×1Δω\times\frac{1}{\Delta\omega}×Δω1​ (1/f1/f1/f noise source, −10-10−10 dB/dec) =1Δω3=\frac{1}{\Delta\omega^3}=Δω31​, i.e. 1/f31/f^31/f3 (−30-30−30 dB/dec).
  • c0c_0c0​ is the switch: the whole expression is multiplied by c02c_0^2c02​. c0=0c_0=0c0​=0 → this 1/f31/f^31/f3 term vanishes (is suppressed), and close-in falls back to white-noise-dominated 1/f21/f^21/f2; c0≠0c_0\neq0c0​=0 → 1/f31/f^31/f3 appears with height proportional to c02c_0^2c02​.

The corner frequency where the 1/f31/f^31/f3 and 1/f21/f^21/f2 segments intersect ([P1] Eq.(24), p.185):

Δω1/f3=ω1/f⋅c022 Γrms2≈ω1/f(c0c1)2\Delta\omega_{1/f^3}=\omega_{1/f}\cdot\frac{c_0^2}{2\,\Gamma_{rms}^2}\approx\omega_{1/f}\left(\frac{c_0}{c_1}\right)^2Δω1/f3​=ω1/f​⋅2Γrms2​c02​​≈ω1/f​(c1​c0​​)2
  • Design implication: shrink c0c_0c0​ (waveform asymmetry) and the corner moves left — the close-in 1/f31/f^31/f3 region narrows.
  • Notation trap: c0c_0c0​ is a Fourier coefficient; the ISF's DC value is c0/2c_0/2c0​/2 (see notation).

In this lab's toy formulation, the asymmetric ISF is gamma_asym = cos(theta) + 0.5, DC value =0.5=0.5=0.5, corresponding to c0=1.0c_0=1.0c0​=1.0; the symmetric ISF is gamma_sym = cos(theta), DC value =0=0=0, c0=0c_0=0c0​=0. Using cos instead of the LC's −sin⁡-\sin−sin simply makes the "symmetric basis + DC shift" contrast more intuitive; both are toys.

4. Core Python code​

Verbatim from simulations/lab_07_flicker_noise.py: the same flicker-noise record passes separately through the symmetric and asymmetric ISFs, then each is integrated and its PSD estimated. Note that phase_from_isf is exactly "ISF weighting → cumsum integration".

def phase_from_isf(i_n, gamma_vals, q_max, fs):
    g = gamma_vals * i_n / q_max
    phi = np.cumsum(g) / fs
    return phi - np.mean(phi)


def main():
    f0 = 1.0
    fs = 256.0
    n = 2 ** 20
    t = np.arange(n) / fs
    q_max = 1.0

    theta = 2 * np.pi * f0 * t
    gamma_sym = np.cos(theta)            # c0 = 0
    gamma_asym = np.cos(theta) + 0.5     # c0 = 1.0 (DC = 0.5)

    i_flicker = flicker_noise(n, fs, k_flicker=1e-4, rng=RNG)

    phi_sym = phase_from_isf(i_flicker, gamma_sym, q_max, fs)
    phi_asym = phase_from_isf(i_flicker, gamma_asym, q_max, fs)

    f, S_sym = estimate_psd(phi_sym, fs, nperseg=2 ** 16)
    _, S_asym = estimate_psd(phi_asym, fs, nperseg=2 ** 16)
  • The only difference between the two ISFs is that + 0.5 (DC shift). Everything else is identical — so any difference between the two output PSDs can only come from c0c_0c0​. This turns "is c0c_0c0​ the switch for 1/f31/f^31/f3?" into a controlled experiment.

9. How to read the figure​

  • Red line (asymmetric, c0≠0c_0\neq0c0​=0): in the close-in (low-offset) region a tall, steep curve appears, with slope near −30-30−30 dB/dec (1/f31/f^31/f3). The black dotted line is a pure 1/f31/f^31/f3 slope reference; the red line hugs it.
  • Green line (symmetric, c0=0c_0=0c0​=0): clearly much lower in the close-in region, with a gentler slope (near 1/f21/f^21/f2, gray dashed reference). 1/f31/f^31/f3 is suppressed — visual proof that "waveform symmetry cuts close-in noise for free".
  • The two lines converge at higher offsets: far from the carrier, the gap between 1/f31/f^31/f3 and 1/f21/f^21/f2 shrinks, because flicker noise itself is already weak at high frequency.
  • Key point: the only difference between the two ISFs is c0c_0c0​. The huge close-in gap between red and green is caused entirely by c0c_0c0​. As c0→0c_0\to0c0​→0, the red line collapses onto the green one.

11. Limitations and approximations​

  • Pedagogical toy model, not transistor-level: the two ISFs (cos, cos+0.5) are teaching toys, not extracted from real circuits. The +0.5 is an artificially set c0c_0c0​, purely for a controlled comparison.
  • Normalized units: f0=1f_0=1f0​=1, qmax=1q_{max}=1qmax​=1, k_flicker on an arbitrary scale — no absolute dBc/Hz. The relative shape of the curves (slopes, red–green gap) is the teaching point.
  • Flicker generation is approximate: flicker_noise uses frequency-domain 1/f1/\sqrt f1/f​ shaping and relies on f_low to tame the divergent DC bin; accuracy at very low frequency is limited by f_low and the total record length.
  • Stationary-noise assumption: real flicker upconversion also involves cyclostationary modulation (the device leaks noise only while conducting); the full treatment uses Γeff=Γ⋅α\Gamma_{eff}=\Gamma\cdot\alphaΓeff​=Γ⋅α (see effective_isf); this lab demonstrates only the c0c_0c0​ mechanism.
  • Welch low-frequency scatter: the close-in region has few points and large statistical scatter; the plot shows only the trustworthy segment f>0.02f>0.02f>0.02.

Key takeaways​

  • Device 1/f1/f1/f noise is concentrated near DC; whether it upconverts into phase noise is determined by the ISF's DC component (c0/2c_0/2c0​/2).
  • c0≠0c_0\neq0c0​=0 → close-in 1/f31/f^31/f3 (−30-30−30 dB/dec); c0=0c_0=0c0​=0 → suppressed, falls back to 1/f21/f^21/f2.
  • The 1/f31/f^31/f3 height is proportional to c02c_0^2c02​; the corner ∝c02/Γrms2\propto c_0^2/\Gamma_{rms}^2∝c02​/Γrms2​.
  • Design lesson: making the waveform symmetric (suppressing c0c_0c0​) is a free way to lower close-in phase noise.
