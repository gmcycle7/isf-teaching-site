Lab 08 — rms Jitter by Integrating L(f)

This lab turns something you see on every datasheet — the single-sideband phase-noise curve L(f)\mathcal{L}(f)L(f) (dBc/Hz) — into the number designers actually care about: rms timing jitter σt\sigma_tσt​. We use a canonical scenario (f0=5f_0=5f0​=5 GHz, L(1MHz)=−100\mathcal{L}(1\text{MHz})=-100L(1MHz)=−100 dBc/Hz, 1/f21/f^21/f2 slope, integrated 1→100 MHz) and make the numerical integration and the analytic closed form agree digit by digit: σt=447.9\sigma_t=447.9σt​=447.9 fs.

Physical intuition (conclusion first): phase noise is "how much phase power density sits at each offset frequency"; jitter is "add it all up, take the square root, convert to time". So going from L(f)\mathcal{L}(f)L(f) to σt\sigma_tσt​ is three things: (1) convert dBc/Hz back to linear and multiply by 2 to recover SϕS_\phiSϕ​; (2) integrate over offset frequency to get the phase variance; (3) take the square root and divide by 2πf02\pi f_02πf0​ to convert to time. For a 1/f21/f^21/f2 shape, the integral is dominated by the lower limit f1f_1f1​ — "where you start integrating" matters far more than "how high you go".

1. Learning objectives​

  • Convert L(f)\mathcal{L}(f)L(f) (dBc/Hz) step by step into rms phase σϕ\sigma_\phiσϕ​ and rms jitter σt\sigma_tσt​.
  • Build a feel for the 5 GHz conversion: −100-100−100 dBc/Hz @ 1 MHz, 1/f21/f^21/f2, integrated 1→100 MHz → about 448 fs.
  • Verify numerical integration = analytic closed form (1/f21/f^21/f2 has a closed form).
  • Understand why 1/f21/f^21/f2 jitter is dominated by the lower integration limit.

2. Mathematical model​

Step 1: L\mathcal{L}L → SϕS_\phiSϕ​. Under the small-angle / single-sideband approximation (canonical formula 16):

L(Δf)≈12Sϕ(Δf)  ⇒  Sϕ(f)=2⋅10L(f)/10.\mathcal{L}(\Delta f)\approx\tfrac12 S_\phi(\Delta f)\;\Rightarrow\;S_\phi(f)=2\cdot10^{\mathcal{L}(f)/10}.L(Δf)≈21​Sϕ​(Δf)⇒Sϕ​(f)=2⋅10L(f)/10.

Step 2: write the 1/f21/f^21/f2 shape (anchored at fref=1f_{ref}=1fref​=1 MHz, canonical example C):

Sϕ(f)=Sϕ(fref)(freff)2.S_\phi(f)=S_\phi(f_{ref})\left(\frac{f_{ref}}{f}\right)^2.Sϕ​(f)=Sϕ​(fref​)(ffref​​)2.

Step 3: integrate to get the phase variance (canonical formula 18):

σϕ2=∫f1f2Sϕ(f) df.\sigma_\phi^2=\int_{f_1}^{f_2}S_\phi(f)\,df.σϕ2​=∫f1​f2​​Sϕ​(f)df.

For the 1/f21/f^21/f2 shape this integral has a closed form (∫f−2df=−1/f\int f^{-2}df=-1/f∫f−2df=−1/f):

σϕ2=Sϕ(fref) fref2 ⁣∫f1f2dff2=Sϕ(fref) fref2(1f1−1f2).\sigma_\phi^2=S_\phi(f_{ref})\,f_{ref}^2\!\int_{f_1}^{f_2}\frac{df}{f^2}=S_\phi(f_{ref})\,f_{ref}^2\left(\frac{1}{f_1}-\frac{1}{f_2}\right).σϕ2​=Sϕ​(fref​)fref2​∫f1​f2​​f2df​=Sϕ​(fref​)fref2​(f1​1​−f2​1​).

Step 4: convert to rms jitter (canonical formula 19):

σt=σϕ2πf0=12πf0∫f1f2Sϕ(f) df.\sigma_t=\frac{\sigma_\phi}{2\pi f_0}=\frac{1}{2\pi f_0}\sqrt{\int_{f_1}^{f_2}S_\phi(f)\,df}.σt​=2πf0​σϕ​​=2πf0​1​∫f1​f2​​Sϕ​(f)df​.
  • Dimension check (step 4): σϕ\sigma_\phiσϕ​ is rad, 2πf02\pi f_02πf0​ is rad/s, [rad]/[rad/s]=[s][\text{rad}]/[\text{rad/s}]=[\text{s}][rad]/[rad/s]=[s] ✓.
  • Lower-limit dominance: (1f1−1f2)=10−6−10−8=9.9×10−7\big(\tfrac1{f_1}-\tfrac1{f_2}\big)=10^{-6}-10^{-8}=9.9\times10^{-7}(f1​1​−f2​1​)=10−6−10−8=9.9×10−7, of which 1/f1=10−61/f_1=10^{-6}1/f1​=10−6 contributes 99%. So the integral depends almost entirely on f1f_1f1​.

Substituting the canonical numbers digit by digit (identical to numerical_feeling example C):

Sϕ(1MHz)=2×10−100/10=2×10−10 rad2/Hz,σϕ2=2×10−10 (106)2 (10−6−10−8)=200×9.9×10−7=1.98×10−4 rad2,σϕ=1.407×10−2 rad=14.07 mrad,σt=1.407×10−22π×5×109=4.479×10−13 s=447.9 fs.\begin{aligned} S_\phi(1\text{MHz})&=2\times10^{-100/10}=2\times10^{-10}\ \text{rad}^2/\text{Hz},\\ \sigma_\phi^2&=2\times10^{-10}\,(10^6)^2\,(10^{-6}-10^{-8})=200\times9.9\times10^{-7}=1.98\times10^{-4}\ \text{rad}^2,\\ \sigma_\phi&=1.407\times10^{-2}\ \text{rad}=14.07\ \text{mrad},\\ \sigma_t&=\frac{1.407\times10^{-2}}{2\pi\times5\times10^{9}}=4.479\times10^{-13}\ \text{s}=447.9\ \text{fs}. \end{aligned}Sϕ​(1MHz)σϕ2​σϕ​σt​​=2×10−100/10=2×10−10 rad2/Hz,=2×10−10(106)2(10−6−10−8)=200×9.9×10−7=1.98×10−4 rad2,=1.407×10−2 rad=14.07 mrad,=2π×5×1091.407×10−2​=4.479×10−13 s=447.9 fs.​

4. Core Python code​

Verbatim from main() in simulations/lab_08_jitter_integration.py: first build the 1/f21/f^21/f2 curve with leeson_one_over_f2, then integrate numerically with integrate_rms_jitter, and finally check against the hand-computed 1/f21/f^21/f2 closed form.

import numpy as np
from simulations.common.noise_utils import leeson_one_over_f2, integrate_rms_jitter

f0 = 5e9
f_ref = 1e6
L_ref = -100.0  # dBc/Hz
f1, f2 = 1e6, 100e6

f = np.logspace(np.log10(f1), np.log10(f2), 4000)
L = leeson_one_over_f2(f, L_ref, f_ref)

# numerical integration
sigma_t, sigma_phi = integrate_rms_jitter(f, L, f0, f1, f2)

# analytic closed form (1/f^2)
L_ref_lin = 10 ** (L_ref / 10)
sigma_phi2_analytic = 2 * L_ref_lin * f_ref ** 2 * (1 / f1 - 1 / f2)
sigma_phi_analytic = np.sqrt(sigma_phi2_analytic)
sigma_t_analytic = sigma_phi_analytic / (2 * np.pi * f0)

print(round(sigma_t * 1e15, 1))    # -> 447.9   (sigma_t in fs)
print(round(sigma_phi * 1e3, 2))   # -> 14.07   (sigma_phi in mrad)

The underlying function integrate_rms_jitter (noise_utils.py) implements exactly steps 1, 3, and 4:

l_linear   = 10 ** (l_dbc_per_hz[mask] / 10)   # dBc/Hz -> linear
s_phi      = 2 * l_linear                       # L ~= 0.5 * S_phi
sigma_phi  = np.sqrt(_trapz(s_phi, f[mask]))    # integrate + square root
sigma_t    = sigma_phi / (2 * np.pi * f0)        # convert to time
  • The script prints sigma_phi (numeric) ≈ sigma_phi (analytic) and sigma_t ≈ 447.9 fs; the numerical and analytic values agree digit by digit (the only difference is the negligible discretization error of logspace sampling and trapezoidal integration).

9. How to read the figure​

  • Blue line (L(f)L(f)L(f)): a straight line on semilog (logarithmic x-axis), because 1/f21/f^21/f2 has a constant slope in dBc/Hz vs log-f (−20-20−20 dB/dec). The red dot marks the anchor point L(1MHz)=−100\mathcal{L}(1\text{MHz})=-100L(1MHz)=−100 dBc/Hz.
  • Blue shading: illustrates "where the phase power sits over offset frequency". Under 1/f21/f^21/f2, the part closest to f1f_1f1​ contributes the most — the visual rendering of "lower-limit dominance".
  • Text box: lists the integration results σϕ=14.07\sigma_\phi=14.07σϕ​=14.07 mrad, σt=447.9\sigma_t=447.9σt​=447.9 fs, and notes that the analytic value equals the numerical one, proving the closed form matches the trapezoidal integration.
  • How to use it: take any datasheet L(f)\mathcal{L}(f)L(f) curve, integrate the area under the blue line, take the square root, divide by 2πf02\pi f_02πf0​, and you have the jitter. Remember the 5 GHz conversion point: ≈448\approx448≈448 fs in this example. With phase noise 20 dB better (−120-120−120 dBc/Hz @ 1 MHz), the power is 100× smaller and σ\sigmaσ 10× smaller → ≈45\approx45≈45 fs.

11. Limitations and approximations​

  • Small-angle approximation L≈12Sϕ\mathcal{L}\approx\frac12 S_\phiL≈21​Sϕ​: breaks down at large phase excursions; here σϕ=14\sigma_\phi=14σϕ​=14 mrad ≪1\ll1≪1 rad, so the approximation is excellent.
  • Pure 1/f21/f^21/f2 skirt assumption: real curves also have 1/f31/f^31/f3 (close-in, see lab_07) and a far-out white floor (noise floor). This lab takes only a single 1/f21/f^21/f2 segment — a teaching simplification. This part is not a toy (the integration flow itself is real engineering practice), but the L(f)L(f)L(f) shape is idealized.
  • Sensitivity to the integration range: with 1/f21/f^21/f2, the lower limit f1f_1f1​ dominates; changing f1f_1f1​ visibly changes σt\sigma_tσt​, while the upper limit matters little. In practice f1f_1f1​, f2f_2f2​ must be chosen per application (PLL loop bandwidth, data rate).
  • Numerical = analytic: the two differ only by the discretization error (logspace + trapezoidal rule), negligible in this setup.

Key takeaways​

  • L\mathcal{L}L (dBc/Hz) → linear → ×2\times2×2 gives SϕS_\phiSϕ​ → integrate → square root → ÷(2πf0)\div(2\pi f_0)÷(2πf0​) = rms jitter.
  • Canonical: 5 GHz, −100-100−100 dBc/Hz @ 1 MHz, 1/f21/f^21/f2, integrated 1→100 MHz → σϕ=14.07\sigma_\phi=14.07σϕ​=14.07 mrad, σt=447.9\sigma_t=447.9σt​=447.9 fs.
  • 1/f21/f^21/f2 jitter is dominated by the lower integration limit (the 1/f11/f_11/f1​ term).
  • The numerical integration agrees digit by digit with the 1/f21/f^21/f2 analytic closed form.
