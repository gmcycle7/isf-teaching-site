Lab 09 — Design trade-off scaling synthesis

Breadcrumb: Simulation labs › Noise & jitter › This page (design trade-offs intro). Upstream: lab_06, lab_08; advanced version: lab_17.

The first eight labs exercised each mechanism one at a time. This synthesis lab introduces no new simulation; instead it treats [P1] Eq.(21) — the signature equation — as a map of design knobs: holding everything else fixed, separately sweep qmaxq_{max}qmax​, Γrms\Gamma_{rms}Γrms​, and the ring stage count NNN, and watch how the phase noise L\mathcal{L}L and the rms jitter σt\sigma_tσt​ move. Throughout we use the canonical numbers (spec Section 8) for back-of-envelope arithmetic, building the reflex of "turn this knob, gain that many dB".

Physical intuition (conclusion first): 1/f21/f^21/f2 phase noise ∝Γrms2/qmax2\propto\Gamma_{rms}^2/q_{max}^2∝Γrms2​/qmax2​. There are only two broad roads to lower phase noise: make the signal charge qmaxq_{max}qmax​ larger (store more energy, so the noise is relatively smaller), or make the ISF Γrms\Gamma_{rms}Γrms​ smaller (make the waveform insensitive to noise). Both are 20log⁡1020\log_{10}20log10​ relationships: doubling qmaxq_{max}qmax​ → phase noise −6-6−6 dB; halving Γrms\Gamma_{rms}Γrms​ → also −6-6−6 dB. A ring oscillator's NNN moves two things at once — watch the net effect carefully.

1. Learning objectives​

  • Read [P1] Eq.(21) as a scaling law and build design intuition for qmaxq_{max}qmax​, Γrms\Gamma_{rms}Γrms​, and NNN.
  • Use the canonical numbers to compute "how many dB / how many fs one knob buys".
  • Understand the two-sided nature of the ring oscillator's NNN (Γrms∝N−3/2\Gamma_{rms}\propto N^{-3/2}Γrms​∝N−3/2, but power/area grow too).
  • Connect the scaling conclusions to the design-insight pages.

2. Mathematical model​

The starting point is [P1] Eq.(21), p.185:

L{Δω}=10log⁡10 ⁣(Γrms2qmax2⋅in2‾/Δf4 Δω2)\mathcal{L}\{\Delta\omega\}=10\log_{10}\!\left(\frac{\Gamma_{rms}^2}{q_{max}^2}\cdot\frac{\overline{i_n^2}/\Delta f}{4\,\Delta\omega^2}\right)L{Δω}=10log10​(qmax2​Γrms2​​⋅4Δω2in2​​/Δf​)

Expand the logarithm into "additive knobs" (fixing Δω\Delta\omegaΔω and Si=in2‾/ΔfS_i=\overline{i_n^2}/\Delta fSi​=in2​​/Δf):

L=20log⁡10Γrms−20log⁡10qmax+10log⁡10Si−20log⁡10(2Δω)+const.\mathcal{L}=20\log_{10}\Gamma_{rms}-20\log_{10}q_{max}+10\log_{10}S_i-20\log_{10}(2\Delta\omega)+\text{const}.L=20log10​Γrms​−20log10​qmax​+10log10​Si​−20log10​(2Δω)+const.
  • How to read it: every knob enters as 20log⁡1020\log_{10}20log10​ (voltage/charge-like) or 10log⁡1010\log_{10}10log10​ (power-like). Both qmaxq_{max}qmax​ and Γrms\Gamma_{rms}Γrms​ enter through 20log⁡1020\log_{10}20log10​, so "double/halve = ±6\pm6±6 dB".

Jitter and phase noise share the same origin: for the 1/f21/f^21/f2 skirt, σt=12πf0∫Sϕdf\sigma_t=\frac{1}{2\pi f_0}\sqrt{\int S_\phi df}σt​=2πf0​1​∫Sϕ​df​ (spec formula 19), and Sϕ∝Γrms2/qmax2S_\phi\propto\Gamma_{rms}^2/q_{max}^2Sϕ​∝Γrms2​/qmax2​, so

σt  ∝  Γrmsqmax(固定f0, Si, 積分範圍).\sigma_t\;\propto\;\frac{\Gamma_{rms}}{q_{max}}\qquad(\text{固定}f_0,\ S_i,\ \text{積分範圍}).σt​∝qmax​Γrms​​(固定f0​, Si​, 積分範圍).
  • The bridge from dB to jitter: L\mathcal{L}L down 666 dB (power ×14\times\frac14×41​) → σt\sigma_tσt​ halves (the \sqrt{}​).

Ring oscillator: [P2] gives two scalings — more stages make each stage's ISF sharper but its rms smaller ([P2] Eq.(16), p.794):

Γrms=2π23η3  1N1.5([P2] Eq.(16), p.794 — v7 re-verified: the square root covers only the constant, Γrms∝N−3/2; ≈4/N1.5 at η=0.75, the solid line in [P2] Fig.8),f0=12NτD [P2] Eq.(15).\Gamma_{rms}=\sqrt{\dfrac{2\pi^2}{3\eta^3}}\;\dfrac{1}{N^{1.5}}\quad(\text{[P2] Eq.(16), p.794 — v7 re-verified: the square root covers only the constant, }\Gamma_{rms}\propto N^{-3/2}\text{; }\approx4/N^{1.5}\text{ at η=0.75, the solid line in [P2] Fig.8}),\qquad f_0=\frac{1}{2N\tau_D}\ \text{[P2] Eq.(15)}.Γrms​=3η32π2​​N1.51​([P2] Eq.(16), p.794 — v7 re-verified: the square root covers only the constant, Γrms​∝N−3/2; ≈4/N1.5 at η=0.75, the solid line in [P2] Fig.8),f0​=2NτD​1​ [P2] Eq.(15).
  • Looking at phase noise alone, NNN from 5 → 15 (×3\times3×3): Γrms\Gamma_{rms}Γrms​ is multiplied by 3−3/2=0.1923^{-3/2}=0.1923−3/2=0.192, a L\mathcal{L}L change of 20log⁡100.192=−14.320\log_{10}0.192=-14.320log10​0.192=−14.3 dB. But more stages → power, area, and the qmaxq_{max}qmax​ allocation all change, and f0f_0f0​ drops (unless τD\tau_DτD​ shrinks), so this is a toy scaling that "looks at Γrms\Gamma_{rms}Γrms​ in isolation", not a net design conclusion.

4. Core Python code​

This lab produces no new figure; the scaling comes straight from back-of-envelope use of [P1] Eq.(21). The snippet below (following the conventions of simulations/lab_08_jitter_integration.py) shows how to turn knob changes into dB and fs so you can sweep the parameters yourself:

import math

def L_dbc(Grms, qmax, Si, df):
    """Hajimiri-Lee Eq.(21): 1/f^2 SSB phase noise [dBc/Hz]."""
    dw = 2 * math.pi * df
    return 10 * math.log10((Grms**2 / qmax**2) * (Si / (4 * dw**2)))

# canonical baseline (spec example B)
f0, df, Si = 5e9, 1e6, 1e-24
base = L_dbc(Grms=0.5, qmax=1e-12, Si=Si, df=df)   # -148.0 dBc/Hz

print("baseline           :", round(base, 1), "dBc/Hz")
print("q_max x2           :", round(L_dbc(0.5, 2e-12, Si, df) - base, 1), "dB")  # -6.0
print("Gamma_rms /2       :", round(L_dbc(0.25, 1e-12, Si, df) - base, 1), "dB") # -6.0
# ring N: Gamma_rms ~ N^-1.5 ([P2] Eq.(16), p.794, re-verified v7: sqrt covers only the constant); show isolated scaling
for N in (5, 15, 45):
    rel = (N / 5.0) ** -1.5
    print(f"N={N:2d} Gamma_rms rel={rel:.3f}  dL={20*math.log10(rel):+.1f} dB")

# jitter scales as Gamma_rms / q_max  ->  -6 dB phase noise = sigma_t / 2
  • L_dbc is not the same thing as lab_08's integrate_rms_jitter: lab_08 integrates jitter out of L\mathcal{L}L; here we go the other way — use Eq.(21) to generate L\mathcal{L}L, then infer jitter from the scaling. The two pages are forward and inverse operations of each other.

Figure 1: simulation evidence for the Γrms2/qmax2\Gamma_{rms}^2/q_{max}^2Γrms2​/qmax2​ scaling. This explains where knob 3 in the scaling table comes from — and reminds you it is an isolated scaling.

11. Limitations and approximations​

  • Toy scaling, not transistor-level: the scaling assumes "turn one knob, hold everything else exactly fixed". In a real circuit qmaxq_{max}qmax​, Γrms\Gamma_{rms}Γrms​, NNN, power, area, and f0f_0f0​ are coupled and cannot be tuned in isolation.
  • Ring NNN scaling ([P2] Eq.(16), p.794 — v7 re-verified: the square root covers only the constant, Γrms∝N−3/2\Gamma_{rms}\propto N^{-3/2}Γrms​∝N−3/2; the body text's 4/N1.54/N^{1.5}4/N1.5 at η=0.75 and App. B Eq.(55) triple-confirm this. v3 had misread it as N−3/4N^{-3/4}N−3/4): the proportionality constant is Γrms=2π2/(3η3)⋅1N1.5\Gamma_{rms}=\sqrt{2\pi^2/(3\eta^3)}\cdot\dfrac{1}{N^{1.5}}Γrms​=2π2/(3η3)​⋅N1.51​ (η≈1\eta\approx1η≈1); adding stages also changes f0=1/(2NτD)f_0=1/(2N\tau_D)f0​=1/(2NτD​), power, and area — the net phase noise/jitter requires the full FOM, not Γrms\Gamma_{rms}Γrms​ alone.
  • Single white source: ignores multiple sources, cyclostationarity (Γeff=Γ⋅α\Gamma_{eff}=\Gamma\cdot\alphaΓeff​=Γ⋅α), and flicker upconversion (1/f31/f^31/f3, see lab_07). The table does not apply in the close-in region.
  • Factor-of-2: uses Eq.(21)'s denominator 4Δω24\Delta\omega^24Δω2; it differs from the time-domain version by the factor-of-2 SSB bookkeeping, which affects none of the scaling conclusions (all dB changes are relative).
  • Jitter scaling: σt∝Γrms/qmax\sigma_t\propto\Gamma_{rms}/q_{max}σt​∝Γrms​/qmax​ assumes a fixed integration range and a 1/f21/f^21/f2 shape; if close-in 1/f31/f^31/f3 dominates, jitter is set by c0c_0c0​ and the lower integration limit and must be computed separately.

Key takeaways​

  • 1/f21/f^21/f2 phase noise ∝Γrms2/qmax2\propto\Gamma_{rms}^2/q_{max}^2∝Γrms2​/qmax2​; jitter ∝Γrms/qmax\propto\Gamma_{rms}/q_{max}∝Γrms​/qmax​.
  • Doubling qmaxq_{max}qmax​ or halving Γrms\Gamma_{rms}Γrms​ → phase noise −6-6−6 dB, jitter halved (20log⁡1020\log_{10}20log10​).
  • Ring NNN in isolation: Γrms∝N−3/2\Gamma_{rms}\propto N^{-3/2}Γrms​∝N−3/2 (N×3→−14.3N\times3\to-14.3N×3→−14.3 dB), but f0f_0f0​/power/area change simultaneously — a toy scaling.
  • Baseline numbers: qmax=1q_{max}=1qmax​=1 pC, Γrms=0.5\Gamma_{rms}=0.5Γrms​=0.5, 5 GHz @ 1 MHz, Si=10−24S_i=10^{-24}Si​=10−24 → L=−148.0\mathcal{L}=-148.0L=−148.0 dBc/Hz.
