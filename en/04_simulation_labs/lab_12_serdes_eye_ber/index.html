Lab 12 — From jitter to eye to BER (SerDes bathtub)

Breadcrumb: Simulation labs › Noise & jitter › This page (eye / BER bathtub). Upstream: lab_08, lab_11; downstream: lab_13.

This lab settles, once and for all, the "why care about jitter" question of the whole ISF course: the oscillator's phase noise integrates into rms timing jitter σt\sigma_tσt​ (see lab_08); this σt\sigma_tσt​ is the random jitter (RJ) of the SerDes sampling clock; RJ closes the eye diagram (the opening formed by overlaying many bits) and sets the BER (bit-error rate). We plot the eye diagram and the BER bathtub (a curve of BER versus sampling instant, shaped like a bathtub).

Physical intuition (conclusion first): an ideal clock always samples at the exact center of the UI (unit interval, the time span of one bit), UI/2UI/2UI/2 away from either data edge — the safest spot. With jitter, the sampling instant wanders randomly left and right; whenever it wanders past either edge, the wrong bit is sampled. RJ is Gaussian and unbounded, so there is always a tail that crosses an edge — the BER is always >0>0>0; its size is set by "how many σ\sigmaσ you sit from the edge". The more σ\sigmaσ of margin, the error probability drops exponentially via Q(⋅)Q(\cdot)Q(⋅) (the Gaussian tail) — which is why the bathtub floor is deep and flat.

1. Learning objectives​

  • Map rms jitter σt\sigma_tσt​ to eye closure and BER.
  • Write down and understand the RJ-only BER bathtub formula (the SerDes BER expression of spec section 10.2).
  • See that "larger σt\sigma_tσt​ → narrower usable sampling window (eye opening at a target BER)".
  • Link the QQQ-function (Gaussian tail) with "how many σ\sigmaσ from the edge" to grasp the BER's exponential sensitivity.

2. Mathematical model​

QQQ-function (Gaussian tail probability).

BER bathtub (RJ only). Sample within the UI at offset ttt relative to the eye center, with the left edge at −UI/2-UI/2−UI/2 and the right edge at +UI/2+UI/2+UI/2. The sampling instant is dithered by Gaussian jitter σt\sigma_tσt​; crossing either edge produces an error (spec section 10.2, "SerDes BER (RJ)"):

BER(t)=12[ Q ⁣(UI/2−tσt)+Q ⁣(UI/2+tσt)].\text{BER}(t)=\frac12\Big[\,Q\!\Big(\frac{UI/2-t}{\sigma_t}\Big)+Q\!\Big(\frac{UI/2+t}{\sigma_t}\Big)\Big].BER(t)=21​[Q(σt​UI/2−t​)+Q(σt​UI/2+t​)].
  • Term-by-term physics: the first term is the probability of jittering past the right edge (distance UI/2−tUI/2-tUI/2−t); the second is that of jittering past the left edge (distance UI/2+tUI/2+tUI/2+t). The leading 12\tfrac1221​ is the bookkeeping for "a transition is present half the time" (RJ-only first-order model).
  • Eye center t=0t=0t=0: the two terms are symmetric, BER(0)=Q(UI/(2σt))\text{BER}(0)=Q(UI/(2\sigma_t))BER(0)=Q(UI/(2σt​)) — both edges sit UI/(2σt)UI/(2\sigma_t)UI/(2σt​) σ\sigmaσ away. This ratio is everything: it is called the "eye half-width in units of σ\sigmaσ".
  • Dimension check: the argument of QQQ, (UI/2−t)/σt(UI/2-t)/\sigma_t(UI/2−t)/σt​, is [s]/[s][\text{s}]/[\text{s}][s]/[s], dimensionless ✓; the BER is a probability (dimensionless) ✓.

UI/2σt=50 psσt.\frac{UI/2}{\sigma_t}=\frac{50\ \text{ps}}{\sigma_t}.σt​UI/2​=σt​50 ps​.

4. Core Python code​

Verbatim from main() in simulations/lab_12_serdes_eye_ber.py: the left panel overlays the eye with eye_traces; the right panel plots bathtub curves for three values of σt\sigma_tσt​ with ber_bathtub.

ui = 100e-12       # 10 Gb/s -> 100 ps UI
sigma_t = 4e-12    # 4 ps rms RJ (e.g. from an integrated 5 GHz clock)

# (a) eye diagram
t, traces = eye_traces(sigma_t, ui, n_traces=300, rng=RNG)
for tr in traces:
    ax.plot(t, tr, color="tab:blue", alpha=0.05, lw=1.0)

# (b) BER bathtub
toff = np.linspace(-ui / 2 * 0.98, ui / 2 * 0.98, 400)
for st, c in zip([2e-12, 4e-12, 8e-12], ["tab:green", "tab:orange", "tab:red"]):
    ber = ber_bathtub(toff, st, ui)
    ax.semilogy(toff / ui, ber, color=c, label=fr"$\sigma_t$={st*1e12:.0f} ps")
ax.axhline(1e-12, color="gray", ls="--", lw=1, label="BER = $10^{-12}$")

The underlying ber_bathtub and Q (serdes_utils.py) are a verbatim implementation of the spec section 10.2 BER formula:

def Q(x):
    """Gaussian tail probability Q(x) = 0.5*erfc(x/sqrt(2))."""
    return 0.5 * erfc(np.asarray(x, dtype=float) / np.sqrt(2.0))

def ber_bathtub(t_offsets, sigma_t, ui):
    t = np.asarray(t_offsets, dtype=float)
    half = ui / 2.0
    ber = 0.5 * (Q((half - t) / sigma_t) + Q((half + t) / sigma_t))
    return np.maximum(ber, 1e-300)
  • eye_traces adds N(0,σt/UI)\mathcal{N}(0,\sigma_t/UI)N(0,σt​/UI) jitter to each transition's edge time (in UI units); overlaying 300 traces forms the eye.
  • ber_bathtub applies the QQQ-function directly; np.maximum(ber, 1e-300) puts a floor under the log plot to avoid log⁡0\log 0log0.

9. How to read the figure​

  • Left panel (eye diagram): 300 jitter-dithered transitions overlaid, leaving a diamond-shaped eye opening at the center. Jitter smears the edges out and narrows the opening horizontally; with even more jitter the eye closes until no sampling instant is safe.
  • Right panel (BER bathtub): three bathtub curves (green/orange/red = σt=2/4/8\sigma_t=2/4/8σt​=2/4/8 ps).
    • Floor depth: the smaller σt\sigma_tσt​, the deeper the bathtub floor (the lower the BER). The green curve (2 ps) bottoms out beyond the plot (UI/(2σt)=25σUI/(2\sigma_t)=25\sigmaUI/(2σt​)=25σ, QQQ vanishingly small); the red curve (8 ps) only reaches the ∼10−10\sim10^{-10}∼10−10 level.
    • Walls: near ±0.5\pm0.5±0.5 UI (i.e. the edges) the BER shoots up to ∼0.5\sim0.5∼0.5 (a coin flip).
    • Usable window (eye opening @ BER): the span between where the two walls cross the 10−1210^{-12}10−12 dashed line is the "window in which sampling is safe at that BER". The larger σt\sigma_tσt​, the narrower this window — this is "jitter eating the timing budget".
  • How to use it: given the data rate (UI) and target BER, back out the tolerable σt\sigma_tσt​; then require the clock's integrated phase noise to stay below that σt\sigma_tσt​ (closing the loop with lab_08).

11. Limitations and approximations​

  • This is a pedagogical toy model, not transistor-level: the eye approximates NRZ transitions with tanh-smoothed edges and has no real channel/equalizer; the BER uses the closed-form QQQ expression, not Monte-Carlo error counting.
  • RJ-only (random jitter only): ignores DJ (deterministic jitter — bounded, from ISI, duty-cycle distortion, crosstalk, etc.). Real jitter is dual-Dirac (RJ ⊛ DJ); DJ pushes the bathtub walls inward and puts a plateau on the floor. This lab demonstrates only the Gaussian-tail RJ part.
  • No amplitude noise / vertical eye closure: timing only (horizontal eye); vertical closure from voltage noise is not included.
  • Ideal two-level signaling, no ISI: assumes clean transitions between adjacent bits and no inter-symbol interference; practical high-speed channels need CTLE/DFE equalization.
  • The 12\tfrac1221​ bookkeeping: transition density taken as 0.5 (random-data average); specific patterns will differ.

Key takeaways​

  • Integrated phase noise → σt\sigma_tσt​ → RJ of the SerDes sampling clock → eye closure → BER.
  • BER(t)=12[Q(UI/2−tσt)+Q(UI/2+tσt)]\text{BER}(t)=\tfrac12[Q(\tfrac{UI/2-t}{\sigma_t})+Q(\tfrac{UI/2+t}{\sigma_t})]BER(t)=21​[Q(σt​UI/2−t​)+Q(σt​UI/2+t​)]; at the eye center BER(0)=Q(UI/(2σt))\text{BER}(0)=Q(UI/(2\sigma_t))BER(0)=Q(UI/(2σt​)).
  • The key quantity is the eye half-width in units of σ\sigmaσ, UI/(2σt)UI/(2\sigma_t)UI/(2σt​): double the jitter and the BER floor rises by dozens of orders of magnitude.
  • Gaussian RJ is unbounded → the BER is always >0>0>0; the intersections of the bathtub with the target-BER line bound the usable sampling window.
