Lab 17 — Design Sweeps: Three Design Curves for swing / Γrms / N

Breadcrumb: Simulation labs › System & advanced › This page (advanced design sweeps). Back-of-the-envelope intro version: lab_09; upstream: lab_06, lab_08.

β: This English translation is in beta — the Traditional-Chinese original is the authoritative version.

lab_09 read [P1] Eq.(21) as a scaling law by mental arithmetic. This lab actually sweeps the same equation and plots it as three curves: holding everything else fixed, sweep the node charge swing qmaxq_{max}qmax​ (swing), the ISF rms Γrms\Gamma_{rms}Γrms​, and the ring stage count NNN, and watch how the phase noise L\mathcal{L}L at 111 MHz offset moves. On the plots you will see with your own eyes the "−20-20−20 dB/decade" straight-line slope, the "2×2\times2× swing →−6\to-6→−6 dB" arrow, and the ring oscillator's nearly horizontal NNN curve (the famous NNN-independence).

Physical intuition (conclusion first): 1/f21/f^21/f2 phase noise ∝Γrms2/qmax2\propto\Gamma_{rms}^2/q_{max}^2∝Γrms2​/qmax2​. Both knobs enter as 20log⁡1020\log_{10}20log10​: doubling qmaxq_{max}qmax​ → −6-6−6 dB; halving Γrms\Gamma_{rms}Γrms​ → −6-6−6 dB. The ring's NNN is sneakier: adding stages shrinks Γrms∝N−3/2\Gamma_{rms}\propto N^{-3/2}Γrms​∝N−3/2, but the per-node qmaxq_{max}qmax​ shrinks and there are more noisy devices — the three roughly cancel at fixed f0f_0f0​/power, so net phase noise is almost independent of NNN.

1. Learning objectives​

  • Plot [P1] Eq.(21)'s L∝Γrms2/qmax2\mathcal{L}\propto\Gamma_{rms}^2/q_{max}^2L∝Γrms2​/qmax2​ as three design curves.
  • On the qmaxq_{max}qmax​ curve, quantify "−20-20−20 dB/decade" and "2×2\times2× swing →−6\to-6→−6 dB".
  • On the Γrms\Gamma_{rms}Γrms​ curve, see "symmetric waveform / low Γrms→\Gamma_{rms}\toΓrms​→ PN↓".
  • On the ring NNN curve, see where NNN-independence comes from ([P2] Eq.(16), p.794 — v7 re-verified: Γrms∝N−3/2\Gamma_{rms}\propto N^{-3/2}Γrms​∝N−3/2).
  • Connect the curves back to lab_09 and the Chapter 06 design-insight pages.

2. Mathematical model​

The starting point is again [P1] Eq.(21), p.185 (1/f21/f^21/f2 region, fixed offset):

L{Δω}=10log⁡10 ⁣(Γrms2qmax2⋅in2‾/Δf4 Δω2)\mathcal{L}\{\Delta\omega\}=10\log_{10}\!\left(\frac{\Gamma_{rms}^2}{q_{max}^2}\cdot\frac{\overline{i_n^2}/\Delta f}{4\,\Delta\omega^2}\right)L{Δω}=10log10​(qmax2​Γrms2​​⋅4Δω2in2​​/Δf​)

Expand the logarithm to expose each knob's own slope:

L=20log⁡10Γrms−20log⁡10qmax+10log⁡10 ⁣(in2‾/Δf)−20log⁡10(2Δω)+const.\mathcal{L}=20\log_{10}\Gamma_{rms}-20\log_{10}q_{max}+10\log_{10}\!\big(\overline{i_n^2}/\Delta f\big)-20\log_{10}(2\Delta\omega)+\text{const}.L=20log10​Γrms​−20log10​qmax​+10log10​(in2​​/Δf)−20log10​(2Δω)+const.
  • Knob 1 (qmaxq_{max}qmax​): −20log⁡10qmax-20\log_{10}q_{max}−20log10​qmax​ → against a log⁡\loglog horizontal axis in qmaxq_{max}qmax​ this is a straight line with slope −20-20−20 dB/decade; qmax×2⇒20log⁡102=6.02q_{max}\times2\Rightarrow20\log_{10}2=6.02qmax​×2⇒20log10​2=6.02 dB → −6-6−6 dB.
  • Knob 2 (Γrms\Gamma_{rms}Γrms​): +20log⁡10Γrms+20\log_{10}\Gamma_{rms}+20log10​Γrms​ → halving Γrms\Gamma_{rms}Γrms​ → −6-6−6 dB; this lab uses a linear horizontal axis, so the curve is the logarithmic rise of 20log⁡10Γrms20\log_{10}\Gamma_{rms}20log10​Γrms​.

The ring's NNN ([P2] Eq.(16), p.794 — v7 re-verified: the square root covers only the constant, Γrms∝N−3/2\Gamma_{rms}\propto N^{-3/2}Γrms​∝N−3/2; the body text's 4/N1.54/N^{1.5}4/N1.5 at η=0.75 and App. B Eq.(55) triple-confirm this. v3 had misread it as N−3/4N^{-3/4}N−3/4): adding stages moves three things at once, and the three cancel each other at fixed f0f_0f0​/power:

Γrms∝N−3/2 [P2] Eq.(16),qmax∝N−1 (smaller per-node swing),in2‾∝N (more devices).\Gamma_{rms}\propto N^{-3/2}\ \text{[P2] Eq.(16)},\qquad q_{max}\propto N^{-1}\ (\text{smaller per-node swing}),\qquad \overline{i_n^2}\propto N\ (\text{more devices}).Γrms​∝N−3/2 [P2] Eq.(16),qmax​∝N−1 (smaller per-node swing),in2​​∝N (more devices).

Substituting into Γrms2/qmax2⋅in2‾\Gamma_{rms}^2/q_{max}^2\cdot\overline{i_n^2}Γrms2​/qmax2​⋅in2​​:

(N−3/2)2(N−1)2⋅N=N−3N−2⋅N=N−1⋅N=N0=const.\frac{(N^{-3/2})^2}{(N^{-1})^2}\cdot N=\frac{N^{-3}}{N^{-2}}\cdot N=N^{-1}\cdot N=N^{0}=\text{const}.(N−1)2(N−3/2)2​⋅N=N−2N−3​⋅N=N−1⋅N=N0=const.
  • Conclusion: under this toy scaling the net effect ∝N0\propto N^0∝N0 → phase noise is independent of NNN ([P2]'s signature result).
  • Dimension check: Γrms2/qmax2⋅(A2/Hz)/(rad/s)2\Gamma_{rms}^2/q_{max}^2\cdot(\text{A}^2/\text{Hz})/(\text{rad/s})^2Γrms2​/qmax2​⋅(A2/Hz)/(rad/s)2 → the bracket is dimensionless (before taking 10log⁡1010\log_{10}10log10​), legitimate ✓; NNN is dimensionless throughout ✓.

Numbers for this lab: evaluated at Δf=1\Delta f=1Δf=1 MHz, in2‾/Δf=10−22\overline{i_n^2}/\Delta f=10^{-22}in2​​/Δf=10−22 A²/Hz; the baseline qmax=1q_{max}=1qmax​=1 pC, Γrms=0.5\Gamma_{rms}=0.5Γrms​=0.5 gives L=−128.0\mathcal{L}=-128.0L=−128.0 dBc/Hz.

4. Core Python code​

simulations/lab_17_design_sweep.py uses a shared L_dbc to evaluate [P1] Eq.(21) in dBc/Hz, then sweeps one curve per knob:

import numpy as np


def L_dbc(Grms, qmax, in2_df, dw):
    return 10 * np.log10(Grms ** 2 / qmax ** 2 * in2_df / (4 * dw ** 2))


dw = 2 * np.pi * 1e6        # evaluate at 1 MHz offset
in2_df = 1e-22

# (a) sweep q_max: 0.1 pC .. 10 pC  -> slope -20 dB/decade, 2x -> -6 dB
q = np.logspace(-13, -11, 50)
L_q = L_dbc(0.5, q, in2_df, dw)                # baseline qmax=1pC -> -128 dBc/Hz

# (b) sweep Gamma_rms: low Grms -> lower PN
g = np.linspace(0.1, 1.5, 50)
L_g = L_dbc(g, 1e-12, in2_df, dw)

# (c) ring N: Gamma_rms ~ N^-3/2, per-node qmax ~ 1/N, more noisy devices ~ N
N = np.arange(3, 31)
Grms_N = 0.5 * (5.0 / N) ** 1.5                # scaling (illustrative; [P2])
qmax_N = 1e-12 * (5.0 / N)                      # lower per-node swing as N grows
noise_N = in2_df * (N / 5.0)                    # more noisy devices
L_N = 10 * np.log10(Grms_N ** 2 / qmax_N ** 2 * noise_N / (4 * dw ** 2))
print(round(L_N[0], 1), round(L_N[-1], 1))
# -> -128.0 -128.0  (essentially flat for all N: the famous N-independence)
  • L_dbc vs lab_08: lab_08 integrates the measured L\mathcal{L}L into jitter; here we go the other way, using Eq.(21) to generate L\mathcal{L}L and then sweep the knobs. The two pages are inverse operations of each other (same note as in lab_09).
  • The three scalings in (c) are illustrative: the constant in Γrms∝N−3/2\Gamma_{rms}\propto N^{-3/2}Γrms​∝N−3/2 and the exponents for per-node qmaxq_{max}qmax​ and device count are toy assumptions, meant to draw concretely "why NNN roughly cancels".

8. Simulation figure​

9. How to read the figure​

  • (a) swing sweep (blue): on a log horizontal axis, qmaxq_{max}qmax​ (0.1–10 pC) vs L\mathcal{L}L is a straight line with slope −20-20−20 dB/decade — as qmaxq_{max}qmax​ goes from 0.1 → 10 pC (two decades), L\mathcal{L}L drops from −108-108−108 → −148-148−148 dBc/Hz, exactly 404040 dB. The red arrow marks "2×2\times2× swing →−6\to-6→−6 dB" (1→21\to21→2 pC, −128→−134-128\to-134−128→−134 dBc/Hz). Mnemonic: double the swing, gain 6 dB of phase noise.
  • (b) Γrms\Gamma_{rms}Γrms​ sweep (green): linear horizontal axis, a logarithmic curve L=20log⁡10Γrms+\mathcal{L}=20\log_{10}\Gamma_{rms}+L=20log10​Γrms​+const — smaller Γrms\Gamma_{rms}Γrms​ means lower phase noise, with the steepest descent at the small-Γrms\Gamma_{rms}Γrms​ end (halving Γrms\Gamma_{rms}Γrms​ from 0.5 to 0.25 → −6-6−6 dB). This is the payoff of "symmetric waveform / low sensitivity".
  • (c) ring NNN sweep (purple): a nearly perfectly horizontal line (≈−128\approx-128≈−128 dBc/Hz, independent of NNN). Not a coincidence — it is the N0N^0N0 computed in Section 2: more stages shrink Γrms\Gamma_{rms}Γrms​ (good), but qmaxq_{max}qmax​ also shrinks and there are more devices (bad); the three cancel at fixed f0f_0f0​/power. Adding ring stages does not buy you phase noise for free ([P2]).
  • Putting it together: (a)(b) are the "knobs that truly earn dB" (raise the swing, suppress Γrms\Gamma_{rms}Γrms​); (c) is the "looks tunable, actually cancels" knob — choose NNN based on f0f_0f0​, power, area, and phase-count requirements, not for phase noise.

11. Limitations and approximations​

  • Toy scaling, not transistor-level: (a)(b) assume "turn one knob only, everything else perfectly fixed"; in real circuits qmaxq_{max}qmax​, Γrms\Gamma_{rms}Γrms​, NNN, power, area, and f0f_0f0​ are coupled and cannot be tuned in isolation.
  • The three exponents in ring (c) are illustrative: Γrms∝N−3/2\Gamma_{rms}\propto N^{-3/2}Γrms​∝N−3/2, qmax∝N−1q_{max}\propto N^{-1}qmax​∝N−1, in2‾∝N\overline{i_n^2}\propto Nin2​​∝N are toy assumptions to demonstrate the cancellation; the exact constants are marked TODO: manual verification needed from [P2] page 794–796. Changing NNN also changes f0=1/(2NτD)f_0=1/(2N\tau_D)f0​=1/(2NτD​) (unless τD\tau_DτD​ is shrunk), which this figure does not show simultaneously.
  • 1/f21/f^21/f2 region only, fixed offset: evaluated at 111 MHz; close-in 1/f31/f^31/f3 is dominated by c0c_0c0​ and the lower integration limit, where these three plots do not apply (see lab_07).
  • Single white noise source: ignores multiple sources, cyclostationarity (Γeff=Γα\Gamma_{eff}=\Gamma\alphaΓeff​=Γα, lab_14), and AM–PM.
  • Factor-of-2: uses Eq.(21)'s 4Δω24\Delta\omega^24Δω2 convention; the factor-of-2 SSB-bookkeeping difference does not affect any relative (dB) slope.
  • Jitter inference: σt∝Γrms/qmax\sigma_t\propto\Gamma_{rms}/q_{max}σt​∝Γrms​/qmax​ (−6-6−6 dB phase noise = jitter halved) requires a fixed integration range and 1/f21/f^21/f2 shape; see lab_08, lab_09.

Key takeaways​

  • qmaxq_{max}qmax​ curve: −20-20−20 dB/decade; 2×2\times2× swing →−6\to-6→−6 dB (baseline −128-128−128 → −134-134−134 dBc/Hz).
  • Γrms\Gamma_{rms}Γrms​ curve: 20log⁡10Γrms20\log_{10}\Gamma_{rms}20log10​Γrms​, halving →−6\to-6→−6 dB; symmetric waveforms / low sensitivity pay off.
  • Ring NNN curve: nearly horizontal — Γrms2/qmax2⋅in2‾∝N0\Gamma_{rms}^2/q_{max}^2\cdot\overline{i_n^2}\propto N^0Γrms2​/qmax2​⋅in2​​∝N0, phase noise is independent of NNN ([P2] Eq.(16), p.794, v7 re-verified: Γrms∝N−3/2\Gamma_{rms}\propto N^{-3/2}Γrms​∝N−3/2).
  • Baseline: qmax=1q_{max}=1qmax​=1 pC, Γrms=0.5\Gamma_{rms}=0.5Γrms​=0.5, in2‾/Δf=10−22\overline{i_n^2}/\Delta f=10^{-22}in2​​/Δf=10−22, 111 MHz →L=−128.0\to\mathcal{L}=-128.0→L=−128.0 dBc/Hz.
