Worked Examples

This page is the hands-on worked-example bank for ISF / phase noise / jitter. The theory pages show where the formulas come from; here you learn to plug in the numbers, compute all the way through, check the units, and verify with one line of Python. All formulas are carried over verbatim from [the AUTHORING_SPEC authoritative formula table]; numbers follow numerical_feeling and the spec Section 8 canonical values (qmax=1q_{max}=1qmax​=1 pC, Γrms=0.5\Gamma_{rms}=0.5Γrms​=0.5, f0=5f_0=5f0​=5 GHz, L(1MHz)=−100\mathcal{L}(1\text{MHz})=-100L(1MHz)=−100 dBc/Hz).

How to use this page: cover the step-by-step solution, work each problem yourself, then check. The core skill of an analog designer is order-of-magnitude estimation at the whiteboard — seeing "−100-100−100 dBc/Hz @ 1 MHz, 5 GHz" you should call out "a few hundred fs of jitter" within 30 seconds. The one-line Python at the end of each problem is only for checking, never a substitute for the hand calculation.

Four levels:

  • (A) Basic conversions: rad ↔ fs, dBc ↔ linear, phase PSD ↔ L\mathcal{L}L. Drill until they become reflexes.
  • (B) ISF → phase noise: Eq.(21)/(23)/(24) algebra — turn Γrms,c0,qmax\Gamma_{rms},c_0,q_{max}Γrms​,c0​,qmax​ into dBc/Hz.
  • (C) jitter integration: integrate L(f)\mathcal{L}(f)L(f) to get σt\sigma_tσt​; the high-pass kernel of period jitter.
  • (D) design back-calculation: how large a qmax/Γrmsq_{max}/\Gamma_{rms}qmax​/Γrms​ for −120-120−120 dBc/Hz; how to choose the ring stage count NNN.

Every problem follows a fixed format: Problem → step-by-step solution (with units) → Result → dimension check → one-line Python verification. All Python calls real functions from simulations/common/ (see the spec Section 5 API) and runs as-is.

Example A1: phase → time (how many fs is 1 mrad at 5 GHz?)​

Problem: f0=5f_0=5f0​=5 GHz, Δϕ=1\Delta\phi=1Δϕ=1 mrad; find the timing error Δt\Delta tΔt.

Example A2: dBc/Hz → linear (how much is −100 dBc/Hz?)​

Problem: L=−100\mathcal{L}=-100L=−100 dBc/Hz. Convert to linear (power ratio relative to the carrier, per Hz), then recover the phase PSD SϕS_\phiSϕ​.

Example A4: phase sensitivity varies with injection phase (a taste of LTV)​

Problem: an ideal LC oscillator has ISF Γ(θ)=−sin⁡θ\Gamma(\theta)=-\sin\thetaΓ(θ)=−sinθ. With the same Δq=1\Delta q=1Δq=1 fC and qmax=1q_{max}=1qmax​=1 pC, inject at the zero crossing (θ=π/2\theta=\pi/2θ=π/2, maximum waveform slope) and at the peak (θ=0\theta=0θ=0, waveform top), and find Δϕ\Delta\phiΔϕ in each case.

Step-by-step solution

Step 1: read off the ISF at both points. Note the phase convention here: with V∝cos⁡θV\propto\cos\thetaV∝cosθ the peak is at θ=0\theta=0θ=0 and the (falling-edge) zero crossing at θ=π/2\theta=\pi/2θ=π/2; the ideal LC has Γ=−sin⁡θ\Gamma=-\sin\thetaΓ=−sinθ:

Γ(θ=π/2)=−sin⁡π2=−1,Γ(θ=0)=−sin⁡0=0.\Gamma(\theta=\pi/2)=-\sin\tfrac{\pi}{2}=-1,\qquad \Gamma(\theta=0)=-\sin 0=0 .Γ(θ=π/2)=−sin2π​=−1,Γ(θ=0)=−sin0=0.

Step 2: substitute each into Δϕ=Γ Δq/qmax\Delta\phi=\Gamma\,\Delta q/q_{max}Δϕ=ΓΔq/qmax​ (Δq/qmax=10−15/10−12=10−3\Delta q/q_{max}=10^{-15}/10^{-12}=10^{-3}Δq/qmax​=10−15/10−12=10−3):

Example B3: symmetry and 1/f³ (the role of c0c_0c0​)​

Problem: two oscillators with identical white noise and qmaxq_{max}qmax​, ω1/f=2π×1\omega_{1/f}=2\pi\times1ω1/f​=2π×1 MHz. Step-by-step solution

Step 1: look at Eq.(23) — phase noise in the 1/f³ region is proportional to c02c_0^2c02​.

Problem: build an f0=5f_0=5f0​=5 GHz single-ended ring. (a) With per-stage delay τD=20\tau_D=20τD​=20 ps, how many stages NNN? Example D4: back-solving phase noise from a jitter spec (SerDes link)​

Problem: a 5 GHz clock requires integrated rms jitter σt≤100\sigma_t\le100σt​≤100 fs (integrated 1 MHz→100 MHz, 1/f² spectrum). Back-solve how low L\mathcal{L}L must be at 1 MHz.

Self-check list​

After finishing the 15 problems above, cover the answers and quiz yourself — every item should get an instant "direction" answer in your head:

Level B (ISF → phase noise)

  • 1/f² is −20-20−20 dB/dec, 1/f³ is −30-30−30 dB/dec — read them off a plot by eye.

  • Can run the full chain dBc/Hz → (integrate) → σϕ\sigma_\phiσϕ​ → (÷2πf0\div2\pi f_0÷2πf0​) → σt\sigma_tσt​.
