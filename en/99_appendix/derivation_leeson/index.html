Leeson Model Derivation and ISF Comparison

Prerequisites / See also: tank_Q_and_energy_restoration (the energy definition of QQQ, why the tank shapes 1/f21/f^21/f2), psd_phase_noise_jitter (4kTR4kTR4kTR thermal noise and PSD basics), white_noise_to_phase_noise (the ISF-version 1/f21/f^21/f2 derivation) | Next: symmetry (using c0c_0c0​ symmetry to suppress the 1/f31/f^31/f3 corner), references (external literature [E1])

Before Hajimiri–Lee's ISF theory ([P1], 1998) appeared, engineers estimated oscillator phase noise using the Leeson model (1966). It is a semi-empirical formula: the physical skeleton (tank filtering + feedback) is correct, but it packs in a noise factor FFF that is "unknown where it comes from — has to be fit from measurement." This page derives Leeson from scratch, then maps it term by term onto the closed-form ISF result — you'll see that ISF theory "explains why Leeson looks the way it does, and replaces that mysterious FFF with a computable physical quantity."

Honesty note (read first): the Leeson model comes from [E1] D. B. Leeson, "A Simple Model of Feedback Oscillator Noise Spectrum," Proc. IEEE, vol. 54, no. 2, pp. 329–330, Feb. 1966, not among the five source PDFs downloaded for this site. This page relies only on standard-literature knowledge for background and comparison; the volume/issue/pages/DOI have been verified online (DOI 10.1109/PROC.1966.4682); FFF (noise figure) is inherently an empirically fitted parameter of the Leeson model (implementation-dependent), not a fixed constant. By contrast, the ISF formulas in the right half of this page ([P1] Eqs.(21),(23),(24)) are authoritative, verified expressions from within the five source PDFs.

This page answers:

  1. Physically, where does each term of the Leeson expression (floor, 1/f21/f^21/f2, 1/f31/f^31/f3) come from?
  2. Why are the slopes 1/f21/f^21/f2 and 1/f31/f^31/f3, and where is the corner?
  3. Which ISF quantities do Leeson's QQQ, FFF, ω1/f3\omega_{1/f^3}ω1/f3​ correspond to? Which ones does ISF explain more clearly?

Physical intuition (conclusion first): Leeson treats the oscillator as "a feedback system continuously fed by thermal noise and narrowband-filtered by a high-QQQ tank." Three things stack up: (1) the amplifier/tank injects a white noise floor (2FkT/Ps2FkT/P_s2FkT/Ps​); (2) because it is an autonomous oscillator, phase perturbations near the carrier have no restoring force, so the closed loop multiplies the noise by a (ω0/2QΔω)2(\omega_0/2Q\Delta\omega)^2(ω0​/2QΔω)2 "phase-integration" transfer function, producing the 1/f21/f^21/f2 skirt; (3) the device's 1/f1/f1/f flicker noise gets upconverted by one more order, producing the 1/f31/f^31/f3 closest to the carrier. ISF theory tells the same three-part story, only it replaces 1/2Q1/2Q1/2Q with Γrms/qmax\Gamma_{rms}/q_{max}Γrms​/qmax​, and replaces FFF with a physical quantity computable from Γeff\Gamma_{eff}Γeff​.

The full formula (state it first, then derive step by step)​

Leeson model (spec 10.2, external literature, not one of the five PDFs):

L(Δω)=10log⁡10 ⁣[2FkTPs(1+(ω02Q Δω)2)(1+ω1/f3∣Δω∣)]\mathcal{L}(\Delta\omega)=10\log_{10}\!\left[\frac{2FkT}{P_s}\left(1+\Big(\frac{\omega_0}{2Q\,\Delta\omega}\Big)^2\right)\left(1+\frac{\omega_{1/f^3}}{\lvert\Delta\omega\rvert}\right)\right]L(Δω)=10log10​[Ps​2FkT​(1+(2QΔωω0​​)2)(1+∣Δω∣ω1/f3​​)]

Symbols: FFF = amplifier noise figure (empirical quantity, dimensionless); kkk = Boltzmann constant (J/K); TTT = temperature (K); PsP_sPs​ = oscillation signal power (W); QQQ = tank quality factor (dimensionless); ω0\omega_0ω0​ = carrier angular frequency (rad/s); Δω\Delta\omegaΔω = offset angular frequency (rad/s); ω1/f3\omega_{1/f^3}ω1/f3​ = flicker corner (rad/s).

Below, the three factors inside the brackets are derived one at a time.

Step 1: tank thermal noise — the noise floor 2FkT/Ps2FkT/P_s2FkT/Ps​​

Treat the oscillator as a "feedback loop of amplifier + resonant tank." The thermal-noise source in the loop is the tank's loss resistance RRR (parallel-equivalent), whose single-sided thermal-noise voltage PSD (Johnson–Nyquist) is:

vn2‾Δf=4kTR.\frac{\overline{v_n^2}}{\Delta f}=4kTR.Δfvn2​​​=4kTR.
  • Physics used: resistor thermal noise 4kTR4kTR4kTR (standard result; see psd_phase_noise_jitter).
  • Dimension check: [kT]=J=V⋅C[kT]=\text{J}=\text{V·C}[kT]=J=V⋅C, [kTR]=V⋅C⋅Ω=V2⋅s=V2/Hz[kTR]=\text{V·C·}\Omega=\text{V}^2\text{·s}=\text{V}^2/\text{Hz}[kTR]=V⋅C⋅Ω=V2⋅s=V2/Hz ✓.

The amplifier itself also adds noise; the whole thing is lumped into a single noise figure FFF (which packages "actual total noise" over "input thermal noise alone" into one ratio). Normalizing the noise power against the carrier power PsP_sPs​ gives the phase-noise floor near the carrier:

Lfloor=2FkTPs.\mathcal{L}_{\text{floor}}=\frac{2FkT}{P_s}.Lfloor​=Ps​2FkT​.
  • FFF is Leeson's "empirical escape hatch": it absorbs all the noise that isn't explicitly modeled (amplifier, conversion loss, cyclostationary effects, ...) into a single measurement-fit number. This is exactly what ISF later replaces (see Step 5's comparison).
  • Where the 2 comes from: this is a bookkeeping convention of the Leeson model (not the only way to write it — it varies by reference). Physically there are actually two factors, pulling in opposite directions: (1) AM/PM equipartition — thermal noise perturbs amplitude and phase simultaneously, and phase gets only half the power (×12\times\tfrac12×21​); (2) single-sideband (SSB) accounting converts double-sided power to single-sided (×2\times2×2). The two cancel, so the "cleanest" way to write the floor is actually FkT/PsFkT/P_sFkT/Ps​; writing it as 2FkT/Ps2FkT/P_s2FkT/Ps​ leaves the SSB convention explicit in the leading constant without folding the AM/PM 12\tfrac1221​ into FFF. This is the same kind of SSB/double-sided bookkeeping difference as [P1] Eq.(21)'s 4Δω24\Delta\omega^24Δω2 vs. the time-domain 2Δω22\Delta\omega^22Δω2 (see the factor-of-2 discussion in white_noise_to_phase_noise). (FFF is an empirically fitted parameter, and the leading constant varies slightly by reference — this is precisely what ISF later replaces with Γrms/qmax\Gamma_{rms}/q_{max}Γrms​/qmax​.)
  • Dimension check: [2FkT/Ps]=J/W=J/(J/s)=s=1/Hz[2FkT/P_s]=\text{J}/\text{W}=\text{J}/(\text{J/s})=\text{s}=1/\text{Hz}[2FkT/Ps​]=J/W=J/(J/s)=s=1/Hz ✓ (L\mathcal{L}L is relative power per hertz, dBc/Hz).

Step 2: narrowband filtering by the high-QQQ tank → the 1/f21/f^21/f2 skirt​

The tank is a narrowband filter. Near the carrier, at offset Δω\Delta\omegaΔω, the phase/amplitude response slope of the parallel RLC is set by QQQ. The standard result: the (half-power) transfer of the tank at offset Δω\Delta\omegaΔω can be written as

∣H(Δω)∣2  ∝  (ω02Q Δω)2(Δω≪ω0/2Q).\left|H(\Delta\omega)\right|^2\;\propto\;\left(\frac{\omega_0}{2Q\,\Delta\omega}\right)^2\qquad(\Delta\omega\ll\omega_0/2Q).∣H(Δω)∣2∝(2QΔωω0​​)2(Δω≪ω0​/2Q).
  • The physics of QQQ: Q=ω0/Δω3dBQ=\omega_0/\Delta\omega_{3dB}Q=ω0​/Δω3dB​ = "how sharp the resonance peak is" = stored/dissipated energy ratio per cycle ×2π\times2\pi×2π. The higher the QQQ, the narrower the tank bandwidth, the steeper the phase slope, and the stronger the suppression of offset noise.
  • Why 1/Δω21/\Delta\omega^21/Δω2 (i.e., −20-20−20 dB/dec): an autonomous oscillator's phase is a neutral direction (no restoring force, echoing λ1=0\lambda_1=0λ1​=0 in derivation_floquet_ppv). The closed loop is equivalent to one integration of the phase perturbation, which in the frequency domain is ×1/Δω\times 1/\Delta\omega×1/Δω; squaring for power gives 1/Δω21/\Delta\omega^21/Δω2. This is the fundamental reason phase noise must be 1/f21/f^21/f2 in the mid-band, slope −20-20−20 dB/dec — it shares the same origin as ISF's 1/Δω21/\Delta\omega^21/Δω2 ([P1] Eq.(21)).
  • Dimension check: ω0/(2QΔω)\omega_0/(2Q\Delta\omega)ω0​/(2QΔω) is dimensionless (rad/s ÷ rad/s) ✓, so the whole transfer is dimensionless.

Multiplying Steps 1 and 2 (floor × tank shaping) gives the first two terms in the brackets:

L1/f2+floor=2FkTPs(1+(ω02Q Δω)2).\mathcal{L}_{1/f^2+\text{floor}}=\frac{2FkT}{P_s}\left(1+\Big(\frac{\omega_0}{2Q\,\Delta\omega}\Big)^2\right).L1/f2+floor​=Ps​2FkT​(1+(2QΔωω0​​)2).
  • The 111 in "1+1+1+" is the white noise floor (dominant at far offset, flat); (ω0/2QΔω)2(\omega_0/2Q\Delta\omega)^2(ω0​/2QΔω)2 is the 1/f21/f^21/f2 skirt (dominant near the carrier). Where the two are equal is the corner where 1/f2→1/f^2\to1/f2→ floor, Δω≈ω0/2Q\Delta\omega\approx\omega_0/2QΔω≈ω0​/2Q.

Step 3: device flicker → the 1/f31/f^31/f3 region closest to the carrier​

The device's low-frequency 1/f1/f1/f (flicker) noise gets "upconverted" near the carrier by the oscillator's nonlinearity, and after the phase integration of Step 2, becomes a 1/f31/f^31/f3 steeper than 1/f21/f^21/f2. Leeson attaches it with a multiplicative factor:

(1+ω1/f3∣Δω∣).\left(1+\frac{\omega_{1/f^3}}{\lvert\Delta\omega\rvert}\right).(1+∣Δω∣ω1/f3​​).
  • When Δω≫ω1/f3\Delta\omega\gg\omega_{1/f^3}Δω≫ω1/f3​: this factor ≈1\approx1≈1, flicker is invisible, leaving just 1/f21/f^21/f2 and the floor.
  • When Δω≪ω1/f3\Delta\omega\ll\omega_{1/f^3}Δω≪ω1/f3​: this factor ≈ω1/f3/∣Δω∣∝1/Δω\approx\omega_{1/f^3}/\lvert\Delta\omega\rvert\propto1/\Delta\omega≈ω1/f3​/∣Δω∣∝1/Δω, which further multiplies the 1/Δω21/\Delta\omega^21/Δω2 from Step 2 → total 1/Δω31/\Delta\omega^31/Δω3, i.e., 1/f31/f^31/f3, −30-30−30 dB/dec.
  • ω1/f3\omega_{1/f^3}ω1/f3​ is the "flicker corner of the phase noise", not the device's own 1/f1/f1/f corner. Leeson never explains what determines it — this is exactly the key physics ISF fills in (Step 5, [P1] Eq.(24)).
  • Dimension check: ω1/f3/∣Δω∣\omega_{1/f^3}/\lvert\Delta\omega\rvertω1/f3​/∣Δω∣ dimensionless ✓.

Multiplying all three terms gives the full Leeson formula from the top. Three slope segments: floor (flat) → 1/f21/f^21/f2 (−20-20−20 dB/dec) → 1/f31/f^31/f3 (−30-30−30 dB/dec), from far to near.

The only difference is where the corner falls and the absolute level — which is set by the parameter correspondence, see below.

Step 5: term-by-term comparison (Leeson ↔ ISF)​

This is the core of this page. Putting the corresponding terms of both models side by side:

Key comparisons expanded:

(a) Q↔Γrms/qmaxQ\leftrightarrow\Gamma_{rms}/q_{max}Q↔Γrms​/qmax​. Both are "the efficiency with which noise is converted into a phase skirt." Leeson says "higher QQQ is better"; ISF says "smaller Γrms/qmax\Gamma_{rms}/q_{max}Γrms​/qmax​ is better." But ISF is more general: it also holds for ring oscillators with no high-QQQ tank (a ring has no QQQ to speak of, but does have Γrms,qmax\Gamma_{rms},q_{max}Γrms​,qmax​; see lab_03). This is the first way ISF goes beyond Leeson.

(b) Empirical FFF vs ISF physical. Leeson's FFF is a black box: you must first build the oscillator, measure the phase noise, and back out FFF, before you can "predict" with the model — which is really post-hoc fitting, not prediction. ISF writes the same level as in2‾/Δf4qmax2Γrms2\dfrac{\overline{i_n^2}/\Delta f}{4q_{max}^2}\Gamma_{rms}^24qmax2​in2​​/Δf​Γrms2​ ([P1] Eq.(21)), where every quantity can be computed ahead of time from the device model and waveform, and cyclostationary behavior (device leaking noise only at certain phases) can be folded in via Γeff=Γ⋅α\Gamma_{eff}=\Gamma\cdot\alphaΓeff​=Γ⋅α — this is exactly why the Colpitts's "effective FFF" is much lower than a naive Leeson estimate (see effective_isf).

(c) 1/f31/f^31/f3 corner. Leeson simply takes ω1/f3\omega_{1/f^3}ω1/f3​ as an input parameter, effectively admitting "I don't know where it comes from." Early engineering practice even mistook it for the device's own 1/f1/f1/f corner. ISF's [P1] Eq.(24) settles it: Δω1/f3=ω1/f⋅c02/(2Γrms2)\Delta\omega_{1/f^3}=\omega_{1/f}\cdot c_0^2/(2\Gamma_{rms}^2)Δω1/f3​=ω1/f​⋅c02​/(2Γrms2​) — it is set by the ISF's DC coefficient c0c_0c0​ (waveform symmetry). Making rise/fall symmetric → c0→0c_0\to0c0​→0 → the 1/f31/f^31/f3 corner drops sharply → near-carrier phase noise falls substantially. This is a design rule Leeson simply cannot give, and it is the theoretical basis for [P2]'s use of symmetry to suppress ring phase noise (see symmetry, flicker_noise_upconversion).

Numerical example (building intuition)​

Example (1/f31/f^31/f3 corner comparison): take a device 1/f1/f1/f corner f1/f=1f_{1/f}=1f1/f​=1 MHz (ω1/f=2π×106\omega_{1/f}=2\pi\times10^6ω1/f​=2π×106 rad/s). Compare the phase-noise 1/f31/f^31/f3 corner of a "symmetric" vs. an "asymmetric" waveform.

ISF's [P1] Eq.(24): Δω1/f3=ω1/f⋅c02/(2Γrms2)\Delta\omega_{1/f^3}=\omega_{1/f}\cdot c_0^2/(2\Gamma_{rms}^2)Δω1/f3​=ω1/f​⋅c02​/(2Γrms2​), take Γrms=0.5\Gamma_{rms}=0.5Γrms​=0.5.

  • Asymmetric waveform (large c0c_0c0​, set c0=0.4c_0=0.4c0​=0.4):
Δω1/f3=ω1/f⋅(0.4)22(0.5)2=ω1/f⋅0.160.5=0.32 ω1/f.\Delta\omega_{1/f^3}=\omega_{1/f}\cdot\frac{(0.4)^2}{2(0.5)^2}=\omega_{1/f}\cdot\frac{0.16}{0.5}=0.32\,\omega_{1/f}.Δω1/f3​=ω1/f​⋅2(0.5)2(0.4)2​=ω1/f​⋅0.50.16​=0.32ω1/f​.

That is, f1/f3≈0.32×1 MHz=320f_{1/f^3}\approx0.32\times1\ \text{MHz}=320f1/f3​≈0.32×1 MHz=320 kHz — the 1/f31/f^31/f3 skirt extends far from the carrier.

  • Symmetric waveform (small c0c_0c0​, set c0=0.04c_0=0.04c0​=0.04, 10× smaller):
Δω1/f3=ω1/f⋅(0.04)22(0.5)2=ω1/f⋅0.00160.5=3.2×10−3 ω1/f.\Delta\omega_{1/f^3}=\omega_{1/f}\cdot\frac{(0.04)^2}{2(0.5)^2}=\omega_{1/f}\cdot\frac{0.0016}{0.5}=3.2\times10^{-3}\,\omega_{1/f}.Δω1/f3​=ω1/f​⋅2(0.5)2(0.04)2​=ω1/f​⋅0.50.0016​=3.2×10−3ω1/f​.

That is, f1/f3≈3.2f_{1/f^3}\approx3.2f1/f3​≈3.2 kHz — the corner drops 100× (because c0c_0c0​ is squared: a 10× reduction in c0c_0c0​ → 100× reduction in the corner).

  • Dimension check: c02/Γrms2c_0^2/\Gamma_{rms}^2c02​/Γrms2​ is dimensionless, ω1/f×\omega_{1/f}\timesω1/f​×dimensionless === rad/s ✓.
  • Intuition: Leeson treats ω1/f3\omega_{1/f^3}ω1/f3​ as "fixed by nature"; ISF tells you it is a knob the designer can turn by two orders of magnitude via symmetry. This is ISF's practical value.

One-line Python verification (corner ratio):

import numpy as np
from simulations.common.isf_utils import gamma_rms
# Ratio of the 1/f^3 corner for a symmetric vs asymmetric waveform = (c0_asym/c0_sym)^2
c0_asym, c0_sym, Gamma_rms = 0.4, 0.04, 0.5
w1f = 2*np.pi*1e6
corner_asym = w1f * c0_asym**2 / (2*Gamma_rms**2)
corner_sym  = w1f * c0_sym**2  / (2*Gamma_rms**2)
print(corner_asym/(2*np.pi)/1e3, "kHz ;", corner_sym/(2*np.pi)/1e3, "kHz")
# -> ~320.0 kHz ; ~3.2 kHz   (a symmetric waveform pushes the 1/f^3 corner down 100x)

(For gamma_rms and related library functions, see simulations/common/isf_utils.py; this example computes the corner directly by hand from [P1] Eq.(24).)

  • Three segments: white-noise floor (2FkT/Ps2FkT/P_s2FkT/Ps​) → tank-shaped 1/f21/f^21/f2 (−20-20−20 dB/dec, from phase integration 1/Δω21/\Delta\omega^21/Δω2) → flicker-upconverted 1/f31/f^31/f3 (−30-30−30 dB/dec).
