Rigorous LTV framework: Zadeh's time-varying transfer function and the harmonic transfer matrix

Prerequisites: lti_vs_ltv (intuition for LTV vs. LTI), convolution_derivation ([P1] Eq.(11)'s LTV convolution), fourier_series_of_isf (ISF Fourier coefficients cnc_ncn​) | Next: derivation_floquet_ppv (the PPV/Floquet face of the same ISF)

This site's main thread ([P1]) introduces the ISF via "physical intuition + impulse simulation," and convolution_derivation uses superposition to generalize a single impulse to arbitrary noise. That path works very well, but leaves a gap: we keep saying the oscillator's response to noise is LTV (linear time-varying), "it acts like a time-varying mixer that shifts noise near nω0n\omega_0nω0​ to the carrier" — but in the language of signals and systems, exactly which rigorous object do these statements correspond to? Can "frequency gets shifted, gain is ckc_kck​" be written as a clean transfer function?

This page fills in that system-theory foundation. Starting from the convolution/LTI framework the reader already knows, we work up to Zadeh's time-varying transfer function H(f,t)H(f,t)H(f,t) and the harmonic transfer matrix (HTM), and then prove one statement:

The ISF (together with 1/qmax1/q_{max}1/qmax​) is exactly the "conversion vector from each input-harmonic band to the phase output" — its kkk-th component is precisely the kkk-th Fourier coefficient ckc_kck​ of the ISF. In other words, the ISF's Fourier series {ck}\{c_k\}{ck​} is not merely a set of numbers — it is exactly the "phase-output row" of this LTV system's HTM.

Honesty note (read first): this page's Zadeh time-varying transfer function H(f,t)H(f,t)H(f,t), bi-frequency function, and harmonic transfer matrix (HTM) belong to the broader theory of linear time-varying systems and are not among the 5 PDFs hosted on this site. The original concept comes from [E5] L. A. Zadeh, "Frequency Analysis of Variable Networks," Proc. IRE, vol. 38, no. 3, pp. 291–299, Mar. 1950 (DOI 10.1109/JRPROC.1950.231083); the HTM formulation is standard in periodic-time-varying/RF circuit literature (e.g., cyclostationary, LPTV system analysis). These are external mathematical frameworks; the formal [E5] citation (Zadeh 1950, Proc. IRE 38(3):291–299, DOI 10.1109/JRPROC.1950.231083) is recorded in references. This page only uses them to "re-derive the ISF"; every correspondence to the ISF converges back to [P1] Eq.(13) (within the 5 PDFs, verified verbatim).

This page answers four questions:

  1. How does LTI convolution generalize to LTV? (First connect to the reader's signals-and-systems background.)
  2. How does Zadeh write "the LTV response to each input frequency fff" as a time-varying transfer function H(f,t)H(f,t)H(f,t)?
  3. When this LTV system is periodic (as an oscillator is), what structure does H(f,t)H(f,t)H(f,t) collapse into — why does the input frequency fff only get shifted to the discrete set f+kf0f+kf_0f+kf0​, with gain ckc_kck​? This is the HTM.
  4. Narrowing to the "phase output," how do we prove the ISF is exactly that conversion vector?

Step 0: review LTI — convolution and a single transfer function (the reader's starting point)​

The LTI (linear time-invariant) systems taught in signals-and-systems courses are completely determined by a single impulse response h(τ)h(\tau)h(τ). For an input x(t)x(t)x(t), the output is a convolution:

y(t)=∫−∞∞h(t−τ) x(τ) dτ.y(t)=\int_{-\infty}^{\infty}h(t-\tau)\,x(\tau)\,d\tau .y(t)=∫−∞∞​h(t−τ)x(τ)dτ.
  • Key feature: the kernel hhh depends only on the time difference t−τt-\taut−τ, not on absolute time. "Kicking it now" and "kicking it one beat later" give the same effect, just shifted in time.
  • The frequency domain is diagonal: LTI's signature property is that complex exponentials are eigenfunctions. Substituting x(t)=ej2πftx(t)=e^{j2\pi f t}x(t)=ej2πft,
y(t)=∫h(t−τ) ej2πfτ dτ=ej2πft∫h(σ) e−j2πfσ dσ⏟= H(f),y(t)=\int h(t-\tau)\,e^{j2\pi f\tau}\,d\tau =e^{j2\pi f t}\underbrace{\int h(\sigma)\,e^{-j2\pi f\sigma}\,d\sigma}_{=\,H(f)},y(t)=∫h(t−τ)ej2πfτdτ=ej2πft=H(f)∫h(σ)e−j2πfσdσ​​,

(change of variables σ=t−τ\sigma=t-\tauσ=t−τ). The output is the same frequency fff multiplied by a complex gain H(f)H(f)H(f).

  • This is the essence of LTI: input frequency fff in, only frequency fff out — no new frequencies are generated. So a single transfer function H(f)H(f)H(f) suffices to describe everything — in the frequency domain, LTI is diagonal (different frequencies do not couple).
  • Dimension check: [h]=[y]/([x]⋅s)[h]=[y]/([x]\cdot\text{s})[h]=[y]/([x]⋅s) (convolution carries a dτd\taudτ); H(f)=∫h e−j2πfσdσH(f)=\int h\,e^{-j2\pi f\sigma}d\sigmaH(f)=∫he−j2πfσdσ differs from hhh by one s\text{s}s, so [H]=[y]/[x][H]=[y]/[x][H]=[y]/[x] (a pure gain) ✓.

Why is an oscillator not LTI? Because "kicking at the peak" and "kicking at the zero crossing" give wildly different effects — the kernel depends on the absolute injection instant (through Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ)), not only on t−τt-\taut−τ. This is exactly what lti_vs_ltv and impulse_to_phase_shift Step 4 ("hϕ(t,τ)h_\phi(t,\tau)hϕ​(t,τ) depends on τ\tauτ") describe. Below we systematize this.

Step 1: LTV — the kernel becomes a two-variable function h(t,τ)h(t,\tau)h(t,τ)​

Relax LTI's "depends only on time difference" assumption: an LTV system's impulse response depends on two instants — "when the impulse is applied (τ\tauτ)" and "when it is observed (ttt)." The output is written (per convention 11.2):

 y(t)=∫−∞∞h(t,τ) x(τ) dτ \boxed{\ y(t)=\int_{-\infty}^{\infty}h(t,\tau)\,x(\tau)\,d\tau\ } y(t)=∫−∞∞​h(t,τ)x(τ)dτ ​
  • h(t,τ)h(t,\tau)h(t,τ) reads as "the response measured at time ttt to a unit impulse fired at time τ\tauτ."
  • LTI is a special case: if the system is time-invariant, h(t,τ)=h(t−τ)h(t,\tau)=h(t-\tau)h(t,τ)=h(t−τ), and the expression above collapses back to convolution. LTV loosens "t−τt-\taut−τ" into the "independent pair (t,τ)(t,\tau)(t,τ)" — the extra degree of freedom is exactly the mathematical container for the physical fact that "when you kick it matters."
  • Correspondence to the ISF: [P1] Eq.(10), p.182's excess-phase impulse response hϕ(t,τ)=Γ(ω0τ)qmax u(t−τ)h_\phi(t,\tau)=\dfrac{\Gamma(\omega_0\tau)}{q_{max}}\,u(t-\tau)hϕ​(t,τ)=qmax​Γ(ω0​τ)​u(t−τ) is exactly such an h(t,τ)h(t,\tau)h(t,τ) — its dependence on τ\tauτ is entirely encoded in Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ), and its dependence on t−τt-\taut−τ is just a unit step (the phase step is retained permanently). Substituting into the box above gives [P1] Eq.(11)'s ϕ(t)=1qmax∫−∞tΓ(ω0τ) in(τ) dτ\phi(t)=\frac{1}{q_{max}}\int_{-\infty}^{t}\Gamma(\omega_0\tau)\,i_n(\tau)\,d\tauϕ(t)=qmax​1​∫−∞t​Γ(ω0​τ)in​(τ)dτ (see convolution_derivation). So ISF theory was already an LTV convolution all along — just with a particularly simple kernel.
  • Dimension check: same as LTI, [h(t,τ)]=[y]/([x]⋅s)[h(t,\tau)]=[y]/([x]\cdot\text{s})[h(t,τ)]=[y]/([x]⋅s) ✓.

Step 2: Zadeh's time-varying transfer function H(f,t)H(f,t)H(f,t) — "the instantaneous response to each frequency"​

LTI needs only one H(f)H(f)H(f). For LTV, the response to "each input frequency" varies with the observation instant ttt, so Zadeh (1950) defines a time-varying transfer function H(f,t)H(f,t)H(f,t): feed a pure sinusoid x(τ)=ej2πfτx(\tau)=e^{j2\pi f\tau}x(τ)=ej2πfτ into the system, and write the output as "ej2πfte^{j2\pi f t}ej2πft times a gain that varies with ttt":

y(t)∣x=ej2πfτ=H(f,t) ej2πft.y(t)\big|_{x=e^{j2\pi f\tau}}=H(f,t)\,e^{j2\pi f t}.y(t)​x=ej2πfτ​=H(f,t)ej2πft.

Substitute Step 1's LTV convolution into this, and change variables σ=t−τ\sigma=t-\tauσ=t−τ (i.e., τ=t−σ\tau=t-\sigmaτ=t−σ):

y(t)=∫h(t,τ) ej2πfτ dτ=∫h(t, t−σ) ej2πf(t−σ) dσ=ej2πft∫h(t, t−σ) e−j2πfσ dσ⏟≡ H(f,t).y(t)=\int h(t,\tau)\,e^{j2\pi f\tau}\,d\tau =\int h(t,\,t-\sigma)\,e^{j2\pi f(t-\sigma)}\,d\sigma =e^{j2\pi f t}\underbrace{\int h(t,\,t-\sigma)\,e^{-j2\pi f\sigma}\,d\sigma}_{\equiv\,H(f,t)} .y(t)=∫h(t,τ)ej2πfτdτ=∫h(t,t−σ)ej2πf(t−σ)dσ=ej2πft≡H(f,t)∫h(t,t−σ)e−j2πfσdσ​​.

This yields Zadeh's time-varying transfer function (convention 11.2):

 H(f,t)=∫−∞∞h(t, t−σ) e−j2πfσ dσ \boxed{\ H(f,t)=\int_{-\infty}^{\infty}h(t,\,t-\sigma)\,e^{-j2\pi f\sigma}\,d\sigma\ } H(f,t)=∫−∞∞​h(t,t−σ)e−j2πfσdσ ​
  • How to read it: H(f,t)H(f,t)H(f,t) is the "instantaneous complex gain at this instant ttt, for input frequency fff." Its dependence on fff resembles LTI's H(f)H(f)H(f); the extra dependence on ttt is the entire content of being time-varying.
  • Degeneracy check: when time-invariant, h(t,t−σ)=h(σ)h(t,t-\sigma)=h(\sigma)h(t,t−σ)=h(σ) is independent of ttt, so H(f,t)→H(f)H(f,t)\to H(f)H(f,t)→H(f), recovering LTI ✓.
  • Dimension check: same as H(f)H(f)H(f), [H(f,t)]=[y]/[x][H(f,t)]=[y]/[x][H(f,t)]=[y]/[x] (a pure gain) ✓.
  • Why this still isn't "elegant" enough: H(f,t)H(f,t)H(f,t) is an arbitrary function of ttt, carrying the same amount of information as the entire h(t,τ)h(t,\tau)h(t,τ) — no compression. The real magic comes in the next step — when the system is periodic, H(f,t)H(f,t)H(f,t)'s dependence on ttt reduces to only discrete Fourier components, and the whole LTV system collapses into a matrix (the HTM).

Step 3: periodic LTV → Fourier expansion of H(f,t)H(f,t)H(f,t) → harmonic transfer matrix​

In periodic steady state, an oscillator's LTV kernel is TTT-periodic: h(t+T,τ+T)=h(t,τ)h(t+T,\tau+T)=h(t,\tau)h(t+T,τ+T)=h(t,τ) (invariant when τ\tauτ and ttt are both shifted by one period). This class of systems is called LPTV (linear periodically time-varying). Periodicity makes H(f,t)H(f,t)H(f,t)'s dependence on ttt become TTT-periodic, so it can be expanded in a Fourier series in ttt:

H(f,t)=∑k=−∞∞Hk(f) ej2πkf0t,f0=1T,H(f,t)=\sum_{k=-\infty}^{\infty}H_k(f)\,e^{j2\pi k f_0 t},\qquad f_0=\frac1T,H(f,t)=k=−∞∑∞​Hk​(f)ej2πkf0​t,f0​=T1​,

where Hk(f)=1T∫0TH(f,t) e−j2πkf0t dtH_k(f)=\dfrac1T\displaystyle\int_0^T H(f,t)\,e^{-j2\pi k f_0 t}\,dtHk​(f)=T1​∫0T​H(f,t)e−j2πkf0​tdt is the kkk-th harmonic transfer function.

  • Physical meaning (key): feeding a pure sinusoid x=ej2πfτx=e^{j2\pi f\tau}x=ej2πfτ into the system, the output is
y(t)=H(f,t) ej2πft=∑kHk(f) ej2π(f+kf0)t.y(t)=H(f,t)\,e^{j2\pi f t}=\sum_{k}H_k(f)\,e^{j2\pi (f+kf_0) t}.y(t)=H(f,t)ej2πft=k∑​Hk​(f)ej2π(f+kf0​)t.

A single input frequency fff scatters into an entire row of discrete frequencies f+kf0f+kf_0f+kf0​ (k=0,±1,±2,…k=0,\pm1,\pm2,\dotsk=0,±1,±2,…), with the complex gain of the kkk-th line being Hk(f)H_k(f)Hk​(f). This is the rigorous statement of "the oscillator is a time-varying mixer" / "frequency gets shifted": in the frequency domain, LPTV is no longer diagonal — it couples an input band to every band "spaced by an integer multiple of f0f_0f0​."

  • The harmonic transfer matrix (HTM): index both input and output by "harmonic bands spaced by f0f_0f0​"; the entire LPTV system is then described by a matrix H\mathbf{H}H whose elements
[H]m,k=Hm−k ⁣(f)[\mathbf{H}]_{m,k}=H_{m-k}\!\left(f\right)[H]m,k​=Hm−k​(f)

map "input band kkk" to "output band mmm." It has Toeplitz structure (elements depend only on the band difference m−km-km−k), because the shift amount only depends on "how many multiples of f0f_0f0​ apart." This is the harmonic transfer matrix — LPTV's "transfer function" is not a single number but this matrix that couples the harmonic bands to one another.

  • Degeneracy check: if the system is time-invariant, only H0(f)=H(f)H_0(f)=H(f)H0​(f)=H(f) is nonzero, and the matrix becomes diagonal (the k=0k=0k=0 line), recovering LTI's "no new frequencies generated" ✓.
  • Dimension check: every Hk(f)H_k(f)Hk​(f) is a pure gain (same dimension as H(f,t)H(f,t)H(f,t)) ✓.

Step 4: substitute the oscillator's ISF kernel — HkH_kHk​ is exactly ckc_kck​​

Now we narrow the abstract HTM to [P1]'s phase channel. The phase output's LTV kernel (with respect to noise current) comes from [P1] Eq.(11), written in Step 1's h(t,τ)h(t,\tau)h(t,τ) form (phase is the cumulative integral of noise, so the kernel carries a unit step):

hϕ(t,τ)=Γ(ω0τ)qmax u(t−τ)[P1] Eq.(10), p.182.h_\phi(t,\tau)=\frac{\Gamma(\omega_0\tau)}{q_{max}}\,u(t-\tau)\qquad[\text{P1] Eq.(10), p.182}.hϕ​(t,τ)=qmax​Γ(ω0​τ)​u(t−τ)[P1] Eq.(10), p.182.

Substitute the ISF's Fourier series ([P1] Eq.(12), p.183) into Γ\GammaΓ:

Γ(ω0τ)=c02+∑n=1∞cncos⁡(nω0τ+θn)=∑k=−∞∞c~k ejkω0τ,\Gamma(\omega_0\tau)=\frac{c_0}{2}+\sum_{n=1}^{\infty}c_n\cos(n\omega_0\tau+\theta_n) =\sum_{k=-\infty}^{\infty}\tilde c_k\,e^{jk\omega_0\tau},Γ(ω0​τ)=2c0​​+n=1∑∞​cn​cos(nω0​τ+θn​)=k=−∞∑∞​c~k​ejkω0​τ,

where the right-hand side rewrites the real-valued cosine series as a complex exponential series (c~0=c0/2\tilde c_0=c_0/2c~0​=c0​/2, c~±k=12cke±jθk\tilde c_{\pm k}=\tfrac12 c_k e^{\pm j\theta_k}c~±k​=21​ck​e±jθk​, k≥1k\ge1k≥1; this is the standard real↔complex Fourier conversion, see math_identities).

Core algebra: the phase channel is "ISF-weight, then integrate." First look at the "ISF weighting" — an instantaneous multiplication (we leave the integrator to the next step, since it multiplies every band uniformly by 1/(j2πf)1/(j2\pi f)1/(j2πf) and does not couple bands). Weight a pure sinusoidal noise in(τ)=ej2πfτi_n(\tau)=e^{j2\pi f\tau}in​(τ)=ej2πfτ by the ISF:

Γ(ω0τ) ej2πfτ=∑kc~k ejkω0τ ej2πfτ=∑kc~k ej2π(f+kf0)τ.\Gamma(\omega_0\tau)\,e^{j2\pi f\tau} =\sum_{k}\tilde c_k\,e^{jk\omega_0\tau}\,e^{j2\pi f\tau} =\sum_{k}\tilde c_k\,e^{j2\pi (f+kf_0)\tau}.Γ(ω0​τ)ej2πfτ=k∑​c~k​ejkω0​τej2πfτ=k∑​c~k​ej2π(f+kf0​)τ.

(using kω0τ=2π(kf0)τk\omega_0\tau=2\pi(kf_0)\taukω0​τ=2π(kf0​)τ). Comparing against Step 3's y=∑kHk(f)ej2π(f+kf0)ty=\sum_k H_k(f)e^{j2\pi(f+kf_0)t}y=∑k​Hk​(f)ej2π(f+kf0​)t, term-by-term matching reads off the harmonic transfer function of the ISF-weighting stage:

Hands-on verification: Hk=ckH_k=c_kHk​=ck​ is not an analogy — it's a measurable number​

The block below can be run directly (it depends on this site's simulations/common/isf_utils). It tests the claim Hk=c~kH_k=\tilde c_kHk​=c~k​ verbatim: separately inject equal-amplitude single-tone noise near 1ω01\omega_01ω0​, 2ω02\omega_02ω0​, 3ω03\omega_03ω0​ (each offset by Δf\Delta fΔf), integrate into phase ϕ(t)\phi(t)ϕ(t), take the FFT of ϕ(t)\phi(t)ϕ(t), and measure the amplitude of the "sideband down-converted to baseband Δf\Delta fΔf." If Hn∝cnH_n\propto c_nHn​∝cn​, these sideband ratios must equal the ratios of the ISF's Fourier coefficients c1:c2:c3c_1:c_2:c_3c1​:c2​:c3​.

import numpy as np
from simulations.common.isf_utils import (
    compute_fourier_coefficients, integrate_phase_from_noise)

f0, qmax = 5e9, 1e-12                 # 5 GHz carrier, q_max = 1 pC
w0 = 2 * np.pi * f0
fs = 8 * f0                           # resolves up to ~3 w0 without aliasing
df = 5e6                              # injected single-tone offset near each harmonic [Hz]
N  = 1 << 21                          # large N -> cleanly resolve the baseband df sideband
t  = np.arange(N) / fs

# same pedagogical ISF as this page's figure / lab_05 (nonzero c0, several nontrivial harmonics):
def gamma(theta):
    return (-np.sin(theta) + 0.35*np.sin(2*theta)
            + 0.18*np.cos(3*theta) + 0.25)

g_traj = gamma(w0 * t)                # Gamma(w0 t), sampled along the trajectory
th = np.linspace(0, 2*np.pi, 4000, True)
_, _, _, c, _ = compute_fourier_coefficients(th, gamma(th), 4)
print(np.round(c[:4], 3))             # -> [0.5  1.    0.35 0.18]  (c0, c1, c2, c3)

I0 = 1e-6
def phi_sideband(n):                  # inject I0 cos((n w0 + df) t), measure phi's sideband at df
    i_n = I0 * np.cos((n*w0 + 2*np.pi*df) * t)
    phi = integrate_phase_from_noise(t, i_n, g_traj, qmax)
    P = np.abs(np.fft.rfft((phi - phi.mean()) * np.hanning(N))) / N
    f = np.fft.rfftfreq(N, 1/fs)
    k = int(np.argmin(np.abs(f - df)))
    return P[k-5:k+6].max()

a1, a2, a3 = (phi_sideband(n) for n in (1, 2, 3))
print(f"a1/a2 = {a1/a2:.3f}   c1/c2 = {c[1]/c[2]:.3f}")  # -> a1/a2 = 2.857   c1/c2 = 2.857
print(f"a1/a3 = {a1/a3:.3f}   c1/c3 = {c[1]/c[3]:.3f}")  # -> a1/a3 = 5.556   c1/c3 = 5.556

The two sets of ratios match digit-for-digit: ϕ\phiϕ's response strength to "injection near nω0n\omega_0nω0​" is proportional to cnc_ncn​, which is the numerical witness to Hn(Γ)=c~nH_n^{(\Gamma)}=\tilde c_nHn(Γ)​=c~n​ — the HTM's folding gain is the ISF's Fourier coefficient, not an analogy. (This also corresponds to the arrow heights on the left side of the band-folding figure above, ∣c~±1∣=c1/2|\tilde c_{\pm1}|=c_1/2∣c~±1​∣=c1​/2, ∣c~±2∣=c2/2|\tilde c_{\pm2}|=c_2/2∣c~±2​∣=c2​/2.)

Step 5: adding back the integrator and 1/qmax1/q_{max}1/qmax​ — the complete HTM row of the phase channel​

The full phase channel is "ISF weighting →\to→ multiply by 1/qmax1/q_{max}1/qmax​ →\to→ integrate" (see the block diagram in white_noise_to_phase_noise). In the frequency domain, the integrator multiplies the "post-shift" frequency f+kf0f+kf_0f+kf0​ by 1j2π(f+kf0)\dfrac{1}{j2\pi(f+kf_0)}j2π(f+kf0​)1​. But what we care about is phase noise near the carrier: noise falling at f=−kf0+Δff=-kf_0+\Delta ff=−kf0​+Δf (i.e., "the kkk-th harmonic band offset by Δf\Delta fΔf") gets shifted by HkH_{k}Hk​ to baseband Δf\Delta fΔf (following Step 3's HTM convention y=∑mHm x(f−mf0)y=\sum_m H_m\,x(f-mf_0)y=∑m​Hm​x(f−mf0​), shifting input −kf0+Δf-kf_0+\Delta f−kf0​+Δf to Δf\Delta fΔf requires m=km=km=k), and the integrator there multiplies by 1j2πΔf\dfrac{1}{j2\pi\Delta f}j2πΔf1​. So the gain of the entire chain "noise in the kkk-th band → phase at Δf\Delta fΔf near the carrier" is

1qmax⋅c~k⏟ISF shift⋅1j2πΔf⏟integrator  → ∣⋅∣   ∣ck∣2 qmax⋅12πΔf(k≥1).\frac{1}{q_{max}}\cdot \underbrace{\tilde c_{k}}_{\text{ISF shift}}\cdot\underbrace{\frac{1}{j2\pi\Delta f}}_{\text{integrator}} \;\xrightarrow{\ |\cdot|\ }\; \frac{|c_k|}{2\,q_{max}}\cdot\frac{1}{2\pi\Delta f}\quad(k\ge1).qmax​1​⋅ISF shiftc~k​​​⋅integratorj2πΔf1​​​ ∣⋅∣ ​2qmax​∣ck​∣​⋅2πΔf1​(k≥1).

This is exactly [P1] Eq.(16/17), p.183's single-tone sideband result ϕp=I0 ck2qmax Δω\phi_p=\dfrac{I_0\,c_k}{2q_{max}\,\Delta\omega}ϕp​=2qmax​ΔωI0​ck​​ (Δω=2πΔf\Delta\omega=2\pi\Delta fΔω=2πΔf) — we've re-derived it from the HTM, with every piece (ISF shift =ck=c_k=ck​, integrator =1/(j2πΔf)=1/(j2\pi\Delta f)=1/(j2πΔf), normalization =1/qmax=1/q_{max}=1/qmax​) cleanly separated out.

Collect this entire row of gains "each input harmonic band → phase output" into a vector (this is the row of the HTM corresponding to the "phase output"):

 gϕ=1qmax[…, c~−2, c~−1, c02, c~1, c~2, …] \boxed{\ \mathbf{g}_\phi=\frac{1}{q_{max}}\big[\dots,\ \tilde c_{-2},\ \tilde c_{-1},\ \tfrac{c_0}{2},\ \tilde c_{1},\ \tilde c_{2},\ \dots\big]\ } gϕ​=qmax​1​[…, c~−2​, c~−1​, 2c0​​, c~1​, c~2​, …] ​
  • The kkk-th component =c~k/qmax=\tilde c_k/q_{max}=c~k​/qmax​: maps "the noise band a distance kf0kf_0kf0​ from the carrier" to phase. The sum of squared magnitudes ∑k∣c~k∣2=(c0/2)2+12∑n≥1cn2=Γrms2\sum_k|\tilde c_k|^2=(c_0/2)^2+\tfrac12\sum_{n\ge1}c_n^2=\Gamma_{rms}^2∑k​∣c~k​∣2=(c0​/2)2+21​∑n≥1​cn2​=Γrms2​ (the DC term contributes as (c0/2)2(c_0/2)^2(c0​/2)2, consistent with lab_05's Parseval correction and [P1] Eq.(20)) — this is the HTM version of white_noise_to_phase_noise's use of Parseval to convert ∑cn2\sum c_n^2∑cn2​ into Γrms2\Gamma_{rms}^2Γrms2​: the total phase-noise weight = the energy of this conversion vector.
  • Dimension check: each component c~k/qmax\tilde c_k/q_{max}c~k​/qmax​ carries C−1\text{C}^{-1}C−1; multiplying by the noise band's charge (A·s/...) and the integrator afterward yields rad ✓.

Step 6: conclusion — "the ISF is exactly the conversion vector from each harmonic to the phase output"​

Combining Steps 4 and 5, this page's signature theorem holds:

Theorem (ISF = HTM row of the phase output): treat the periodic-time-varying oscillator's phase channel as an LPTV system, indexing input/output by harmonic bands spaced by f0f_0f0​. Then the kkk-th component of the conversion vector gϕ\mathbf{g}_\phigϕ​ mapping "each input harmonic band → phase output" is exactly the (complex) ISF Fourier coefficient divided by qmaxq_{max}qmax​: [gϕ]k=c~k/qmax[\mathbf{g}_\phi]_k=\tilde c_k/q_{max}[gϕ​]k​=c~k​/qmax​. Equivalently, the ISF's Fourier series {ck}\{c_k\}{ck​} is exactly the content of that row of the phase output in the HTM.

Key takeaways​

  • LTI is described by a single h(t−τ)h(t-\tau)h(t−τ)/H(f)H(f)H(f), diagonal in frequency domain, generating no new frequencies; LTV's kernel becomes h(t,τ)h(t,\tau)h(t,τ), with output y=∫h(t,τ)x dτy=\int h(t,\tau)x\,d\tauy=∫h(t,τ)xdτ; the oscillator's hϕ(t,τ)=Γ(ω0τ)qmaxu(t−τ)h_\phi(t,\tau)=\frac{\Gamma(\omega_0\tau)}{q_{max}}u(t-\tau)hϕ​(t,τ)=qmax​Γ(ω0​τ)​u(t−τ) is exactly one example.
  • Zadeh's time-varying transfer function H(f,t)=∫h(t,t−σ)e−j2πfσdσH(f,t)=\int h(t,t-\sigma)e^{-j2\pi f\sigma}d\sigmaH(f,t)=∫h(t,t−σ)e−j2πfσdσ describes "the instantaneous gain at frequency fff right now"; it degenerates to H(f)H(f)H(f) when time-invariant.
  • Periodic LTV (LPTV): H(f,t)=∑kHk(f)ejkω0tH(f,t)=\sum_k H_k(f)e^{jk\omega_0 t}H(f,t)=∑k​Hk​(f)ejkω0​t; an input frequency fff gets shifted to an entire row f+kf0f+kf_0f+kf0​, with gain HkH_kHk​. This set of harmonic gains forms the Toeplitz harmonic transfer matrix (HTM).
  • Substituting the ISF kernel → Hk(Γ)=c~kH_k^{(\Gamma)}=\tilde c_kHk(Γ)​=c~k​ (the ISF's Fourier coefficient); adding back 1/qmax1/q_{max}1/qmax​ and the integrator re-derives [P1] Eq.(16/17)'s single-tone sideband.
  • Signature theorem: the phase-output conversion vector [gϕ]k=c~k/qmax[\mathbf g_\phi]_k=\tilde c_k/q_{max}[gϕ​]k​=c~k​/qmax​ — the ISF is exactly the conversion vector from each harmonic band to the phase output (the HTM's phase-output row); its energy ∑k∣c~k∣2=Γrms2\sum_k|\tilde c_k|^2=\Gamma_{rms}^2∑k​∣c~k​∣2=Γrms2​ is Parseval.
  • The entire Zadeh/HTM apparatus belongs to external LTV system theory, not among the 5 PDFs ([E5] Zadeh 1950); together with [P1] Eq.(13) and PPV, it is the same ISF in three languages.
