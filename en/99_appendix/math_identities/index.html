Math Toolbox — Math Identities

See also: notation (authoritative symbols and units), glossary (Chinese–English term intuitions), convolution_derivation (LTV convolution uses the tools on this page), white_noise_to_phase_noise (application site for Parseval/integrator response)

ISF theory looks very "circuits," but its skeleton is really a handful of standard math tools combined repeatedly. This page collects them, gives each a short proof or citation, and marks which page on the site uses it. Come back here when a derivation stalls — it beats memorizing formulas by rote.

How to use this page: each section first gives "one line on what it says," then "why it holds" (proof or citation), and finally "where on the site it's used." Every quantity carries units — doing a dimension check is always the fastest way to catch mistakes.

1. Fourier series and Parseval (harmonic decomposition of the ISF)​

One line: any 2π2\pi2π-periodic real function can be split into DC plus a set of harmonics; its "total energy" equals the sum of each harmonic's energy. This is the mathematical basis for splitting the ISF Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ) into c0,c1,c2,…c_0,c_1,c_2,\dotsc0​,c1​,c2​,….

The ISF is a dimensionless, 2π2\pi2π-periodic function, written as a cosine series ([P1] Eq.(12), p.183):

Γ(ω0τ)=c02+∑n=1∞cncos⁡(nω0τ+θn)\Gamma(\omega_0\tau)=\frac{c_0}{2}+\sum_{n=1}^{\infty}c_n\cos(n\omega_0\tau+\theta_n)Γ(ω0​τ)=2c0​​+n=1∑∞​cn​cos(nω0​τ+θn​)

Write the argument as x=ω0τx=\omega_0\taux=ω0​τ. Parseval's relation ([P1] Eq.(20), p.185):

∑n=0∞cn2=1π∫02π∣Γ(x)∣2 dx=2 Γrms2\sum_{n=0}^{\infty}c_n^2=\frac{1}{\pi}\int_0^{2\pi}|\Gamma(x)|^2\,dx=2\,\Gamma_{rms}^2n=0∑∞​cn2​=π1​∫02π​∣Γ(x)∣2dx=2Γrms2​

Why it holds (short proof): square the series and integrate from 000 to 2π2\pi2π. Cosines of different harmonics are mutually orthogonal,

∫02πcos⁡(mx+θm)cos⁡(nx+θn) dx=π δmn(m,n≥1),\int_0^{2\pi}\cos(mx+\theta_m)\cos(nx+\theta_n)\,dx=\pi\,\delta_{mn}\quad(m,n\ge1),∫02π​cos(mx+θm​)cos(nx+θn​)dx=πδmn​(m,n≥1),

so the cross terms all vanish, leaving only the square terms: each cncos⁡(⋅)c_n\cos(\cdot)cn​cos(⋅) term contributes cn2⋅πc_n^2\cdot\picn2​⋅π, and the DC term (c02)2\left(\frac{c_0}{2}\right)^2(2c0​​)2 contributes (c02)2⋅2π=c022π\left(\frac{c_0}{2}\right)^2\cdot 2\pi=\frac{c_0^2}{2}\pi(2c0​​)2⋅2π=2c02​​π. Dividing both sides by π\piπ gives ∑n=1∞cn2+c022\sum_{n=1}^{\infty}c_n^2+\frac{c_0^2}{2}∑n=1∞​cn2​+2c02​​. Hajimiri–Lee write the DC term as c022\frac{c_0^2}{2}2c02​​ (note the n=0n=0n=0 term is counted as only half in the sum), and rearranging gives exactly the form above.

rms definition consistency check: Γrms2=12π∫02π∣Γ(x)∣2 dx\Gamma_{rms}^2=\frac{1}{2\pi}\int_0^{2\pi}|\Gamma(x)|^2\,dxΓrms2​=2π1​∫02π​∣Γ(x)∣2dx (rms is just "root mean square": square first, average, then take the root). Substituting into the right-hand side of Parseval: 1π∫=2⋅12π∫=2Γrms2\frac{1}{\pi}\int=2\cdot\frac{1}{2\pi}\int=2\Gamma_{rms}^2π1​∫=2⋅2π1​∫=2Γrms2​ ✓.

Numerical feel: for the ideal LC, Γ(θ)=−sin⁡θ\Gamma(\theta)=-\sin\thetaΓ(θ)=−sinθ, only c1=1c_1=1c1​=1 (all others 0). Γrms2=12π∫02πsin⁡2θ dθ=12\Gamma_{rms}^2=\frac{1}{2\pi}\int_0^{2\pi}\sin^2\theta\,d\theta=\frac12Γrms2​=2π1​∫02π​sin2θdθ=21​, so Γrms=1/2≈0.707\Gamma_{rms}=1/\sqrt2\approx0.707Γrms​=1/2​≈0.707; the right-hand side of Parseval, 2×12=1=c122\times\frac12=1=c_1^22×21​=1=c12​ ✓.

2. Convolution and the LTI vs LTV distinction (why the oscillator is "time-variant")​

One line: an LTI (linear time-invariant) system's impulse response depends only on "how long ago" t−τt-\taut−τ; an LTV (linear time-variant) system also depends on "at what instant it's kicked" τ\tauτ. The oscillator's response to noise is LTV — this is the core of ISF theory.

LTI superposition is standard convolution:

y(t)=∫−∞∞h(t−τ) x(τ) dτ.y(t)=\int_{-\infty}^{\infty}h(t-\tau)\,x(\tau)\,d\tau .y(t)=∫−∞∞​h(t−τ)x(τ)dτ.
  • Core feature: hhh depends only on the difference t−τt-\taut−τ (time-invariant). Delay the input, and the output is delayed unchanged.

The oscillator's excess-phase impulse response, however, is ([P1] Eq.(10), p.182):

hϕ(t,τ)=Γ(ω0τ)qmax u(t−τ).h_\phi(t,\tau)=\frac{\Gamma(\omega_0\tau)}{q_{max}}\,u(t-\tau).hϕ​(t,τ)=qmax​Γ(ω0​τ)​u(t−τ).

It simultaneously depends on τ\tauτ (via Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ) — at what phase of the waveform it's kicked) and on t−τt-\taut−τ (via the step u(t−τ)u(t-\tau)u(t−τ) — it persists permanently after being kicked). Superposing all past noise ([P1] Eq.(11), p.182):

ϕ(t)=∫−∞∞hϕ(t,τ) in(τ) dτ=1qmax∫−∞tΓ(ω0τ) in(τ) dτ.\phi(t)=\int_{-\infty}^{\infty}h_\phi(t,\tau)\,i_n(\tau)\,d\tau=\frac{1}{q_{max}}\int_{-\infty}^{t}\Gamma(\omega_0\tau)\,i_n(\tau)\,d\tau .ϕ(t)=∫−∞∞​hϕ​(t,τ)in​(τ)dτ=qmax​1​∫−∞t​Γ(ω0​τ)in​(τ)dτ.

Why it's LTV, not LTI: because Γ(ω0τ)\Gamma(\omega_0\tau)Γ(ω0​τ) is a periodic function of the absolute instant of injection. The same impulse, kicked at the peak (Γ≈0\Gamma\approx0Γ≈0), barely changes phase; kicked at the zero crossing (∣Γ∣|\Gamma|∣Γ∣ maximal), changes it the most. This is exactly [P1] Sec. III's claim C1: "the oscillator's response to noise is linear time-variant, not LTI."

Unit check: hϕh_\phihϕ​ has units of 1/C1/\text{C}1/C (Γ\GammaΓ dimensionless, qmaxq_{max}qmax​ in C, uuu dimensionless), ∫hϕ in dτ\int h_\phi\, i_n\, d\tau∫hϕ​in​dτ has units =(1/C)⋅A⋅s=(1/C)⋅C==(1/\text{C})\cdot\text{A}\cdot\text{s}=(1/\text{C})\cdot\text{C}==(1/C)⋅A⋅s=(1/C)⋅C= dimensionless === rad ✓.

3. The integrator's frequency response 1/(jω)1/(j\omega)1/(jω) (why white noise → 1/f² phase noise)​

One line: phase is the "integral" of noise current (the upper limit of Eq.(11) is ttt); an integrator in the frequency domain is 1/(jω)1/(j\omega)1/(jω), and in power terms 1/ω21/\omega^21/ω2. This is the source of the −20-20−20 dB/dec slope.

For an ideal integrator y(t)=∫−∞tx(τ) dτy(t)=\int_{-\infty}^{t}x(\tau)\,d\tauy(t)=∫−∞t​x(τ)dτ, with a single tone x(t)=ejωtx(t)=e^{j\omega t}x(t)=ejωt:

∫tejωτ dτ=1jωejωt  ⇒  H(jω)=1jω.\int^{t}e^{j\omega\tau}\,d\tau=\frac{1}{j\omega}e^{j\omega t}\;\Rightarrow\;H(j\omega)=\frac{1}{j\omega}.∫tejωτdτ=jω1​ejωt⇒H(jω)=jω1​.
  • Magnitude: ∣H(jω)∣=1/ω|H(j\omega)|=1/\omega∣H(jω)∣=1/ω. Power (PSD multiplier): ∣H∣2=1/ω2|H|^2=1/\omega^2∣H∣2=1/ω2.
  • dB slope: 10log⁡10(1/ω2)=−20log⁡10ω10\log_{10}(1/\omega^2)=-20\log_{10}\omega10log10​(1/ω2)=−20log10​ω, −20-20−20 dB per decade — exactly the 1/f21/f^21/f2-region slope of phase noise.

Sϕ(Δω)=Γrms2qmax2⋅SiΔω2.S_\phi(\Delta\omega)=\frac{\Gamma_{rms}^2}{q_{max}^2}\cdot\frac{S_i}{\Delta\omega^2}.Sϕ​(Δω)=qmax2​Γrms2​​⋅Δω2Si​​.
  • Unit check (using C=A⋅s\text{C}=\text{A}\cdot\text{s}C=A⋅s):

4. The PSD of a stochastic process and the Wiener–Khinchin theorem​

One line: a stationary stochastic process's "power spectral density" (PSD) is the Fourier transform of its "autocorrelation function." This connects time-domain noise (autocorrelation) with frequency-domain noise (PSD), and is the foundation of every phase-noise calculation.

For a stationary stochastic process x(t)x(t)x(t), the autocorrelation is Rx(τ)=⟨x(t) x(t+τ)⟩R_x(\tau)=\langle x(t)\,x(t+\tau)\rangleRx​(τ)=⟨x(t)x(t+τ)⟩. Wiener–Khinchin theorem:

Sx(ω)=∫−∞∞Rx(τ) e−jωτ dτ.S_x(\omega)=\int_{-\infty}^{\infty}R_x(\tau)\,e^{-j\omega\tau}\,d\tau .Sx​(ω)=∫−∞∞​Rx​(τ)e−jωτdτ.
  • White-noise special case: Rx(τ)=N02δ(τ)R_x(\tau)=\frac{N_0}{2}\delta(\tau)Rx​(τ)=2N0​​δ(τ) (completely uncorrelated at different instants) ⇒Sx(ω)=N02\Rightarrow S_x(\omega)=\frac{N_0}{2}⇒Sx​(ω)=2N0​​ (frequency-independent — that's what "white" means). This site uses the single-sided PSD Si=in2‾/ΔfS_i=\overline{i_n^2}/\Delta fSi​=in2​​/Δf (A²/Hz).
  • Variance (total power):
σx2=Rx(0)=12π∫−∞∞Sx(ω) dω=∫0∞Sx(1-side)(f) df.\sigma_x^2=R_x(0)=\frac{1}{2\pi}\int_{-\infty}^{\infty}S_x(\omega)\,d\omega=\int_0^{\infty}S_x^{(1\text{-side})}(f)\,df .σx2​=Rx​(0)=2π1​∫−∞∞​Sx​(ω)dω=∫0∞​Sx(1-side)​(f)df.

This is where the phase-variance formula σϕ2=∫f1f2Sϕ(f) df\sigma_\phi^2=\int_{f_1}^{f_2}S_\phi(f)\,dfσϕ2​=∫f1​f2​​Sϕ​(f)df comes from: phase variance is the integral of the phase PSD over frequency ([P1]'s usage convention; a standard stochastic-process result).

Unit check: SϕS_\phiSϕ​ is in rad²/Hz, ∫Sϕ df\int S_\phi\, df∫Sϕ​df has units =rad2/Hz⋅Hz=rad2=\text{rad}^2/\text{Hz}\cdot\text{Hz}=\text{rad}^2=rad2/Hz⋅Hz=rad2 ✓.

External source: Wiener–Khinchin is a standard stochastic-process theorem (not among the five downloaded PDFs, standard textbook material, e.g. Papoulis; [P1] uses its conclusion directly).

6. The small-angle PM approximation (where L≈12Sϕ\mathcal{L}\approx\frac12 S_\phiL≈21​Sϕ​ comes from)​

One line: when phase jitter is small, the single-sideband power of a phase modulation is about half the phase PSD. This is the bridge that converts "phase PSD" into the "dBc/Hz" on a datasheet.

Consider a phase-modulated carrier: v(t)=Acos⁡ ⁣(ω0t+ϕ(t))v(t)=A\cos\!\big(\omega_0 t+\phi(t)\big)v(t)=Acos(ω0​t+ϕ(t)). When ∣ϕ(t)∣≪1|\phi(t)|\ll1∣ϕ(t)∣≪1 rad (small-angle), expand trigonometrically and approximate cos⁡ϕ≈1\cos\phi\approx1cosϕ≈1, sin⁡ϕ≈ϕ\sin\phi\approx\phisinϕ≈ϕ:

v(t)=A[cos⁡ω0tcos⁡ϕ−sin⁡ω0tsin⁡ϕ]≈Acos⁡ω0t−A ϕ(t)sin⁡ω0t.v(t)=A\big[\cos\omega_0 t\cos\phi-\sin\omega_0 t\sin\phi\big]\approx A\cos\omega_0 t-A\,\phi(t)\sin\omega_0 t .v(t)=A[cosω0​tcosϕ−sinω0​tsinϕ]≈Acosω0​t−Aϕ(t)sinω0​t.
  • The first term is the pure carrier; the second term −A ϕ(t)sin⁡ω0t-A\,\phi(t)\sin\omega_0 t−Aϕ(t)sinω0​t is the "phase sideband" — it moves the baseband ϕ(t)\phi(t)ϕ(t) to either side of the carrier.
  • For a phase component at a single offset frequency Δf\Delta fΔf, the sideband power is proportional to the power of ϕ\phiϕ; converting to the single-sideband (SSB) density relative to the carrier gives
L(Δf)≈12Sϕ(Δf).\mathcal{L}(\Delta f)\approx\frac12 S_\phi(\Delta f).L(Δf)≈21​Sϕ​(Δf).

That 12\frac1221​ comes from the bookkeeping of "total phase power split evenly between the upper and lower sidebands."

Applicability condition (important): holds only for σϕ≪1\sigma_\phi\ll1σϕ​≪1 rad. If the integration bandwidth is wide enough that σϕ\sigma_\phiσϕ​ approaches or exceeds 1 rad, this approximation fails (the carrier gets "smeared out"), and a more complete treatment is needed. Canonical example C's σϕ=14.07\sigma_\phi=14.07σϕ​=14.07 mrad ≪1\ll1≪1, so it is safe.

7. Trigonometric identities (the workhorse behind deriving Eq.(15)–(18))​

One line: when multiplying "some harmonic of the ISF" by "an injected single tone" and integrating over time, you use product-to-sum identities to split the product into a slow term (survives) and a fast term (vanishes after integration).

For an injected single tone i(t)=I0cos⁡(Δω t)i(t)=I_0\cos(\Delta\omega\,t)i(t)=I0​cos(Δωt) near DC, the phase response ([P1] Eq.(13), p.183's c0c_0c0​ term) requires computing ∫tI0cos⁡(Δω τ) dτ=I0sin⁡(Δω t)Δω\int^{t}I_0\cos(\Delta\omega\,\tau)\,d\tau=\dfrac{I_0\sin(\Delta\omega\,t)}{\Delta\omega}∫tI0​cos(Δωτ)dτ=ΔωI0​sin(Δωt)​, directly giving [P1] Eq.(15), p.183:

ϕ(t)≈I0 c0sin⁡(Δω t)2qmax Δω.\phi(t)\approx\frac{I_0\,c_0\sin(\Delta\omega\,t)}{2q_{max}\,\Delta\omega}.ϕ(t)≈2qmax​ΔωI0​c0​sin(Δωt)​.

When the tone is near nω0n\omega_0nω0​, use product-to-sum:

cos⁡(nω0τ+θn)cos⁡((nω0+Δω)τ)=12cos⁡((2nω0+Δω)τ+θn)+12cos⁡(Δω τ−θn).\cos(n\omega_0\tau+\theta_n)\cos\big((n\omega_0+\Delta\omega)\tau\big) =\frac12\cos\big((2n\omega_0+\Delta\omega)\tau+\theta_n\big)+\frac12\cos\big(\Delta\omega\,\tau-\theta_n\big).cos(nω0​τ+θn​)cos((nω0​+Δω)τ)=21​cos((2nω0​+Δω)τ+θn​)+21​cos(Δωτ−θn​).
  • The first term has frequency ≈2nω0\approx2n\omega_0≈2nω0​ (fast); after integration its amplitude ∝1/(2nω0)\propto1/(2n\omega_0)∝1/(2nω0​), tiny, negligible.
  • The second term has frequency Δω\Delta\omegaΔω (slow, near DC); after integration its amplitude ∝1/Δω\propto1/\Delta\omega∝1/Δω, survives.

Keeping only the slow term and integrating gives [P1] Eq.(16)/(17), p.183:

ϕ(t)≈I0 cnsin⁡(Δω t)2qmax Δω.\phi(t)\approx\frac{I_0\,c_n\sin(\Delta\omega\,t)}{2q_{max}\,\Delta\omega}.ϕ(t)≈2qmax​ΔωI0​cn​sin(Δωt)​.

That 12\frac1221​ is exactly what falls out of the product-to-sum step. Physical meaning: the ISF's nnn-th harmonic acts like a mixer, "downconverting" noise near nω0n\omega_0nω0​ into low-frequency phase modulation near the carrier — this is the frequency-translation picture of phase noise.

8. Random walk variance (the Δt\sqrt{\Delta t}Δt​ law of accumulated jitter)​

One line: an open-loop oscillator has no absolute time reference, so each period's phase error accumulates independently like a "drunkard's walk"; the variance of the error grows linearly, so the standard deviation grows as Δt\sqrt{\Delta t}Δt​.

Suppose each period injects an independent, zero-mean phase error δk\delta_kδk​ with variance σ12\sigma_1^2σ12​ (the result of white noise integrated over one period). After MMM periods the total phase error is ΦM=∑k=1Mδk\Phi_M=\sum_{k=1}^{M}\delta_kΦM​=∑k=1M​δk​. Because each δk\delta_kδk​ is independent, the variances add (cross-correlation terms have zero expectation):

Var(ΦM)=∑k=1MVar(δk)=M σ12.\mathrm{Var}(\Phi_M)=\sum_{k=1}^{M}\mathrm{Var}(\delta_k)=M\,\sigma_1^2 .Var(ΦM​)=k=1∑M​Var(δk​)=Mσ12​.
  • The measurement interval is Δt=M⋅T\Delta t=M\cdot TΔt=M⋅T, so M=Δt/TM=\Delta t/TM=Δt/T, Var(ΦM)=σ12T Δt∝Δt\mathrm{Var}(\Phi_M)=\dfrac{\sigma_1^2}{T}\,\Delta t\propto\Delta tVar(ΦM​)=Tσ12​​Δt∝Δt.
  • Converting to time jitter (σt=σϕ/(2πf0)\sigma_t=\sigma_\phi/(2\pi f_0)σt​=σϕ​/(2πf0​)) and taking the square root:
σΔt=κ Δt([P2] Eq.(10), p.793).\sigma_{\Delta t}=\kappa\,\sqrt{\Delta t}\qquad([P2]\ \text{Eq.}(10),\ \text{p.793}).σΔt​=κΔt​([P2] Eq.(10), p.793).

κ\kappaκ is a proportionality constant specific to each device, with units s\sqrt{\text{s}}s​; it is determined by the same Γrms2/qmax2\Gamma_{rms}^2/q_{max}^2Γrms2​/qmax2​ ratio ([P2] Eq.(12), p.793: κ=Γrmsqmax12in2‾Δf\kappa=\frac{\Gamma_{rms}}{q_{max}}\sqrt{\tfrac12\tfrac{\overline{i_n^2}}{\Delta f}}κ=qmax​Γrms​​21​Δfin2​​​​, verified verbatim).

Key intuition: variance (power) grows linearly, standard deviation (rms) grows as a square root. This is the hallmark of a random walk; it appears whenever phase errors accumulate independently with no restoring force (contrast: with a PLL locked, there is a restoring force and jitter is suppressed, no longer growing without bound). Corresponds to claim C6.

Numerical feel: at a spacing of 1000 periods (at 5 GHz, Δt=200\Delta t=200Δt=200 ns), σΔt\sigma_{\Delta t}σΔt​ is 1000/10=100=10×\sqrt{1000/10}=\sqrt{100}=10\times1000/10​=100​=10× that at a spacing of 10 periods (Δt=2\Delta t=2Δt=2 ns) — a 100× longer interval gives only 10× more jitter.

9. Large-angle PM: the Bessel sideband ladder and where the small-angle approximation fails​

One line: Section 6's small-angle PM result (L≈12Sϕ\mathcal{L}\approx\frac12 S_\phiL≈21​Sϕ​) is only the first-order approximation of "large-angle phase modulation" valid for β≪1\beta\ll1β≪1; the full solution is an infinite ladder of Bessel sidebands, with the carrier and each sideband having amplitude J0(β)J_0(\beta)J0​(β) and Jn(β)J_n(\beta)Jn​(β) respectively. This section builds the full ladder and quantifies exactly when the small-angle approximation starts to break down.

9.1 The Jacobi–Anger expansion (external literature, not in this site's 5 PDFs)​

For any real β\betaβ (the modulation index) and angle Ωt\Omega tΩt, the Jacobi–Anger expansion (a standard special-function identity, e.g. Abramowitz & Stegun 9.1.42; external literature, not in this site's 5 PDFs):

ejβsin⁡Ωt=∑n=−∞∞Jn(β) ejnΩte^{j\beta\sin\Omega t}=\sum_{n=-\infty}^{\infty}J_n(\beta)\,e^{jn\Omega t}ejβsinΩt=n=−∞∑∞​Jn​(β)ejnΩt

where Jn(β)J_n(\beta)Jn​(β) is the Bessel function of the first kind, order nnn. Why it holds (one-line provenance): ejβsin⁡Ωte^{j\beta\sin\Omega t}ejβsinΩt is 2π2\pi2π-periodic in Ωt\Omega tΩt; expanding it in a Fourier series, the integral defining its coefficients 12π∫−ππej(βsin⁡x−nx)dx\frac{1}{2\pi}\int_{-\pi}^{\pi}e^{j(\beta\sin x-nx)}dx2π1​∫−ππ​ej(βsinx−nx)dx is exactly one of the standard integral representations of Jn(β)J_n(\beta)Jn​(β) — that integral representation itself is not re-derived here, only its result is cited.

Properties (used below): J−n(β)=(−1)nJn(β)J_{-n}(\beta)=(-1)^n J_n(\beta)J−n​(β)=(−1)nJn​(β) (symmetric for even nnn, antisymmetric for odd nnn), and the Bessel Parseval-like identity:

∑n=−∞∞Jn(β)2=1(∀β)\sum_{n=-\infty}^{\infty}J_n(\beta)^2=1\qquad(\forall\beta)n=−∞∑∞​Jn​(β)2=1(∀β)

This can later be used to check "the sideband ladder's total power is conserved" — a complete analogy to the Parseval relation for the ISF's Fourier coefficients in Section 1.

9.2 The sideband ladder for single-tone PM​

Consider a carrier phase-modulated by a single audio tone Ω\OmegaΩ (writing Section 6's ϕ(t)=ϕpsin⁡Ωt\phi(t)=\phi_p\sin\Omega tϕ(t)=ϕp​sinΩt as ϕ(t)=βsin⁡Ωt\phi(t)=\beta\sin\Omega tϕ(t)=βsinΩt, where β\betaβ is the modulation index, i.e. the peak phase deviation, units rad):

V(t)=cos⁡ ⁣(ω0t+βsin⁡Ωt)V(t)=\cos\!\big(\omega_0 t+\beta\sin\Omega t\big)V(t)=cos(ω0​t+βsinΩt)

Writing this as Re{ejω0t ejβsin⁡Ωt}\mathrm{Re}\{e^{j\omega_0 t}\,e^{j\beta\sin\Omega t}\}Re{ejω0​tejβsinΩt} and substituting the Jacobi–Anger expansion:

V(t)=Re{ejω0t∑n=−∞∞Jn(β)ejnΩt}=∑n=−∞∞Jn(β)cos⁡((ω0+nΩ)t)V(t)=\mathrm{Re}\left\{e^{j\omega_0 t}\sum_{n=-\infty}^{\infty}J_n(\beta)e^{jn\Omega t}\right\} =\sum_{n=-\infty}^{\infty}J_n(\beta)\cos\big((\omega_0+n\Omega)t\big)V(t)=Re{ejω0​tn=−∞∑∞​Jn​(β)ejnΩt}=n=−∞∑∞​Jn​(β)cos((ω0​+nΩ)t)

This is the full Bessel sideband ladder:

  • Carrier (n=0n=0n=0): amplitude J0(β)J_0(\beta)J0​(β), located at ω0\omega_0ω0​.
  • nnn-th sideband (n=±1,±2,…n=\pm1,\pm2,\dotsn=±1,±2,…): amplitude Jn(β)J_n(\beta)Jn​(β), located at ω0+nΩ\omega_0+n\Omegaω0​+nΩ.
  • Because J−n=(−1)nJnJ_{-n}=(-1)^nJ_nJ−n​=(−1)nJn​, the upper and lower sidebands have equal magnitude (∣J−n∣=∣Jn∣|J_{-n}|=|J_n|∣J−n​∣=∣Jn​∣), differing only in sign (phase).

Unit check: β=ϕp\beta=\phi_pβ=ϕp​ is the peak phase, arising from the integral ∫ϕ(t)\int\phi(t)∫ϕ(t), with units rad; Ωt\Omega tΩt and ω0t\omega_0 tω0​t are both dimensionless phase angles (rad), and Jn(β)J_n(\beta)Jn​(β) itself is dimensionless (an amplitude ratio), so substituting into cos⁡(⋅)\cos(\cdot)cos(⋅) raises no unit issue; V(t)V(t)V(t) has the same units as the original cos⁡(ω0t+ϕ(t))\cos(\omega_0t+\phi(t))cos(ω0​t+ϕ(t)) (normalized amplitude) ✓.

9.3 The small-β\betaβ limit: recovering Section 6's small-angle approximation​

Small-argument expansion of the Bessel functions (standard external-literature result):

J0(β)≈1−β24,J1(β)≈β2(β≪1)J_0(\beta)\approx1-\frac{\beta^2}{4},\qquad J_1(\beta)\approx\frac{\beta}{2}\qquad(\beta\ll1)J0​(β)≈1−4β2​,J1​(β)≈2β​(β≪1)

Substituting back into the sideband ladder: the carrier amplitude J0(β)≈1−β2/4≈1J_0(\beta)\approx1-\beta^2/4\approx1J0​(β)≈1−β2/4≈1 (barely attenuated at first order), and the first-sideband amplitude J1(β)≈β/2J_1(\beta)\approx\beta/2J1​(β)≈β/2. The single-sideband relative power:

L(Δf)≈J1(β)2≈(β2)2\mathcal{L}(\Delta f)\approx J_1(\beta)^2\approx\left(\frac{\beta}{2}\right)^2L(Δf)≈J1​(β)2≈(2β​)2

This is exactly Section 6's small-angle PM result L≈(ϕp2)2=12Sϕ\mathcal{L}\approx\left(\frac{\phi_p}{2}\right)^2=\frac12 S_\phiL≈(2ϕp​​)2=21​Sϕ​ (β=ϕp\beta=\phi_pβ=ϕp​ is the peak phase, Sϕ=ϕp2/2S_\phi=\phi_p^2/2Sϕ​=ϕp2​/2 is its power) — the Bessel sideband ladder automatically converges to the small-angle PM formula as β≪1\beta\ll1β≪1; the two are the first-order and full versions of the same thing. The higher-order sidebands J2(β)≈β2/4, J3(β)≈β3/48,…J_2(\beta)\approx\beta^2/4,\,J_3(\beta)\approx\beta^3/48,\dotsJ2​(β)≈β2/4,J3​(β)≈β3/48,… vanish rapidly as β≪1\beta\ll1β≪1 (Jn(β)∼(β/2)n/n!J_n(\beta)\sim(\beta/2)^n/n!Jn​(β)∼(β/2)n/n!), which is why it is reasonable for the small-angle approximation to keep only the first-order sideband.

9.4 Failure boundary: where does the small-angle approximation err by 1 dB?​

The small-angle approximation replaces J1(β)J_1(\beta)J1​(β) with the first-order term β/2\beta/2β/2; as β\betaβ grows, this approximation drifts from the true value. Define the error (comparing the amplitude ratio of the two, in dB):

errdB(β)=20log⁡10 ⁣(J1(β)β/2)\text{err}_{\text{dB}}(\beta)=20\log_{10}\!\left(\frac{J_1(\beta)}{\beta/2}\right)errdB​(β)=20log10​(β/2J1​(β)​)

(errdB→0\text{err}_{\text{dB}}\to0errdB​→0 as β→0\beta\to0β→0; as β\betaβ grows, J1J_1J1​'s growth slows, the ratio drops below 1, and errdB<0\text{err}_{\text{dB}}<0errdB​<0, i.e. the small-angle approximation overestimates the sideband.) Solving numerically for errdB(β)=−1\text{err}_{\text{dB}}(\beta)=-1errdB​(β)=−1 dB (root-finding scipy.optimize.brentq on scipy.special.jv, see the Python block below):

β1dB≈0.950 rad(≈54.5∘)\beta_{1\text{dB}}\approx0.950\ \text{rad}\quad(\approx54.5^\circ)β1dB​≈0.950 rad(≈54.5∘)

In plain terms: as long as the peak phase deviation β≲0.95\beta\lesssim0.95β≲0.95 rad, the small-angle approximation L≈(β/2)2\mathcal{L}\approx(\beta/2)^2L≈(β/2)2 is accurate to within 1 dB; beyond this range (e.g. wideband FM, large-index PM, or an integration bandwidth wide enough that σϕ\sigma_\phiσϕ​ approaches 1 rad), the full Bessel sideband ladder must be used — the small-angle formula no longer applies. This echoes Section 6's qualitative statement that it "holds only for σϕ≪1\sigma_\phi\ll1σϕ​≪1 rad," now with a quantitative boundary.

9.5 Carrier-suppression null and Carson bandwidth (external literature, not in this site's 5 PDFs)​

Carrier suppression: as β\betaβ grows to the first root of J0(β)=0J_0(\beta)=0J0​(β)=0, the carrier vanishes completely and all power is transferred to the sidebands — a classic phenomenon in FM/PM systems:

J0(β)=0’s first root: β=2.405(numerical solution, see the Python block below: J0(2.405)≈−9×10−5≈0)J_0(\beta)=0\text{'s first root: }\beta=2.405\quad(\text{numerical solution, see the Python block below: }J_0(2.405)\approx-9\times10^{-5}\approx0)J0​(β)=0’s first root: β=2.405(numerical solution, see the Python block below: J0​(2.405)≈−9×10−5≈0)

Carson's bandwidth rule (external literature, an engineering rule of thumb, not in this site's 5 PDFs): in practice the sideband ladder has infinitely many terms, but Jn(β)J_n(\beta)Jn​(β) decays rapidly to negligible size once n>β+1n>\beta+1n>β+1, so an effective bandwidth is defined (fm=Ω/2πf_m=\Omega/2\pifm​=Ω/2π):

BWCarson≈2(β+1)fmBW_{\text{Carson}}\approx2(\beta+1)f_mBWCarson​≈2(β+1)fm​

At β=2.405\beta=2.405β=2.405, BW≈6.81 fmBW\approx6.81\,f_mBW≈6.81fm​; at small-angle β=0.1\beta=0.1β=0.1, BW≈2.2 fmBW\approx2.2\,f_mBW≈2.2fm​ (barely more than a single sideband pair, consistent with the picture that "small-angle PM has only the ±1\pm1±1 sidebands").

9.6 Python check: the full sideband ladder at three values of β\betaβ​

import numpy as np
from scipy.special import jv, jn_zeros
from scipy.optimize import brentq

for beta in [0.1, 1.0, 2.405]:
    print(f"beta={beta}")
    for n in range(5):
        print(f"  J_{n}({beta}) = {jv(n, beta):.6f}")
    # -> beta=0.1: J0=0.997502, J1=0.049938, J2=0.001249, J3=0.000021, J4≈0
    # -> beta=1.0: J0=0.765198, J1=0.440051, J2=0.114903, J3=0.019563, J4=0.002477
    # -> beta=2.405: J0=-0.000091(≈0), J1=0.519110, J2=0.431783, J3=0.199032, J4=0.064763

# carrier null (classic 2.405)
z0 = jn_zeros(0, 1)[0]
print(f"first zero of J0: {z0:.6f}")
# -> first zero of J0: 2.404826

# small-angle approximation vs exact
for beta in [0.1, 0.3, 0.5, 1.0]:
    J0, J1 = jv(0, beta), jv(1, beta)
    print(f"beta={beta}: J0={J0:.6f} vs 1-b^2/4={1-beta**2/4:.6f} | "
          f"J1={J1:.6f} vs b/2={beta/2:.6f}")
    # -> beta=0.1: J0=0.997502 vs 0.997500 | J1=0.049938 vs 0.050000
    # -> beta=1.0: J0=0.765198 vs 0.750000 | J1=0.440051 vs 0.500000

# 1 dB failure boundary: 20log10(J1(beta)/(beta/2)) = -1 dB
f = lambda b: 20*np.log10(jv(1, b)/(b/2)) - (-1.0)
beta_1dB = brentq(f, 0.5, 1.5)
print(f"beta_1dB = {beta_1dB:.4f}")
# -> beta_1dB = 0.9505

# Parseval check: sum J_n^2 = 1
for beta in [0.1, 1.0, 2.405]:
    s = sum(jv(n, beta)**2 for n in range(-50, 51))
    print(f"beta={beta}: sum J_n^2 = {s:.8f}")
    # -> all beta give 1.00000000
