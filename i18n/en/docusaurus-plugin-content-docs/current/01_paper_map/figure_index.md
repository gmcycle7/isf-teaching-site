# Figure Index

This site has two kinds of figures: **(a) figures we generate with Python** (all teaching toy/conceptual models,
**not transistor-level**), and **(b) figures inside the cited paper PDFs**. This page files every one of them,
so you can trace any figure back to "which script, which function, what parameters, which formula behind it, which paper it comes from".

> **How to read this table**:
> - **Toy?** = whether it is a simplified teaching model (not transistor-level).
> - **Redrawn?** = whether it was redrawn directly from a paper figure (our generated figures are always **re-simulated**, never traced, so mostly No).
> - **Verify?** = `manual_verification_needed`; entries flagged ⚠️ still need manual confirmation of constants/correspondence.
> - Re-run everything in one shot: `python scripts/run_all_sims.py` (outputs to `static/figures/`).
> Data comes from `extracted/extracted_figures.json`.
